# 验收检查清单

> 每次修改代码后，按对应功能的清单逐项验收。
> 验收格式：**操作 → 预期看到什么**
> 关联文档：[PRD.md](PRD.md) · [APP_FLOW.md](APP_FLOW.md)

---

## 当前验收分层（2026-04-02）

- 稳定主链路：
  小红书单篇/批量/评论/博主/评论图片区，抖音单条视频、分享触发采集、博主页/搜索页批量视频、博主页/搜索页批量评论。
- 重点回归链路：
  抖音单条评论、抖音评论图片区下载、抖音数据面板二次下载长时效、跨页面暂停/继续/停止、内容工作台自动接单闭环。
- 使用原则：
  “代码里有实现”不等于“已验收完成”；接手期优先把重点回归链路跑通，再把结果同步回本清单。

| 15.4b-1 | 小红书博主页作品区本身是内部滚动区，且高度明显小于浏览器窗口 | 插件应按作品区自己的可视高度判断“是否到底”，继续下滑补齐目标数量；不能拿整窗高度误判已经到底 |
| 15.4c | 内容工作台下发小红书博主巡查/表层扫描任务，目标数量大于当前可见作品数 | 插件应按工作台给出的数量继续下滑扫描博主页作品区，不应只取当前可见卡片 |
| 15.4d | 小红书 `author_baseline` 首次建档批量采集到评论数为 0 的作品 | 工作台应把 0 当成已采到的真实评论数，不应继续显示“评论待补采” |
| 15.4e | 小红书 `author_baseline` 首次建档作品详情里有 `cover / coverImg / coverUrl` 任一封面字段 | 工作台发文趋势、作品卡片和详情日志应能显示封面预览，不应只显示空白占位 |
| 15.4f | 小红书 `author_baseline` 首次建档作品详情没有图片，但博主页卡片本身有封面图 | 插件应把卡片封面作为兜底写回，工作台不应只显示“封面待补” |
| 15.4g | 抖音 / 小红书工作台远程任务已经在执行页产出本地结果包 | 插件应使用本次执行页回取结果包，工作台能看到记录和完成事件，不应只有心跳 |
| 15.4h | 内容工作台下发小红书 `xhs.batchNotes` 详情任务，payload 要求 `includeComments=true` 且 `commentLimit=20` | 插件应一次采回正文、指标、公开评论数和 20 条以内评论；公开评论不足 20 条按实际数量完成，公开评论数明确为 0 时不再显示“评论待补采”；公开评论数大于 0 但没有评论正文时必须标为附带评论缺失 |
| 15.5 | 任务正常完成 | 工作台状态推进到 `completed`，结果摘要与插件结果包一致 |
| 15.5a | 工作台任务使用插件新开的执行页完成、失败或停止 | 该执行页应自动关闭，不应继续残留在浏览器标签页里 |
| 15.5b | 工作台任务复用了用户原本打开的页面 | 任务结束后不应关闭用户原本的页面，只结束任务状态和插件控制条 |
| 15.6 | 任务失败或页面上下文不匹配 | 工作台保留 `pending` 或进入 `failed`，并有可读错误；不应误认领到错误页面 |
| 15.6a | 任务停在 `dispatched` 但 45 秒内一直没有本地运行记录 | 插件应自动把该任务标成失败并释放，不能让队列长期挂住 |
| 15.6b | 小红书评论/详情任务打开后发现目标笔记已删除、页面错误或当前账号无权限访问 | 工作台任务应进入 `failed`，错误原因保留为页面不可访问类原因；不应回到 `pending` 并被多个工位反复接单 |
| 15.6c | 任务已经进入 `running`，但执行页结果包交接丢失 | 插件应在保护窗口后把任务标成可读失败并释放工位，不应无限维持“采集中”心跳 |
| 15.7 | 插件 Background 重启后仍存在已接单任务 | 插件能恢复并继续轮询/跟踪已有 `running / paused` 任务，而不是丢失状态 |
| 15.8 | 工位只有超过 200 条 `failed_terminal` 历史死信、没有 `pending / in_flight / failed` 可重试记录 | Popup 仍显示死信红色告警，但插件继续认领新任务；不得进入无法自愈的 `OUTBOX_BACKLOG_BLOCKED`，也不得尝试自动补发死信 |
| 15.9 | 可重试写回超过 200 条，或最老未发送记录超过 30 分钟 | 插件返回 `OUTBOX_BACKLOG_BLOCKED`、暂停认领新任务并触发补发；积压恢复后自动恢复接单 |
| 15.10 | Popup 查看待发送/死信并点击“导出恢复数据” | 两类计数分开展示；恢复包包含采集事实与死信，导出前后本地行数和状态不变 |
| 15.11 | 远程任务页内上报 100% 进度、服务端尚未确认终态 | 插件传输和活跃状态只显示 95%，文案为“等待服务端确认”；服务端确认完成后才显示 100%/完成 |
