D. 公共 Seam

// 映射已验证来源 → 执行 authority
mapExecutionAuthority(ctx: ExecutionTaskContext, sourcePrincipal: string)
  → Extract<EvidenceIngressAuthorityV2, { ingressKind: "execution" }>

// 提取执行专属 header 字段
executionHeaderFields(ctx: ExecutionTaskContext)
  → { jobId, attemptId, leaseEpoch }

// 组合 body + authority → 完整 CaptureSubmissionV2
buildExecutionSubmission(body, ctx, sourcePrincipal)
  → CaptureSubmissionV2

- ✅ sourcePrincipal 为显式参数，不默认、不猜测
- ✅ 空/无效 context 字段 → throw
- ✅ body 含 authority 字段 → throw（leak 检测）
- ✅ 不修改输入对象（immutability 验证）
- ✅ 不调用网络、数据库、outbox
- ✅ 不接 taskLeaseClient/taskPoller/background
