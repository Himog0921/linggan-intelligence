6. Schema 与 Migration 实际差异

schema.prisma RawSnapshot:
- schemaVersion: String → String?
- qualityStatus: RawSnapshotQualityStatus @default(ok) → RawSnapshotQualityStatus? @default(ok)
- source: String @default("plugin_sync") → String? @default("plugin_sync")

schema.prisma RawRecord:
- recordType: String → String?
- FK: fields: [rawSnapshotId], references: [id] → fields: [workspaceId, rawSnapshotId], references: [workspaceId, id], map: "RawRecord_workspace_snapshot_fkey"
- 唯一键: @@unique([workspaceId, idempotencyKey]) → @@unique([workspaceId, rawSnapshotId, idempotencyKey])

Migration SQL (20260805180000_add_v2_evidence_release_b_prepare):
- ALTER TABLE "RawSnapshot" ALTER COLUMN "schemaVersion" DROP NOT NULL
- ALTER TABLE "RawSnapshot" ALTER COLUMN "qualityStatus" DROP NOT NULL
- ALTER TABLE "RawSnapshot" ALTER COLUMN "source" DROP NOT NULL
- ALTER TABLE "RawRecord" ALTER COLUMN "recordType" DROP NOT NULL
- DROP CONSTRAINT "RawRecord_rawSnapshotId_fkey" + 新建 compound FK "RawRecord_workspace_snapshot_fkey"
- DROP INDEX "RawRecord_workspaceId_idempotencyKey_key" + 新建 "RawRecord_workspaceId_rawSnapshotId_idempotencyKey_key"
