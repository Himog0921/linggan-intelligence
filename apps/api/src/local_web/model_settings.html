用途默认

输入先按 UTF-8 字节与固定封装余量保守拦截，供应商实际 token 另记。每次调用先预留输入与输出上限；用量未取得时保留预留，不推断零消耗。预算是本机控制，不是供应商账单。

新配置只用于新任务；已有任务和结果保留当时版本。保存不发起评论分析，已有自动观察开关保持原状态与累计额度。
