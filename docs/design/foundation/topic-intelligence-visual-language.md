# Topic Intelligence Visual Language

> 状态: 权威当前
> 最后核对: 2026-08-21
> 适用范围: DESIGN-002 的 Topic Intelligence Reference Page；后续页面须显式采纳后才可复用
> 事实来源: Mog 确认的“未来感 + ASCII + 新粗野主义 + 情报系统感”方向、`docs/pages/topic-intelligence-surface.md`、Issue #7 与 UI 设计治理协议
> 冲突时以谁为准: 用户最新确认、产品页面/数据/权限合同、`docs/design/design-governance.md` 与真实可访问性验证

## 视觉论点

这不是一张“数据很多所以显得专业”的仪表盘。它应该像一张被标注过的研究台：**深色、硬边、有判断的排版**让人先看到“我正在看什么”，荧光色只用于资格和限制，ASCII 只用来承载系统边界，而不是制造假科技感。

本参考页的记忆锚点是：

> 一块被荧光标记、但仍明确露出缺口的情报研究台。

## DS-001 · 色彩职责

| 角色 | 参考 token | 只用于 | 不得用于 |
|---|---|---|---|
| 深墨背景 | `#080b0a` | 页面底、信息退后层 | 把不同业务状态压成同一黑色 |
| 石墨表面 | `#121815` / `#1a211d` | 区域分层与可读底 | 到处套同一种 Card |
| 荧光酸绿 | `#d8ff4a` | 当前焦点、合成模式、可用下一步 | 成功、可信、增长或正式通过 |
| 警示珊瑚 | `#ff745c` | 明确缺口、来源不足和禁止推断 | 装饰或普通分隔线 |
| 冷白文字 | `#f2f4ee` | 主文与关键数字 | 与酸绿/珊瑚混作状态等级 |
| 雾灰文字 | `#a8b1aa` | 元数据和解释 | 低到不可读的“高级感” |

颜色表达的是阅读优先级和资格提醒，不表达未经合同支持的事实强弱。文字与相邻背景必须通过实际对比度检查；不以“霓虹风格”豁免可读性。

## DS-002 · 字体与文字层级

- 中文正文使用系统可用的清晰无衬线字体；英数元数据使用系统等宽字体。参考实现不得为了风格引入外部字体、网络请求或无法验证的品牌资产。
- 单页最多三档文本权重：Topic 名称、区块标题、阅读正文/元数据。不要制造十种“看似有层级”的字号。
- 等宽文字只承担版本、模式、标签、时间窗口和边界；长段中文不进入等宽排版。

## DS-003 · 工作台构图

- 桌面优先：在约 1280px 以上使用不对称三列；中心是“当前样本观察”，左右只承担定向与边界，不抢主问题。
- 狭窄屏幕下按身份与边界 → 观察 → 原声/叙事 → 候选/限制 → 本地意图的顺序单列排开。该退化只保证阅读，不授权移动端操作工作台。
- 使用粗线、色块分层和留白制造层次；不以圆角卡片阵列、阴影堆叠或悬浮玻璃代替信息结构。

## DS-004 · ASCII 的有限职责

ASCII 可以出现于：模式旗标、时间窗口、范围分隔、来源/限制标签和非数据性的静态坐标框。它不得出现于：趋势图、装饰性矩阵、假终端日志、模拟运行进度、假载入动画或会被读作数据的图表。

每个 ASCII 元素必须能被普通中文文案替代而不损失事实含义；屏幕阅读器应能跳过纯装饰字符或取得同义文本。

## DS-005 · 边界可见性

每个页面的第一个视觉层必须同时展示：当前模式、样本范围、最重要限制。限制不是底部脚注，也不能被“系统当前判断”盖住。

`SYNTHETIC / NOT LIVE`、`SOURCE_INCOMPLETE` 和“未创建真实记录”使用可扫描的文字和图形层次同时表达；图标、颜色或动效不能单独承担它们。

## DS-006 · 互动与动效

- 本页唯一的标志性互动是**证据卡的硬切换展开**：点击后内容在原位出现，明确暴露“合成示例／不能证明什么”，不移动其它核心信息，也不模拟数据刷新。
- 时间窗口和本地意图仅改变其声明范围内的示例文案；变化后仍保留模式与限制标记。
- 过渡应短、克制，并在 `prefers-reduced-motion: reduce` 下取消。无真实事件时不播放循环、扫描线、计数跳动或“正在分析”。

## DS-007 · 可访问性与状态稳定性

- 所有互动元素必须可通过键盘获得焦点，并有可见焦点状态；颜色不是唯一状态提示。
- 内容展开、时间窗口和本地意图反馈要有可读名称、选择状态和稳定的布局容器，避免点击后核心区域跳动。
- 动态演示反馈只可在本地、明确标记的说明区出现；不使用“成功”“已完成”“已保存”等会被误解为真实回执的词。

## 非目标与验收

本文件不定义全局品牌、完整组件库、产品框架、颜色主题切换、正式数据可视化或真实状态合同。每次采纳 DS-001–DS-007 的页面必须在其 PAGE 规格里写明使用哪些规则，并检查：主任务是否仍唯一、限制是否首屏可见、无依据的趋势/分数/进度是否进入页面、窄视图是否仍可读、减少动效后是否保留含义。
