## 5b. 第二轮：控件统一到证据库那套语言（Mog 2026-09-10 反馈）

Mog 指出三件事：字段没对齐；三个行内按钮大小不一、放一起违和，删除只是两个字不成设计；工具条控件（最近观察、创作者、输入框、批量编辑）不是标准风格，箭头没质感、没有动效。并指定以证据库那条 `FIND / 筛选 / 最近观察 / 读取材料` 工具条为准。

- **字段没对齐的根因**：表头与数据行是两个各自独立的 grid 容器，而创作者列写的是 `minmax(140px,max-content)`。内容相关的轨道在两个容器里各算各的——表头按「创作者」三字算落到下限 140px，数据行按「头像＋名字＋ID」算得 189px，**189−140=49**，于是从第四列起每个数据格都比表头右移 49px。改成定值 `minmax(0,192px)` 后两表错位归零。
- **三个行内控件统一**：查看档案 / 观察开关 / 删除 全部 34px 高、1px 墨线，沿用 `.ev-button` 的字重与字号。区分不再靠尺寸，靠形状与颜色——开关是唯一带滑轨的，删除是唯一的红（`--lgi-danger` 描边与文字）。
- **开关**：按 Mog 要求不带文字，语义由 `aria-label`/`title` 承载。此前 38×21、13px 滑块夹在 28~40px 按钮之间显得单薄；现在与按钮同高、2px 外框、24px 实心滑块。轨道用下沉面而不是点阵——60×34 这么小的控件上点阵读成噪点；观察中时槽透信号色，隔着一米能看出哪些目标是活的。
- **工具条**：`最近观察` 的箭头此前是**文字字符 ↓**，`创作者` 是**原生 select**（浏览器自带箭头）。现在全部 44px、1px 墨线、650/12px，折角一律用描边自绘并带 160ms 翻转/位移缓动；主按钮黑底白字加点阵（与「读取材料」同一做法），不用硬阴影——工具条是常驻控件，投影会一直在喊。
- **巡查时刻去年份**：同一屏里年份永远相同却占五个字符。裁剪在展示层（`moment_without_year`），不新写 `to_char` 格式——治理检查正是禁止那件事。**去掉年份释放的宽度让所有列不再截断**（1920 下实测缺宽列为 0）。
- **既有护栏抓住了我一次**：给 select 折角写了 `linear-gradient`，被 `!TARGET_DRAWER_CSS.contains("gradient")` 拦下。那条规矩属于 v7「纹理不能做成廉价图案皮肤」的材料纪律，是我违规而不是规矩该改；改用描边画折角、淡出改整体透明度。连注释里的英文词都要避开——断言是纯子串匹配。
