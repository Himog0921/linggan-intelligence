## 2026-10-08 · 用户评论窄屏表格补充

在已部署的 `:3000`、约 495 CSS px 窗口中，用户评论的五列表格将“所属作品”等中文逐字换行，原声阅读列被挤压。其外层已有横向滚动，但通用复核表声明的 `calc(var(...) * 6)` 在实际浏览器算成 `min-width: 0px`；第一列“选择”在桌面还误占 46%。这属于当前四视图的可读性缺口，不改变评论来源、研究资格、状态或任何写入合同。

本补充使用现有 96px 间距 Token 的有效 `calc()` 加法，分别给通用复核表和 `.study-comments-table` 提供 576px、960px 的最小宽度；评论表明确列宽，以既有 64px 间距 Token 作为选择列的宽度基准，原声列优先阅读，窄屏由既有包裹层横向滚动。桌面保持完整五列；评论详情、共享 shell 和 Token 值均不改。依据现有页面规格的窄屏表格横向滚动与表头语义要求，不新增展示规则。

验收在实际浏览器的窄窗口与桌面检查表头和原声不逐字竖排、包裹层能滚动到末列、整页没有横向溢出；从评论目录打开详情并保留父语境／历史入口。CSS 静态检查不能替代上述视觉与交互回执。
