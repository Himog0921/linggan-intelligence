## 状态词典

加载、已知空、读取失败、保留旧值、部分成果、未知、受限、处理中和结果未确认分开。null不是0，材料入库不是采集全部结束，心跳过期不是正在执行。工位恢复接收不等于恢复停止任务。真实动作继续依赖服务端回执，不用本地状态宣称成功。
