## 2. 用户路径与页面布局

首次进入：概览显示当前可读语料和研究覆盖 → “设置自动研究” → 选择模型、范围、日额度、历史补齐政策 → 保存并启用一次 → 返回概览看到下一截点/当前状态。以后无需选评论、每天建批次。

日常进入：概览了解正在处理/还缺什么 → 用户问题看自动组织结果 → 原声查看真实表达与作品上下文；遇到疑惑再打开运行记录看输入、结果接纳和恢复情况。用户有具体问题时，从原声搜索结果发起定向研究。

```text
评论研究                              近30天 ▾  运行记录  研究设置  刷新
概览  原声  用户问题  变化观察
──────────────────────────────────────────────────────────
概览：自动研究状态 / 下一截点 / 今日额度（真实回执，紧凑一行）
      有效原声 · 已研究 · 无信号 · 待更新 · 待研究
      今日新增 / 今日完成 / 执行失败与系统下一动作
      近期主要问题、六类视角、社区词、代表原声

原声：检索/作品/结果状态/执行状态 → 紧凑表格 → 分页
      有选择时才出现定向研究操作条，显示跨页已选总数

问题：问题结构/需求/方案等研究角度 → 定义与样本分布 → 原声
      暂未归并的表达仍可查看，自动整理状态不变成人工待办

变化：符合比较资格的变化 → 计算口径/版本/原因 → 证据
      未具备资格时说明缺哪个条件，并保留已有问题/原声入口
```

图中文字是布局示意，不是合成运行记录；实际渲染不得写入虚构数字、主题或完成状态。

## 3. 表面地图

| 表面 | 首屏内容与默认动作 | 细节与返回路径 |
|---|---|---|
| 概览 | 自动运行状态、当前覆盖、今日新增/完成、需要恢复的数量和下一动作 | 统计可点击进入同范围原声；研究质量/覆盖与运行故障分别表达；近期结果保留，趋势在资格满足时展示 |
| 原声 | 证据库同密度表格，正文、作品、点赞、时间、结果；搜索和筛选 | 任务状态作为次级说明；打开已有分析不用重新运行；分页、跨页选择、页大小继续可用 |
| 用户问题 | 自动形成的问题定义、评论/作品覆盖、邻近问题、代表表达 | 详情区分核心与边界、派生名称与原话；可回原声及运行；自动独立不要求人工合并 |
| 变化观察 | 新采到/首次识别/可比变化的明确类型、范围和依据 | 无基线/覆盖不足/版本变化/历史回填分别解释；不要求先选批次才能看结果 |
| 研究设置 | 一个对话表面，自动研究、研究内容、上下文、资源限制、版本比较分区渐进展开 | 无层叠弹窗跳“每日设置”；基础设置短，技术参数折叠；保存、启用、候选提交有明确各自后果 |
| 规则对比 | 旧/候选版本，配对覆盖，结构/依据拒绝/分布/稳定性/Token/耗时变化，具体差异例 | 在设置内查看，长报告可从运行详情接续；不出现人工标注列表；无数据就解释未运行或不足 |
| 运行记录 | 按影响与时间排序，先本次处理多少/为什么未完成/系统将怎么恢复 | 逐请求/阶段流水显示真实事件、时间、模型、用量；输入输出与校验放检查器，不用技术JSON占第一屏 |
| 定向确认 | 可复用/进行中/首次/过期/待恢复等互斥预检、拟外发条数、作品数和调用/Token估算 | 重研改变立即刷新预检；确认等待新预检回执；取消保留选择、无任务创建 |
| 来源检查器 | 派生文本与可查原文、父回复、作品正文/OCR/ASR片段、点赞事实 | 研究规则、原子/字段依据、历史适用性、关联问题和执行出处按需展开；关闭清理内容并恢复焦点 |

### 研究设置具体内容

1. **自动研究**：启用状态；当前领域/范围；23:00截点；新增持续研究；历史未研究补齐开关及起点；历史结果更新政策。显示待处理存量和保存后开始生效的范围。
2. **研究内容**：当前有效规则、目的与字段“算/不算/何时留空”；高级编辑受限业务定义和例子；保存草稿零调用；提交候选说明自动对比及预算。schema/validator仅查看，不能关闭证据约束。
3. **上下文**：作品正文、OCR、ASR、父评论开关；片段选择方法/预算；调用细节可核对实际片段。已有问题召回属于语义组织，不能写成Task A实际上没有收到的上下文。
4. **资源限制**：日条数/Token、每次输入/输出/timeout、历史剩余额度、回归子预算、有限失败/未知用量恢复。基础显示用户可理解的作用，细节折叠，未知费用不写0元。
5. **版本比较**：最近候选、排队/运行/不足/退化/通过、自动采用政策与当前有效版本；展示真实配对案例，无机械审核按钮。

模型与向量模型仍复用现有个人模型设置入口及单供应商弹窗；此处显示当前选择和状态，不复制一套密钥管理。改变默认模型不弹出“必须评论校验”旧门槛。

## 4. 状态词典

| 后端事实 | 页面表达与动作 |
|---|---|
| 未设置/未启用 | 自动研究尚未启用；设置自动研究 |
| 已启用且没有符合条件任务 | 自动研究已启用，当前没有待处理评论；显示下一截点 |
| 新增/恢复/历史待处理 | 分列原因与数量，不要求用户选一批 |
| 模型暂不可用 | 等待模型恢复；已取得结果仍可查看 |
| 日额度耗尽 | 今日额度已用完，剩余评论将在后续额度内继续处理 |
| 评论未研究 | 未研究；若排队则次级说明已排队 |
| 当前有效分析/no_signal | 已研究 / 未提取到研究信号；no_signal不是失败 |
| 结果不再适用 | 研究结果待更新；旧版说明当前不能直接沿用的原因 |
| 旧结果+更新失败 | 已有结果，本次更新未完成；查看旧结果及失败原因 |
| 部分字段接纳 | 结果已部分保存；说明未完成字段，不给整条“分析失败” |
| 语义不确定 | 暂时保持独立；显示实际下一比较条件或已到自动复核上限，不空承诺马上处理 |
| 自动检查通过 | 通过当前自动检查；展示样本/指标，不显示“研究准确率” |
| 回归未测/失败/不足 | 未执行 / 本次比较未完成 / 可用配对样本不足；不能写“无差异” |
| 没有可比基线 | 暂不判断增长；已有原声可查 |
| 诊断未记录/到期/来源受限 | 本次未保留输入输出 / 记录已到期 / 当前来源不可读取；安全摘要可保留 |
| 来源未知/数字未知/已知零 | 分别使用缺失原因/未知/0，不用空字符串统一代替 |

禁止显示虚构模型内心思考。事件流只显示实际调用、工具（确实使用时）、阶段、可公开返回摘要和接纳结果；未开启工具/思考就如实显示未使用。

## 6. 页面验收矩阵

| ID | 完整操作 | 通过条件 |
|---|---|---|
| U01 | 概览→设置自动研究→保存→返回概览 | 未选任何评论也可完成；启用状态/下一截点来自回执；读取页面零外发；无新一级导航 |
| U02 | 原声检索→详情→已有结果→原文/父评论/作品 | 保持紧凑密度、证据完整、结果与任务双轴；不同资格有真实提示 |
| U03 | 第一页50+第二页50→改变页大小/排序→定向研究→切重研→取消 | 跨页选择不丢；真实范围变更明确清空；预检实时更新；确认是当前版本；取消无新调用 |
| U04 | 用户问题→自动未归并表达→具体问题→原声 | 无强制人工待判；已有表达可查；名称/依据/版本可追溯，不造空洞名称 |
| U05 | 运行→部分失败→某次请求→输入/返回/拒绝字段→返回 | 先看失败影响和恢复行为；7→5真实可见；expired/not_recorded/restricted不混淆；无假思考 |
| U06 | 设置→编辑规则→草稿→候选→版本比较 | 无额外技能中心；排队/运行/不足/退化/通过有对应状态；pair数量与成本unknown诚实 |
| U07 | 变化页分别进入回填/版本变化/无基线/合格变化 | 对前三者不显示上涨结论；后者可回计算与原声；不以选择batch作为日常入口 |
