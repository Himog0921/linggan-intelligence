> 状态: 权威当前
> 最后核对: 2026-10-13
> 适用范围: 本机开发入口 /login、Anatomy 装饰动画与进入既有工作台的导航
> 事实来源: Mog 确认的 Login V2、装置说明和本对话提交推送合并部署授权；当前 main 路由
> 冲突时以谁为准: 用户最新确认、实际代码与运行；本页不授予认证、数据库或外部操作权限

## 用户结果与授权

Mog 已确认本对话的 Login V2 与 Anatomy 动画，要求提交、推送、合并 main 并部署；明确开发期无需接入真实认证。实施与集成由当前 root 执行，不另派 reviewer 或其他 Agent。Issue #410 记录本交付包。

开发期首页转到 `/login`，校验邮箱格式与非空密码后只导航至既有 `/corpus` 入口。页面明确显示开发模式，不能声称登录认证成功。原有工作台深链接继续直接访问；没有账号权限门或持久登录会话。

## 表面、状态与依赖

| 表面 | 状态/含义 | 来源与验收 |
|---|---|---|
| `/`、`/login` | 固定布局登录页；与数据库就绪无关 | Rust 路由测试、正式本机 GET |
| 表单 | 待输入、格式错误、正在进入、导航失败；均不是认证回执 | 原页面校验与开发期授权；浏览器空提交、密码显示、回车、焦点与导航 |
| 记住邮箱 | 用户主动勾选才存邮箱；密码不持久化或发送 | 浏览器存储与网络检查 |
| Anatomy 装置 | 16 秒合成装饰流程；不表示真实材料正在处理 | 纯时间模型、几何与遮挡审计、整轮浏览器运行 |
| 移动/减少动态/后台/离屏/失败 | 不挂载、完整静态帧、暂停续接或原图降级 | 断点、媒体特性、visibility、IntersectionObserver 与失败检查 |
| `/corpus` | 原工作台入口与原有业务读取 | 导航后实际页面与深链接 GET；不改其数据库合同 |

依赖仅为既有 Rust Router、浏览器原生 DOM/SVG 与生成时 Anatomy 工具。独立 `login.rs` 不读取数据库或设置 Cookie；模板不加载外部资源。共享接缝为根路由、原根路由测试和文档索引，当前最新 main 为基线，不吸收共享目录的未提交改动。

## 设计来源与局部例外

已读 AGENTS、文件治理、UI 执行合同、设计治理、LIDS 入口与当前运行 Token/材料/语言规则。五层表达：用户批准的登录专属变量 → 原页面输入/按钮语法 → 表单与 SVG 装置 → 固定分栏 → 登录页。装置为 L3 装饰，不承载实时数字或系统状态。

用户明确要求保留获准 HTML 的品牌、布局、背景、颜色、文案、表单与响应式。因此本页保留其局部视觉变量与 Anatomy 材质参数，作为 LOGIN-ANATOMY-001 的页面级例外；不修改全站 LIDS Token，不晋升新主题或组件，不声明全站合规。开发模式提示及进入行为是本次部署集成所需的局部文案变化。

## 文件与再生

- `apps/api/src/local_web/{login.rs,login.html}`：独立页面组合与生成 HTML；`local_web.rs`、`local_web/tests.rs`：仅入口及其回归。
- `scripts/login-anatomy/`：维护的页面输入、模型、几何、遮挡、样式、动效和构建/验证源；运行说明与 Anatomy MIT 许可。
- 本页、总/设计索引、LIDS 迁移记录、生成物登记和当月进度：来源与验证留痕。
- 生成 `login.html` 必须执行构建，不手工修改。截图与审计 JSON 留在本任务忽略的临时目录，不入 Git。

## 验证与边界

先验证路由、生成一致性、13 个姿态和浏览器表单/生命周期，再推送 PR；按 Mog 当前授权合并并由最新 main 的受控 installer 发布。正式本机核对 API/巡检/媒体三个 PID、cwd、执行文件与 revision，以及 /login 动画和进入工作台路径。

不执行 migration、修改模型/采集政策、调用模型、重载插件或访问平台。真实认证、远端生产环境和 Mog 对正式运行页的视觉验收均不由测试通过推定。共享冲突、待迁移 schema 或 drain 失败时保留证据并停止相关发布步骤。
