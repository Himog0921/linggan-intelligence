## 状态词典与数据含义

| 状态 | 用户含义 | 后端／UI接缝与不得暗示 |
|---|---|---|
| 首次读取 | 正在取得当前范围 | `aria-busy`；没有数字时不先写0 |
| 空结果 | 当前明确筛选没有返回可见原声 | 保留范围及筛选；不代表平台或现实没有讨论 |
| 未配置模型／历史结果仍在 | 事实可浏览，不能开始新的受控分析 | 模型状态与历史语义结果分开；未分析需求数为未知 |
| 部分分析／部分失败 | 部分原声已有有效结果，其余有独立状态 | 不能整包清空成功，也不能把失败补成“无信号” |
| API失败 | 本次读取或动作失败 | 保留已有数据及更新时间／错误提示；不回退HTML演示数据 |
| 受限来源／上下文撤回 | 此来源或依赖它的派生不再具当前访问资格 | 服务器readable与context gate控制；不能靠前端隐藏仍传原文 |
| 0赞／未知赞 | 0为真实数值，未知为未取得 | `0`／`—`；极大数缩写保留精确值访问 |
| 日期未知／相对时间 | 无可靠绝对日期；相对文字属于采集时 | 发表时间过滤报告排除数，不偷换首次观察时间 |
| 窗口不可比 | 可显示计数，不能得出升温或下降结论 | 覆盖、来源、模型／规则、完整日、人工整理与迟到材料各有原因 |
| 原文变化／人工决定失效 | 旧人工意图保留，当前语义需要复核 | `sourceChanged`与active分开；收藏不会重新激活旧标签，模型不得绕过旧锁 |
| 暂停／在途返回 | 停新派发；已发送调用仍可能产生费用与结果 | 暂停不宣称已取消远端计费；回执可接纳 |
| 未知用量／超上限积压 | 用量未确认或任务暂未派发 | 保留预算预留／冻集；明确继续与核对入口，不自动无限重试 |
