# 评论研究：密度、统一控件与检查器续修清单

> 状态: 一次性报告
> 最后核对: 2026-10-22
> 范围: `/corpus/comments` 的用户评论与概览视图
> 事实来源: 2026-10-22 用户提供的真实页面截图、当前 React 源码与 `COMMENT-STUDY-PRODUCTIZATION-001`
> 冲突时以谁为准: 用户最新确认、`AGENTS.md`、运行代码与页面规格
> 适用范围: `/corpus/comments` 的用户评论、评论检查器与概览观察视图

## 问题与目标

截图显示评论表行高过大且点赞列未与原声垂直居中；搜索和选择控件未与证据库的既有阅读控件一致；评论检查器越过 Context Bar，并展示了重复、弱价值信息；概览右侧图表没有用满与左侧统计相称的可用高度，两个纵轴标题也没有与对应统计组对齐。

本次把页面收束为紧凑的“证据阅读目录”：表格保持 48px 单行、数值和文本同一基线；查询与显式选择复用证据库的视觉语法及原有行为；抽屉只呈现可回证的评论、来源语境和研究事实；概览只调整布局高度和标签对齐，不改统计、时间或信号口径。

## 表面、状态与依赖

| 表面 | 正常态 | 关键状态 | 不变量 |
|---|---|---|---|
| 评论目录 | 48px 单行表格 | 搜索、筛选、选择态 | 点赞未知仍为 `—`；不改排序/资格/API |
| 搜索与选择 | FIND 输入与“选择评论”入口 | 有输入、清空、选择、退出选择 | 筛选仅由“应用筛选”提交；跨页选择语义不变 |
| 评论检查器 | Context Bar 下方的内容区抽屉 | 打开、关闭、加载/缺字段 | 不覆盖主导航；Esc/关闭恢复阅读上下文 |
| 概览观察 | 左统计、右图表视觉等高 | 7/28/56 天、图表/表格 | 数据、坐标口径、下钻不变 |

依赖为现有评论查询、URL 深链、`FindField`/`SelectField`/按钮原语、共享 App Shell 的 Context Bar 尺寸变量和观察序列数据；本包不增加接口、数据库、采集、模型或研究执行。

## 实施约束

1. 评论、作品、研究状态和标签在表格内单行截断；点赞列使用表格数字对齐和垂直居中，行高不因 `3.5万` 等格式变化。
2. 输入与选择入口使用证据库的既有控件语言；选择态继续是显式进入、退出即清空，不能因样式修复改变已选集合。
3. 检查器顶部从 Context Bar 下沿开始；保留原声、互动/观察事实、所属作品、父语境、确有差异时的清洗说明，以及有结果时的研究记录/关联信号；删减重复标题、空值和泛化占位。
4. 观察图表提高其可绘制高度；`评论` 与左侧“可研究评论”标题、`信号` 与“当前研究信号”标题处于同一纵向位置，且不改变 SVG 数据尺度。

## 非目标与验证

不改变评论数据、点赞含义、研究历史、筛选 URL/API、批量研究动作或概览指标。验收要求包括相关前端回归、类型检查、lint、构建、LIDS/治理检查及隔离浏览器桌面视口核对；合并、部署与业务验收不在本变更清单内。
