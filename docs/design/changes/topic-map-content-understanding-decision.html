04

先接入共享理解，再补齐完整工作链

  1. 核对覆盖与接入确认哪些材料已有可用 Core，哪些缺材料；读取和版本绑定复用上游，不重新理解同一篇。
  2. 跑通一组主题按已确认 B 实施：作者内容自动形成方向并归并；评论挂靠已有方向，未匹配评论保留。
  3. 补齐研究与交接场景、讲法、五阶段旅程、来源、我方对照；带依据的角度进入运营选题池并被创作读取。
  4. 完成增量与上线补任务恢复、失效来源、性能与全页面验收；配置启用、部署和业务验收分别确认。
为什么不能把候选标签直接当主题？

同一个意思可能有不同标签；同一个标签也可能包含不同问题。主题还需要跨篇比较、清楚定义和边界。Core 的主议题与候选标签提供依据，不自动取得正式主题身份。

为什么不等所有 L2 能力完成才开发图谱？

L1 已承担基础理解。L2 针对具体问题深入，自动路由与补图仍是后续能力。图谱基础可以先消费合格 Core；遇到确实缺失的关键信息，再定位到上游遗漏或按需深化，不让每篇材料都重复付费分析。

哪些既有决定保持不变？
  • 保留主题概览、五阶段旅程、内容格局、来源与我方对照。
  • 方向由系统自动发现与归并，人工可纠偏；结构调整先看影响。
  • 作者内容与评论分开，互动量不证明效果，未知不写零。
  • 原材料继续可读，不以摘要替换；不新增第二份基础理解。
