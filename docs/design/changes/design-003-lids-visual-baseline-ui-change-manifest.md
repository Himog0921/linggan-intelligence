## 4. 逐项变更与理由

| 变更 | 变更前 | 变更后 | 理由 |
|---|---|---|---|
| 画布 | 暖灰 `#ecebe6` | 纯白 `#ffffff` | Mog 明确选择纯白并否定暖灰 |
| 签名色 | 橘红 `#ef4f25` 与玫红 `#e8003f` 并存 | 仅 `#ef4f25` | 两色明度接近但不同，同屏产生脏感 |
| 语义色 | 四轴、缺 dot、为暖灰底调制 | 五轴对称，为白底重新校准 | 状态需由颜色承载；未知需要专属最弱角色 |
| 状态标签 | 浅底 + 细边 + 淡字 | 实心填充 + Ink 文字，无边框 | 浅底会稀释 `#eaaa05`；描边压低饱和并推高线条数 |
| 按钮 | 29px，1px 边，无反馈 | 40/43px，2px 边 + 硬阴影 + hover 位移 + 禁用态降级 | 统一按钮语言；未接通能力必须一眼可辨 |
| 线条 | 194 条可见边框 | 约 100 条，几乎全在可交互元素上 | 六原则；边框成为可供性信号 |
| 上下文行纹理 | 32px 划线网格 | 14/56px 双层点阵 | Mog 要求纹理与未来感；点阵在同等重量下更安静 |
| 页头 | eyebrow + h1 + 说明段 + 统计 + 动作 | h1 视觉隐藏，统计入上下文行，动作入搜索行 | 页面身份此前被陈述三次；空间还给列表 |
| 排版 | 英文主语，中文次要，7–10px 混排 | 中文 sans 主语，英文 mono 标注，标注 ≥11px | Mog 要求中文优先；原 7px 低于可读下限 |
