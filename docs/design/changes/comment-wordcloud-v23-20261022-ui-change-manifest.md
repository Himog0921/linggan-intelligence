## 显示基准

- **不再显示**“评论观察与研究写入”“评论柱状 · 信号下探走势”两段占位标题；图例和时间范围置顶。
- 左数据列保留 17,176/885/1,020 等真实服务端读数和“新表达待建档”入口，统一缩小卡间距。右列统一趋势、语言云、Top10，目标紧凑桌面首次可视区约 500px；禁止硬裁切词语、纵向溢出时局部滚动，窄屏自动分列/堆叠。
- 黑色评论柱；橙红信号曲线 *在横轴上方*，面积向下渐变至基线，不将曲线放到轴下。左右计数刻度独立；覆盖小方轨保留“完整/部分/无记录”。
- 词云不旋转，字体权重按五级 LIDS 文字 Token，黑白为主、少量红色，单词点击和 Top10 保持同一选择。显示“不是问题判定”。
- 点击当前高频词的“查看原声”仅显示稳定引用，点击后打开现有评论详情及父语境。错误、超时和来源失效要显示真实状态。

## 服务器统计口径

- GET `/api/local/comment-study/word-cloud?domain=UUID&days=7|28|56`；返回算法版本、范围、时区、样本界限、短语列表、每词不同评论数/覆盖作品数和最多三条评论引用，严禁返回正文。
- 首次合格观察日（Asia/Shanghai），同一稳定作品+评论身份取最新可读清洗版本，仅使用原 Catalog Gate 的合格 reader 评论。一次评论一个短语只记一次；多个词可以出自同条评论。
- 统计最多 20,000 条且每条截取前 800 字；当 eligibleCommentCount > processedCommentCount 必须清楚说明只是已处理样本，不做未证实同义归并和 AI 需求强度推断。
- 类别只来自精确短语词表；候选词没有类目时归 unclassified，不为凑齐页面填演示词条。
