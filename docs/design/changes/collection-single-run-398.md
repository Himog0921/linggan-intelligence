## 表面与表达

单次表单为居中纵向输入、两种来源选择、独立领域/排序/上限/评论范围、固定底部黑色主按钮。语料勾选入口直接进入精确集合。失败保留输入和幂等身份；关闭返回焦点/原筛选。临时来源与长期周期分开，服务端验证不能仅靠 UI 禁用。

任务一条用户工作一行；五个完整筛选、搜索、右侧黑色主按钮。抽屉按原 Demo 的进展/成果视图、三组真实读数、阶段行、展开宽度、固定成果入口实现；成果优先，执行记录、冻结资源、全部 Attempt/Package/Receipt 和对账在诊断折叠层。已结束、有缺口、人工暂停、资源等待不合并为同一状态。

领域下拉打开居中领域列表，含当前标记、真实目标数/状态、进入/编辑/暂停；编辑只放一个领域组件，原研究目标、关系维护和统计都可达。管理组件继承原页面 Token，原全部表单走原接口，失败不丢草稿，关闭不改变底层 URL。工位从面包屑右端进入完整原页面，任务中的实际工位链接定位行并保留返回任务。

仅 Collection 局部构成与 Corpus 采集上下文变化；不改全站 Token，不新增框架。新增颜色/字体/间距沿用现有 Token；表单 560px、领域弹窗 900px、抽屉 min(1120px,74vw) 使用已批准 Demo 的局部比例，390px 下分别为 358/342/390px。标题/正文/说明为 17/13/12px，真实读数为 27px 等宽数字。五状态条与搜索工具栏分行；更名编辑和目标状态列仅做局部布局修复。原 Demo 模拟推进、恢复登录和旧门槛未搬入正式产品。
