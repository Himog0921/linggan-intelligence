# PAGE-MODEL-AI-SETTINGS-001

> 状态: 权威当前
> 最后核对: 2026-09-06
> 适用范围: Issue #169 的模型与 AI 设置页及评论研究的设置入口
> 事实来源: Mog 四区设置决定、LIDS v7、model-ai-settings 产品合同
> 冲突时以谁为准: 用户最新决定、真实权限/数据与 LIDS

强度 L1，Settings / Governance Pattern。一个配置页面和一个复用的供应商弹窗；供应商行内展示当前版本所属模型，页面保留评论默认选择。没有 Tab 和四区左侧索引，调用限制、已有评论处理和记录按需展开。页名留在共享 Context，语义 h1 隐藏。白底、边界线、中文状态、Serif 原声，不引入 Three.js 或智能内核运行大屏。

三秒内能知道是否配置模型、凭据存放方式；五秒内能添加连接或查看失败。连接和模型列表使用窄状态列、明确按钮，不把“已保存”上色为“已连通”。额度和调用以真实数字/未知显示，不显示虚构金额。配置版本折叠查看，普通流程无需理解表名、Pi 内部会话或 SQL。

| 表面 | 空/失败 | 正常与行动 |
|---|---|---|
| 全页 | DB 未初始化明确指出 0039/0040，结束加载并禁用依赖写入；其它失败提供刷新 | 供应商列表、默认选择；高级调用限制与已有处理记录折叠 |
| 连接 dialog | 地址/凭据未填、Keychain 失败、版本冲突保留表单 | 名称、协议、API 地址、密码、模型 ID；预览最终请求地址；保存并测试或保存连接并获取模型均在同一弹窗，成功保存清理凭据，测试失败保留其它字段 |
| 模型 dialog/测试 | 无连接、未知准确 ID、调用失败/结构失败分开 | 手动 ID/目录候选；合成能力测试，未合格不能存用途默认 |
| 用途表单 | 过期 configRef 提示刷新；不覆盖当前新版本 | 范围、次数、秒数及累计预算；保存不启动分析 |
| 来源选择 dialog | 空匹配、来源失效、预算不足明确提示 | 搜索和指定原声；一条试运行或多条历史补跑，确认后才入队 |
| 自动处理 dialog | 无模型时禁用；停止后保留历史 | 明示新来源时间起点、数量/预算、替换旧授权后果 |
| 恢复计划 dialog | 过期修订提示刷新；连接仍停用时不会派发 | 明示沿用来源、配置、次数、额度；当前自动计划沿用启用时间，被替代计划仅接续已有工作 |
| 重复来源回执 | 新排入为 0 不显示再次处理成功 | 提供实际所属计划链接；按指定计划读取和定位，不受最近 50 条限制 |
| 运行表格 | 无心跳、循环错误、余额不足、连接暂停不同 | 待处理/执行中/结束数量、token 已知/未知、来源与配置回溯 |

原生 dialog 提供取消和 Esc；提交时禁用，重复请求使用同一业务引用，错误保留输入。敏感输入不用 localStorage/sessionStorage，关闭后清除。按钮、select 和输入使用键盘焦点；主验收视口 1440 CSS px，低宽度允许表格滚动。已有打开页须刷新才更新状态，不声称服务端实时推送。

共享 Header 仅在原系统功能槽把未实现 command 按钮改为个人菜单→设置。这个最小适配由本次用户明确需求授权，见 [变更清单](../changes/model-pi-001-ui-change-manifest.md)。原来的一级导航、双语历史欠账、首页职责保持原范围，不借此重建壳层。
