# PAGE-MODEL-AI-SETTINGS-V1-001 · 模型与 AI 设置

> 状态: 权威当前
> 最后核对: 2026-09-10
> 适用范围: V1 模型连接、默认研究模型、embedding 配置和调用账本
> 事实来源: COMMENT-RESEARCH-RESET-001、LIDS、当前 local API/UI
> 冲突时以谁为准: 用户最新确认、AGENTS.md、真实运行/代码/数据合同

## 页面任务

用户应能在一个页面完成：保存连接、用最小 synthetic JSON 验证模型、选择 V1 默认研究模型、保存/验证 embedding 配置，以及看懂近期调用是否成功。它不提供旧 daily、backfill、trial、automatic plan 或评论批次操作。

## LIDS 组合

- 消费共享 L1 shell、Context Bar、表格、状态文字、dialog 与 `--lgi-*` token；不创建新色彩/排版/间距体系。
- 分区顺序固定为连接、V1 生成模型、embedding、最近调用；默认研究模型和 embedding 的角色在文字上明确分开。
- 状态同时有文字和图形/布局，不只依赖颜色；故障详情仅显示受控 failure code 与下一步，不泄漏 endpoint secret 或评论。
- 页面保存/测试动作保留 loading、成功、失败和关闭后的明确焦点；不使用 hover-lift 或额外 motion。

## 数据诚实性

| 情况 | 表达 |
|---|---|
| 没有连接或模型 | “先保存并测试一个研究模型” |
| 生成模型未测试/测试失败/已停用 | 分别说明，不能选为 V1 默认 |
| embedding 未就绪 | “本轮不能完成问题归并和发布”，不改写为研究失败 |
| 最近调用失败 | 显示阶段、失败代码和是否可重试；不把旧结果称为本次成功 |
| 无调用 | 明确尚未有 V1 调用 |

保存设置和 test 都不会外发真实评论；真实研究仅由评论研究页的“开始研究”发起。调用账本是回执，不是新的研究入口。
