## 1. 身份与边界

- **页面规格 ID**：PAGE-CREATION-ASSETS-001。
- **用户任务**：运营写手把一篇稿子写到可以复制发出；写手与 Mog 维护写稿用的资产。
- **明确非目标**：不展示 Demo 的“使用路径”“体验清单”；不做选题池页（DEC-0009 另一条线）；不做语义检索；不在页面里选定任何编辑器库。
- **不能变成**：第二事实源（检查结果不存为稿件状态，样板统计来自稿件与回收数据，不手填）；权限旁路（S0 完成后所有读写经服务端成员会话，隐藏按钮不算保护；S0 之前只靠“仅本机单人使用”，不得对第二个人开放）；第二套视觉语言（只用 `--lgi-*` Token 与共享组件）。
- **入口**（Mog 2026-10-28 选 A）：**保持在「运营」之下**。一级「运营」→ Z03 左栏「数据 / 创作」→ Z02 面包屑带三级页面分区「写稿 / 材料桌 / 资产库」；资产库内六类资产放在页面左侧的“资产类型索引”（Split Evidence Inspector 的 Object Index），不再增加第四级导航。「创作」入口对所有成员可见与成员登录（S0）同时进行；在此之前保持现状，只对管理员显示（`OpsFrame.tsx:22`、`OpsPage.tsx:26`）。未采用的一级「创作」方案（需要改一级导航登记、页面注册表、测试与 LIDS 外壳规范，属共享标准变更）试用后再评估。
- **领域**：沿用面包屑里的领域选择器，不默认选第一个领域；失效领域不读取（现有 PAGE-CONTENT-WORKBENCH-001 的规则继续）。

## 2. 公共状态词典

所有页面共用，禁止互相替代。按[数据边界](../lids/data-boundaries.md)，未知不写成零。

| 状态 | 触发 | 用户应理解 | 禁止暗示 | 下一步 |
|---|---|---|---|---|
| 空 | 读取成功，集合为零 | 现在没有这类内容 | 不等于“读取失败”或“没有权限” | 就地给创建入口 |
| 加载中 | 请求在途 | 正在读取 | 不显示旧结果冒充新结果 | 可取消/离开 |
| 读取失败 | 请求失败，有明确答复 | 读不到，原有输入仍保留 | 不显示为空 | 重试 |
| 结果未确认 | 请求没有得到答复 | 写操作可能已生效 | 不得自动重发 | 沿原请求身份核对 |
| 无权限 | 无成员会话，或角色不允许 | 需要登录或需要权限 | 不显示为空或错误 | 去登录；说明谁能开 |
| 受限 | 来源被撤回或受限 | 原文被遮断，保留身份与说明 | 不显示原文，也不显示“已删除” | 换一份材料 |
| 部分 | 一部分可读 | 能读到的已显示，缺的单列 | 不显示为“完成” | 补齐或接受 |
| 待审 / 待本人确认 / 待机构确认 | 资产尚未被有权限的人确认 | 还不能被稿件或成品包选用 | 不显示为“可用” | 去审核 |
| 外发未授权 | 开稿或复刻需要外发，但设置里未授权或已撤回 | 现在不会调用模型 | 不显示为“失败”或“已调用” | 去设置（只给入口，不在业务页改授权） |
| 额度已用完 | 本月创作 AI 已达设置页的月度上限 | 现在不会调用模型，上限用尽 | 不显示为“失败”，也不暗示授权被撤回 | 去设置调整额度（只给入口） |
| 保存状态 | 沿用现有：已保存 / 未保存 / 保存中 / 结果未确认 / 版本冲突 / 保存失败 | 以服务端修订为准 | 不用本地计数冒充已保存 | 比较版本并选择保留 |

“无权限”在 S0 完成前不会出现（第一版单人本机使用）；页面从第一版起就按此状态设计，避免 S0 时返工。

## 3. 写稿

**模式**：Research Workspace（L2）。区域：左“今日稿件”队列（Z04-B 左栏）｜中编辑区｜右四页签（检查、素材、标题、预览）。窄于 1100 时右栏改为抽屉，按钮显示“检查 · 必改 n”；窄屏时队列也收为抽屉；375 宽单列。**不缩字、不拆行、不静默丢字段**（LIDS 容量规则）。

| 区域 | 内容 | 来源 / 合同 |
|---|---|---|
| 队列 | “选题中 · 还没开稿”的选题框，再列稿件；每条：标题、账号、复用/试新、来由、状态（必改 n · 提醒 n / 可以复制 / 已复制待发布 / 已发布 · 回收中） | 稿件扩展、选题框；状态由检查实时算出 |
| 稿件头 | 账号选择、身份芯片（无关系·不植入 / 身份待确认 / 陪跑营学员·简介已写明 / 简介没写明）、“背后无真人”、选题框跳转（或“＋ 补一个选题框”） | 账号身份；选题框 |
| 选题意图行 | 意图、复用/试新、来由、样板与风格芯片；与我方爆款意思接近时的“关联成同一选题”（依赖选题池，第一版不显示） | 选题框 |
| 封面与标题 | 封面预览（带“AI 作图/实拍”标）；封面大字（字数 n/10）+ 候选 + “换一批”；笔记标题（字数 n/20）+“复制标题” | 稿件、标题 skill |
| 正文 | 每段一个文本框，段首标签是样板步骤名；段下一行显示来源（经历库 · 编码 / 来自材料 · 用作某用途 / AI 起稿）与“换个说法”“换一段经历”“后面插入经历”“删除”；经历位显示“这里需要一段真实经历”及“从经历库选 / 发问题给本人” | 稿件段落；经历库；换个说法见 §5 |
| 衔接位 | 五种状态：不植入（无关系/本篇不植入）、身份待确认（三选一）、简介没写明（建议简介 + 复制 + “我已改好简介”）、可用（衔接句文本 + “换一句 n/m” + “不植入”）；位置在“观点”之后、“收尾”之前 | 账号身份；衔接句库；规格 S-1–S-7 |
| 话题 | 话题标签，回车添加，重复的标红 | 稿件 `tags` |
| 底栏 | 检查摘要（必改 n · 提醒 n）、一行说明、“存为样板”、“复制到小红书”（有必改则禁用并说明“必改清零后才能复制”）、“标记已发布” | 规格 A.2、A.4 |
| 已发布稿 | 回收卡：7 天阅读输入、判定（未填 / 未到 5,000 / 爆款 + “存为样板”“进复用候选”） | 运营发布记录与阅读量报告（不复制）；“进复用候选”等选题池 |

**右栏**：

- **检查**：三组“必须先改 / 提醒 / 发布时记得”，每条有标题、说明、可点的修改动作（见规格 A.2），点击条目定位到出问题的段落并选中命中的字（文本框内无法给文字上色，见小样报告）；底部说明“复制时自动补空行、去重复话题”。
- **素材**：选题框摘要与其材料卡（用途与思路）、本号经历（已确认/待本人确认、别的稿子讲过几次）、本号对应身份的衔接句、人设事实、样板步骤、产品事实卡、风格，后四项折叠。
- **标题**：第一版两块切换。①我方爆款（真实阅读量，未填显示“未填”）；②标题 skill 入口（未导入时显示“待接入”）。“不限领域的高赞标题，每条附 A娃场景版本”第一版不做（Mog 2026-10-28），有采集数据后再加第三块，届时没有数据时为空状态、如实说明，不放示例。疗效承诺的候选标红提醒“有疗效承诺”，仍可选用（词表未校准，不拦截，规格 R-W11）。
- **预览**：手机样式预览与“复制出去的文字”（空行里是“ㅤ”）。

| 用户动作 | 前置条件 | 回执来源 | 页面如何区分 | 不得宣称 |
|---|---|---|---|---|
| 复制到小红书 | 必改为 0 | 客户端剪贴板；复制成功后写“已复制”回执（稿件修订、规则集版本、事实卡修订、提醒与提示编号） | 复制失败时给“手动复制”弹窗；回执未确认时保持“结果未确认” | 不得宣称已发布 |
| 标记已发布 | 状态为已复制 | 在运营发布记录里登记（需要链接）；成功后才进入回收 | 登记中 / 失败 / 未确认分别显示 | 没有登记不得显示“已发布” |
| 存为样板 | 稿件有正文 | 创建待审样板（只存结构）；回执含编码 | 待审状态明示 | 不得显示“可用” |
| 保存 | 无输入法组合中 | 服务端修订回执（沿用现有 `requestId + expectedRevision`） | 沿用保存状态词 | 本地状态不是保存 |

**输入法与撤销**：所有输入框、文本框在中文组词期间不提交、不自动保存、不抢焦点（沿用现有保护）；撤销按“一次输入法提交 / 一次采用 / 一次换个说法”为单位，采用的撤销只还原被采用的那一段（该段此后没有再改时），见小样报告。

## 4. 材料桌

**模式**：Research Workspace 的 Evidence Canvas（L2）。区域：左“找材料”面板（可收起）｜中画布｜右检查器（选题框或材料卡）。

| 区域 | 内容 | 来源 / 合同 |
|---|---|---|
| 找材料 | FIND（C16，250 毫秒防抖、输入法保护）+ 来源筛选（全部 / 历史爆款 / 评论 / 跨行业标题 / 经历）+ 结果卡（“放到桌上”或选中选题框后“放进框”）；结果上方如实写明“共 n 条”和检索范围（字词检索、有界，不称语义检索） | 现有材料浏览接口；经历来自经历库（只列已确认） |
| 画布 | 选题框（标题可改、账号、样板、材料数、“用这组材料开稿 · n 个账号”）与材料卡（种类、内容、用途芯片、思路）；工具：找材料、＋便签、＋选题框、缩放、看全部；提示“拖动空白处移动画布，⌘/Ctrl＋滚轮缩放，双击空白处加便签” | 选题框、材料卡；小样：纯 DOM，400 张以内 |
| 检查器·选题框 | 选题、“这篇想说什么 · AI 先读这段”、给哪些账号写（多选，已开稿的标注）、样板、材料列表（每张可改用途和思路）、**“AI 会看到的内容”**（折叠，显示字数）、已开稿 | 规格 A.5 |
| 检查器·材料卡 | 原文、来源、用途（七选一）、思路；别账号的经历给出说明“只会用在某账号的稿子里；给别的账号开稿时会留空位”；“移出桌面” | 材料卡 |

- **键盘与指针**（Demo 只覆盖指针，这里补键盘）：每张卡与每个选题框可聚焦；方向键移动 10px（Shift 为 50px）；Enter 打开检查器；Delete 移出；缩放有按钮；平移有“看全部”和滚动条之外的键盘路径。**待在小样之外用真机与读屏验证。**
- **状态**：空画布（引导：从左边找材料、点“放到桌上”）；搜索无结果（说明是“当前检索范围没有命中”，不说“不存在”）；材料来源变化/受限（卡上标明，受限时遮断原文，保留身份与说明）；开稿进行中（按钮显示“起稿中…”，沿用请求身份）；开稿结果未确认（核对原请求，不自动重发）；外发未授权（“用这组材料开稿”禁用，说明“需要先在设置里授权模型与外发范围”）；**无账号/账号身份未确认**（仍可开稿，衔接位按规格给必改）。
- **一题多号**：选中多个账号后一次开出多篇；开头互不相同；别账号的经历留经历位（规格 R-D3、R-D5）。开稿是一次服务端命令（同一事务创建多篇稿件并关联选题框），请求身份可重放。
- **不展示**：材料桌里不显示点赞数用于排序（现有合同不向模型发点赞；展示层可按已返回候选的赞数查看，另行声明）。

## 5. 按段落“换个说法”与采用

- 触发：在某段下点“换个说法”，或选中文字后点“改写选段”。候选显示在该段下方，只替换这一段（或选中的那段文字），其他段的改动都保留。
- 采用：预览 → 可手调 → 采用；采用后可“撤销这次采用”。目标段在候选生成后被改动过则该候选标为过期，可比较、不可直接覆盖。**别的段变了不影响采用**（审计 C6 的建议 B，需要服务端按目标段落核对）。
- 外发：在设置页统一授权额度后一键换（Mog 2026-10-28）；授权前保持现有逐次确认（预览—执行）。每月上限默认 100 美元，用尽后按钮禁用并说明（见状态词典“额度已用完”）；开发期间只用合成适配器。
- 结果：候选与采用都来自服务端回执；失败保留输入，可继续手写。

## 6. 资产库

**模式**：Split Evidence Inspector（L2）：左资产类型索引｜中列表或表格（Corpus Explorer / 含搜索的列表 B）｜右详情检查器。表格行 44px、名称列 144px，列宽不足时局部横向滚动，不缩字、不拆行（ALIGN-LEDGER-008）。编码、版本、时间用等宽数字字体，其余全中文。

| 资产 | 列表内容 | 详情与动作 | 特有状态 |
|---|---|---|---|
| 人设事实 | 账号切换；身份区（有无真人开关、与机构关系单选、简介是否写明开关 + 建议简介复制）；事实表（事实、来源、用过几次、状态） | 补一条事实；新旧冲突时弹窗“保留原来的 / 以新的为准” | 推断待确认、缺 |
| 经历 | 卡片（账号、标题、正文、标签、来源、日期、讲过几次） | 采集一条经历（本人口述录入或问题发给本人）；“本人确认”并记录同意；撤回 | 待本人确认；背后无真人的账号不采集 |
| 产品事实卡 | 一张卡：规范名称、可用叫法、禁用叫法、是什么、适合谁、能讲的、不能讲的、必带提示、确认状态 | 编辑 / 保存 / 取消；改后检查跟着变 | 待机构确认 |
| 衔接句 | 三列：陪跑营学员家长 / 陪跑老师 / 无关系（不放衔接句）；每句显示编码、状态、用过几次、入库检查提示 | 审核通过、停用、启用、“用到当前稿”；新增一句（实时检查，入库为待审） | 待审、待改、停用 |
| 样板库 | 表格：编码与版本、名称与标签、要几段经历、来源、状态、用过、平均阅读、爆款；FIND（编码/名称/标签）+ 来源筛选 + 状态筛选 + 排序（编码 / 用得最多 / 平均阅读最高） | 详情：写法步骤、版本记录、统计、防撞车；“审核通过”“用它开稿”“停用 / 重新启用”；“导入样板” | 待审、停用（显示停用原因）、未回收 |
| 风格 | 卡片：结构、节奏、用词、不学、用在哪些账号 | “从博主蒸馏导入”（只取三类，经历与原句不导入） | — |

**导入样板**（弹窗，三步）：1 选笔记（来源：插件采集 / 证据库 / 粘贴链接）→ 2 复刻（原文只读一次，不存；显示进行步骤）→ 3 审核入库（原文结构只看每段作用，不存原句；可改名称与标签；“存为样板（待审）”或“审核通过，直接可用”）。已在库里的笔记显示“已在库里 · 编码”并可跳转。

**粘贴链接**（S3，Mog 2026-10-28 要做）：第 1 步里的链接输入框识别小红书笔记链接，按下列状态呈现，互相不替代：识别中（短链需要先解析出最终地址）；已在库里（给编码和跳转）；将派一次单篇采集（说明会占用一个工位，需要几分钟）；采集中；采集失败（保留原因，可重试）；受限（说明原文被遮断）；不是笔记链接（如实说明，不当作失败）。采到后进入证据库，与另两条来源走同一条复刻流程。该入口的服务器设计核对在 S3 开工前另写，页面细节随之补全。

**每个资产页的空、加载中、读取失败、无权限、待审状态**都按第 2 节词典呈现；样板统计未回收显示“未回收”，不显示 0；敏感资产（人设事实、经历、账号身份）对无权限成员显示“无权限”，不显示为空。

## 7. 证据库检查器里的“复刻成样板”

- **位置**：语料 → 证据库的作品详情右侧检查器（Split Evidence Inspector 的 Provenance Inspector 区），一个次级动作按钮（`ActionButton`，outline），与现有检查器动作同带，不新增第二个检查器。
- **前置**：该作品的研究底稿可读（`/api/local/work-resources/{workRef}/research-dossier` 是唯一读取入口）；外发已授权；成员有权限。
- **状态**：可复刻；已在库里（显示编码，改为“查看样板”）；底稿不可读或受限（禁用并说明原因）；外发未授权（禁用并说明）；复刻中（后台，沿用请求身份）；失败（保留原因，可重试）。
- **后果**：创建一个**待审**样板，不含任何原文；不改动证据库里的作品。
- **不得宣称**：复刻成功不等于样板可用；审核通过前不被成品包或开稿选用。

## 9. LIDS 采用清单与验收

- **Token 与材质**：只读 `lids_tokens.css` 的 `--lgi-*`；按钮 M2；焦点按 Q04 的 C 方案；不新造颜色、字号、圆角、阴影。
- **语言**：按 LANG-05，界面全中文；只有编码、版本、时间等技术标识用等宽数字字体；FIND 字标是已确认的装饰例外。
- **色彩之外的区分**：必改 / 提醒 / 提示用圆点加文字，不靠颜色单独传达；命中文字的选区高亮是浏览器原生高亮。
- **动效**：不用装饰动画；开稿进行中、复刻中只用既有的忙碌态；遵守 `prefers-reduced-motion`。
- **响应式**：1440、1100、375 三档；右栏与队列在窄屏收为抽屉；表格局部横向滚动。
- **验收场景**：规格 V1–V8；每个页面按第 2 节的状态逐一核对；键盘操作与中文输入法在真机复测；真实回执（保存、复制回执、已发布登记、样板创建）分别验证，不以本地成功代替。
- **本次证明**：只有文档与小样；**未证明**：任何真实页面、真实数据、真实输入法、真机与读屏、窄屏实机。
- **原先待决定的项已落定**（DEC-0012）：入口选 A；材料卡以用途取代分组；选题框为新对象；换个说法统一授权额度后一键换；资产可见范围在 S0 完成时生效。**仍待补的页面规格**：设置页的“创作 AI 额度”区、成品包队列（S5）、粘贴链接的细部状态，在对应切片开工前补。
