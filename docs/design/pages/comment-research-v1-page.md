# PAGE-COMMENT-RESEARCH-V1-001 · 评论研究 V1

> 状态: 权威当前
> 最后核对: 2026-09-14
> 适用范围: `/corpus/comments` 的评论研究 V1 页面、研究设置 modal 和五个独立读取视图
> 事实来源: COMMENT-RESEARCH-RESET-001、DEC-0003、Mog 2026-09-10 的上线与开发期重置授权
> 冲突时以谁为准: 用户最新确认、AGENTS.md、真实运行/代码/数据合同

## 用户任务与页面边界

评论研究将当前可读的评论转为可追溯的用户表达和稳定问题。它不是旧分析结果浏览器，也不是向量/聚类工作台。

| 视图 | 回答的问题 | 不显示的内容 |
|---|---|---|
| 概览 | 当前已确认归并的累计用户问题，以及最近可读取统计版本的冻结范围（若存在） | 把累计事实伪装为占比、排行或趋势 |
| 用户原声 | 当前哪些可读普通用户评论及其研究正文可作为证据，以及每条最新研究状态 | 已发布 ResultRevision、向量队列、embedding 状态 |
| 用户问题 | 哪些表达已被有依据地归并为稳定问题 | 仅凭相似度的自动合并 |
| 变化观察 | 相比前一完整周，哪些已定义问题发生可比变化 | 概览或问题表的副本 |
| 运行记录 | 哪轮冻结了什么、逐项如何结束、是否发布，以及是否续办历史待归并 Atom | 把失败写成没有发现或把续办 Run 写成新的统计窗口 |

研究设置保存一次 policy；之后“开始研究”直接冻结当前符合资格的评论。保存设置和进入页面不会外发评论。连续自动排程没有入口且必须保持关闭。

## 表面、状态与数据诚实性

| 状态 | 用户可见表达 | 禁止替代 |
|---|---|---|
| 研究模型未通过 V1 语义测试 | 说明当前默认配置的模型、已启用连接和最新 probe 必须同时通过 `semanticQualified` | 不显示为研究失败，也不允许保存策略或创建 Run |
| 向量未就绪 | 明确本轮不能完成问题归并/发布 | 不把技术队列放到原声行 |
| 无已发布统计版本 | 概览、用户问题仍显示已确认归并的累计事实；变化观察明确没有可读取统计结果；用户原声仍显示当前可读证据 | 不用旧结果或空数字伪装为新研究，也不把累计计数写成实时占比、排行或趋势 |
| 低覆盖 Run | 显示本轮研究信号、问题/需求 Atom、已归并 Atom、待开始归并、处理中、已完成 deferred 与覆盖率；已经确认的归并立即累计到概览和用户问题 | 不把其他未归并 Atom 删除、归零、写成已完成 deferred，或阻止已确认关系可读 |
| 历史待归并续办 | 下一次明确启动的 Run 可在当前预算内带入符合止损条件的历史 resolution；运行记录显示续办、补入、处理中与未完成数 | 页面读取、常驻 worker 空转或每日无条件重发；将续办成功写成新统计样本 |
| 原声尚未进入研究 | 显示“尚未进入研究”；已进入的原声显示该 current derivation 的最新 RunItem 状态 | 不在读取原声时派生、冻结、认领或调用模型 |
| 变化不可比 | 显示不可比原因 | 不重复概览内容填满页面 |
| 当前统计窗口无样本 | 统计版本元信息明确其样本位于基线窗口；概览和用户问题仍显示累计确认事实；变化观察显示不可比较 | 不把基线样本说成实时趋势，也不用当前 0 隐藏累计事实 |
| 作者回复/身份未知 | 不进入用户原声、问题或变化分母 | 不将“作者”徽标写进研究正文，也不把它们伪装成普通用户证据 |
| 运行失败 | 显示逐项终态、可读失败汇总与上次已发布版本边界 | 不显示为“没有发现” |
| 部分研究版本 | 明示冻结、纳入、未纳入与问题组织覆盖；允许回到运行记录查看安全失败原因 | 不把 PARTIAL 显示成完整研究、模型修复或市场结论 |

运行记录只汇总安全的 failure code 与数量。语义 JSON 不可解析、字段/证据合同拒绝、以及证据 Unicode 位置无法映射回原评论必须分开表述；不把评论正文、派生正文或模型原文带入运行列表。

## LIDS 组合

- 使用现有 L1 shell、Corpus side nav、Context Bar 与 `--lgi-*` token。
- 页面内只组合标题/状态、tab、表格、空态和 modal；不提升新的全局组件。
- 文案中文承担含义；`Token`、`JSON` 仅在设置技术说明中保留最小必要英文。

## 验收

1. 页面不含旧“每日观察、保存查询、分析所选、评论研究设置”入口或 API。
2. 原声行不出现向量准备术语、评论作者显示名或 Atom 类型枚举；它只展示 canonical `comment-research.derivation.v2` 的 current、readable、`ordinary_user + eligible` 原文、研究正文和受控中文研究状态/安全失败说明，不依赖或返回 `ResultRevision`。回复在父评论不可读且当前短句需要关联语境时，显示“需要父评论语境”，不写成“未提取到研究信号”。读取原声只执行只读查询，不派生、冻结、认领或调用模型；`limit` / `offset` 保持有效。三类身份事实仍在 derivation 中保存，`content_author_reply` 与 `author_identity_unknown` 不进入研究原声、问题或变化分母。
3. 变化页只有 observation 与 `not_comparable`，不出现问题页副本。
4. 保存 policy 和开始研究都复用同一服务端 V1 语义就绪判断：所选 config 的精确 model/connection version 已启用，且该 model/version 最新 probe 为成功、`ok`、`modelCallable` 与 `semanticQualified` 均为真。保存 policy 不调用模型；若已保存策略仍指向旧输入合同，开始研究会拒绝并要求重新保存策略，绝不以旧合同创建 Run。通过预检后，开始研究一次请求直接创建冻结 Run；该 Run 同时可有界续办符合条件的历史 problem-resolution backlog。结构/Schema 失败只在模型配置或 membership contract 改变后续办，语义接纳失败最多三次，瞬时服务失败可由后续已启动 Run 续办。续办 Run 不生成 ResultRevision；成功只补足 Atom 原冻结 Run 的组织覆盖。
5. `no-store`、local-origin guard 与响应式状态在真实 local API 中验证。
6. `completed_with_failures` 只有在 ResultRevision 冻结的研究覆盖和问题组织覆盖均达到 COMMENT-RESEARCH-PUBLISH-001 门槛时才可发布 PARTIAL 统计版本；Run 状态、失败 Item、失败调用和未组织 Atom 保持可回溯，未纳入对象不进入变化、占比、排行或统计分母。已通过 Problem membership 接纳合同的 Atom 不受本轮发布门槛阻断，立即进入概览和用户问题的累计事实读取；累计事实不携带 share、rank、trend 或冻结窗口指标。

## COMMENT-RESEARCH-PAGINATION-001 补充（2026-09-14）

“用户原声”“用户问题”“运行记录”是可增长的研究列表，不能只依赖页面自然滚动来暗示还有结果。三个视图均使用已有的 `limit` / `offset` 只读接口；页面按当前视图请求有界范围，并在表格后明确显示：当前区间、总条数、页码与上一页/下一页。

- 用户问题每页 10 条，便于在研究定义、证据样本与 Atom 数之间保持可读密度；用户原声和运行记录每页 20 条。
- 翻页只改变当前读取范围，不会创建 Run、改变研究结果、派生评论、调用模型或修改 ResultRevision。
- 视图切换回到第 1 页；当前页码通过 `?view=…&page=N` 保留，便于刷新或复制页面链接。
- 无效或已过期的页码必须回到最后一个有效页，不能呈现“看似空白”的假空态。

新增验收：当发布问题数超过 10 条时，用户问题页明确显示“显示 1–10，共 N 条 · 第 1 / M 页”，下一页显示后续条目；原声与运行记录遵循同一信息与交互契约。

## COMMENT-RESEARCH-OVERVIEW-DISCLOSURE-001 补充（2026-09-14）

概览是研究版本的摘要面，不复制完整用户问题列表或其分页。它展示有限的代表问题时，必须在表格后明确说明当前只展示多少项，并提供进入「用户问题」的链接；完整列表的总数、页码与翻页控制只属于「用户问题」视图。

## COMMENT-RESEARCH-PAGINATION-PLACEMENT-001 补充（2026-09-14）

高密度研究表不能作为整页文档向下生长：十行问题定义或二十行原声在正常 100% 缩放下足以把“下一页”推出首屏。桌面端将页头、状态和 Tab 置于工作区上部；用户原声、用户问题与运行记录在剩余可视高度中显示上下文、当前范围、表格和分页，表格内部滚动且列标题固定。用户在进入视图时能看见当前范围、总数、页码和下一页；读完当前页后也能在同一工作区底部翻页。

上方与下方控制使用同一页码和同一读取请求；不是两套分页，更不改变数据、研究结果或模型调用。小屏幕不强制内部滚动，保留自然页面滚动；上方导航与下方导航的无障碍名称分别说明所在位置。
