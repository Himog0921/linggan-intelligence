## 1. 身份与授权

- 页面规格 ID: `PAGE-COLLECTION-001`
- 关联事项: `DESIGN-005`（无 GitHub Issue，Mog 直接指定）
- 当前状态: 五个子面的路由、骨架、几何与交互全部真实存在；**全部业务数据为空**。Collection 的领域对象（观察目标、观察计划、采集任务、执行尝试、观察事件、执行工位）在本项目中尚不存在。
- LIDS 视觉强度: L1 Operations，Targets 抽屉为受限 L2
- LIDS 主 Pattern: Collection Control；抽屉复用同一工作面，不建立第二首页
- 用户任务: 判断「我关心的对象系统在看吗」「哪里断了」「我要加一个或停一个」。第四个问题——「这个对象最近发生了什么值得做内容的事」——由目标抽屉承担，是本页族价值最高的部分。
- 三秒答案: 「这是采集执行层；现在没有任何观察目标，因为建立目标所需的采集授权链还不存在。」
- 五秒主动作: 无。本页族当前没有任何可执行动作；所有会消耗平台访问的控件都显式不可用并说明原因。
- 明确非目标: 真实平台访问、调度器接通、实时推送、观察目标创建、插件改动、数据库 migration、媒体/OCR/ASR、Agent、部署。

| 序 | 路由 | 中文名 | 唯一主问题 |

## 3. 状态与诚实性

| 状态 ID | 触发 | 用户应理解什么 | 禁止暗示什么 |
|---|---|---|---|
| `NO_OBSERVATION_TARGETS` | 系统中没有观察目标 | 建立目标所需的采集授权链尚未存在 | 平台上没有值得观察的对象；目标被删除；采集失败 |
| `SCHEDULER_NOT_CONNECTED` | 调度器未接通 | 没有任何观察在运行，因此没有事件、任务与运行时读数 | 系统健康；队列为空；工位全部离线 |
| `AUTHORISATION_REQUIRED` | 会消耗平台访问的控件 | 这个动作现在不存在 | 点了没反应；能力即将开放 |
| `TARGET_NOT_FOUND` | 抽屉标识无法解析 | 这个标识没有对应的观察目标 | 该对象在平台上不存在；它曾被删除 |
| `UNKNOWN` | 所有读数 | 尚未获得或无法验证 | 数值为零；运行正常；运行失败 |

本页族不显示 `0`、不显示百分比、不显示任何 Gold Master 的示例数值。自动测试逐项断言这些原型数字不得出现在真实路由上。

## 4. 已批准的设计组合

- 全局页头由 `apps/api/src/local_web/shell.rs` 统一生成，Corpus 与 Collection 共用同一实现；`shell.css` 承载页头、上下文行与 216px 导轨，两页共用。
- 页面局部样式在 `collection_workspace.css`，不声明任何 `--lgi-*`，且整个文件不出现字面色值。
- 深色实时观察流是全产品唯一的深色面，色值以 `--lgi-stream-*` 十项 token 进入唯一色值源（117 → 127 项）。
- 客户端脚本只负责抽屉的 tab、宽度与 Escape；导航状态全部由服务端路由渲染，首屏即正确视图，不存在先画错再切换。

### 页面级例外 `DESIGN-005-UI-EX-01`

Mog 于 2026-08-26 确认保留 V4 的深色终端配色。它与 `system.md` §4.10「不使用黑底荧光绿终端」直接冲突，作为长期例外记录：仅限运行态 / NOW 右栏，禁止扩散到任何其它界面；功能文字提到 11px 下限（V4 原型大量使用 7–9px，低于 DESIGN-003 已确认的可读下限）。

## 5. 交互与真实后果

| 用户动作 | 当前状态 | 真实后果 |
|---|---|---|
| 在五个子面之间导航 | 可用 | 仅页面跳转 |
| 切换运行态三模式 | 可用 | 仅页面跳转 |
| 用地址打开目标抽屉、切 tab、切宽度、Escape 关闭 | 可用 | 仅前端状态，同步进地址栏 |

| 筛选、巡逻、调整策略、自动恢复 | 未实现 | 无 |

**自动恢复开关未实现是有意的**：它在 Gold Master 里是一个 toolbar 开关，但它意味着系统在无人确认的情况下自动重新访问平台。在采集授权模型存在之前，本页族不提供这个开关。
