# PAGE-COMMENT-RESEARCH-001

> 状态: 权威当前
> 最后核对: 2026-09-07
> 适用范围: Issue #167 的评论研究及已存查询页面
> 事实来源: [评论研究产品语义](../../pages/comment-research.md)、LIDS v7、当前受控实现
> 冲突时以谁为准: 用户最新确认、真实数据合同、LIDS；本页只规定本包界面

最新目标：本页主体是早期页面的历史规格；当前源码采用概览/原声/用户问题/变化观察及运行记录。Mog新决定的自动研究路径、单一设置表面、取消必经人工边界判断和双轴状态，统一由[CI-AUTO-004 UI清单](../changes/ci-auto-004-ui-change-manifest.md)承接；实施时重写本页现行规格并保留历史引用，不能从下面旧布局派生新功能。

强度 L1，唯一主 Pattern 为 Corpus Explorer。三秒内能回答“当前有哪些可读原声、是什么范围”；五秒内能检索、研读和收存一句表达。四个内部文字 Tab 是原声浏览、问题分组、语料资产、每日研究；一级语料和四个二级职责不因实现而改变，未接通创作者继续明确禁用。

共享 Header/Context/侧导航消费 shell.rs/shell.css，页面不复制主题 Token，也不覆盖壳层类。页面白底连续表格、中文正文、原声表格 13px Sans、两行截断、7px 纵向内边距；详情 Serif 研读、20 行分页；不用 3D、动画环境、聊天大栏或选题工作区。字体、色彩、空间来自现有 LIDS Token，文字 Tab 使用 3px 下划线；所有常用按钮可由键盘访问。

| 表面 | 正常动作 | 必须诚实的状态 |
|---|---|---|
| 原声表格 | 文字/作品/清洗筛选、分页、勾选分析、研读；点赞单列 | 全范围数/本页数分列；未知正文/作品/作者明说；空库和零命中分开 |
| 每日研究 | 最近批次、处理/清洗统计、逐条结果；研究设置和试跑共用弹窗 | 首次启用起点、23:00 截点、暂停/重试、未知用量、额度不足明确呈现 |
| 来源 dialog | 读原声、父评论、作品上下文；选中后收存 | 4,000 字符截断；固定历史版本；父级不可得；来源受限停止展示 |
| 收存 dialog | 保留精确范围、写理由、选集合、提交 | 保存中禁用；失败保留输入；收到真实服务回执才关闭；幂等重试 |
| 人工标注 dialog | 七维标注、显式/推断、修订理由 | 允许空标注以撤销当前解释；修订冲突要求刷新，模型不覆盖人工 |
| 问题组 | 相同标签及有来源样本 | 精确标签分组与语义聚类分开；原声样本不是代表性判定 |
| 资产与查询 | 集合筛选；整理理由和集合、撤销误收存；查询改名/条件编辑/删除 | 原始来源不变，追加修订；冲突保留输入并要求刷新；旧请求不复活已撤销项；受限历史理由隐藏 |

COMMENT-DAILY-001 承接模型设置入口，原声页按后端显示未配置/已配置/已暂停，来源详情可打开单条按作品分析弹窗；普通原声读取/收存不显示假进度。可见分析状态对应真实 work 状态，成功无信号不是“未分析”。所有接口响应 no-store；关闭详情清理当前 DOM 和内存引用。已有打开页面的来源资格变化要经再次请求才能获知，不宣称实现实时远程擦除。

本包以 1440 CSS px 桌面全屏为验收目标；原生 dialog 为必要交互容器，有取消/关闭与 Esc 行为。证据不足、超长文本、未知、零命中/空态由合成隔离数据验证，真实模型和 Mog 使用验收单独记录。
