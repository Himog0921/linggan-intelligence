## 页面与规则来源

运营一级下增加今日选题/我的创作，进入 `/ops/creation` 的同一篇工作区。保留现有总览/发布/账号/每日数据/导入导出。未完成自动供给时按真实方案显示数量；可从已有材料创建，禁止演示10条进入正式页面。

沿唯一LIDS的Token→基础控件→工作区组合。页头/导航复用唯一 React AppShell；页面位于 apps/web/src/pages/workbench/，使用 CSS Modules 并消费已定义 token。原生页面接入已暂停，不能新增或演进 shell.rs。V3空间浏览、纸条放大、书页翻阅、分布索引、紧凑工具栏和按需来源是本页已批准的局部表达。纸条允许原地scale(1.075)聚焦，不允许hover-lift；reduced-motion取消变换。书页为阅读容器，不引入通用3D引擎。差异用新增/删除语义颜色与ins/del结构，不只依赖颜色。

## 首屏与密度

操作区优先：不恢复口号、巨幅标题、重复面包屑标题、教学段落。紧凑标题/选题与任务工具栏；成功保存以可访问状态按需查看，失败/冲突始终可见。正文连续编辑；材料、来源、方法和历史抽屉按需展开。保持1440/1280、1280×720短屏与390窄屏；画布局部横向滚动允许，页面不横向溢出。

## 交互

- 材料浏览：来源类型/用途/关键词筛选、分组纸条；索引/纸条/书本高亮由同一fragmentId与筛选集合派生。翻页保留焦点；精确选文可含中文emoji换行，OCR对应原图区域。匿名原声按父笔记分组，不制造作者。
- 画布：待整理/开头/论点/例子/结尾，原声和我的表达并列但不混改；一次用于正文与指定内页，回出处、重复/失效/删除目标可理解。
- 正文：沉浸编辑/改稿对照，中文composition期间不重绘；稳定段落ID，逐段与整篇采用、撤销；旧建议不覆盖新编辑。
- 封面/内页：统一模板家族，标题/副标题/文案/配色/图像与裁切可改；排序不改身份，删除可恢复；正文变化只提示相关页，选择带入不覆盖其他手改。
- 预览/导出：同渲染器实际画幅，资源/溢出检查；正文+1封面+4内页为验收样稿。保存失败、资源缺失、生成失败分别说明；重新下载成功包与生成新版分开。

## 状态与验收

source unknown/partial/restricted/changed、save pending/failed/conflict、suggestion running/failed/cancelled/stale、export rendering/failed/complete均按数据合同呈现。普通UI用中文动作和可解决问题；技术ID/版本/调用账只在按需详情。已取得数不冒充平台总量，模型未配置不冒充空建议。验收采用计划A01–A13，UI截图与实际PNG/Mog审美签收分别记录。

## 局部几何 Token

仅本页定义 `--cw-reading-min:28rem`、`--cw-strip-min:14rem`、`--cw-lane-width:18rem`、`--cw-control-width:21rem`、`--cw-dialog-width:60rem`、`--cw-editor-width:48rem`、`--cw-paper-focus:1.075`。这是V3已认可布局在Page层的尺寸参数，非新主题；颜色/字级/间距/线/时长消费LIDS，页面不声明新的--lgi-*真源。阶段 C 的 React 运营导航承载我的创作与真实选题；导航接缝由该阶段负责人统一处理。原生运营壳不改；本阶段仅将 Axum `/ops` 默认跳转接至 `/ops/creation`，在新工作台二级导航保留总览/发布/账号/每日数据/导入导出入口。全局紧凑外壳不在本次改造范围。

2026-10-15 短屏核对修正：单页编辑预览按 55vh 与扣除四个现有 `--lgi-space-24` 的视口空间共同限高，CSS 保持 3:4 完整画幅；桌面随编辑区停靠，窄屏正常滚动。仅 Page 层响应布局，不改变目标 PNG 1080×1440、绘图字体或全站 Token。


## 2026-10-15 · Mog 退回后的 V3 还原合同（覆盖冲突旧条目）

V3 是本轮交互和构图验收基准，参考 `content-workbench-prototype/v3/` 与用户认可截图；不改原型和用户草稿。本条覆盖上文“全局紧凑外壳不在本次范围”：本页通过唯一 React AppShell 的显式局部模式提供紧凑页头和沉浸创作，其他页面不随之变样。

1. 今日选题以真实方案墙和详情展示角度、依据、提纲、材料状态、继续研读/创作；我的创作承载稿件进度，不只是同一列表换标题。无合格方案时如实显示空态并可手动建立，不填演示方案。
2. 本篇材料默认包含已准备的相关笔记与真实评论。选择本篇/搜寻更多作为明确范围；搜索结果先预览完整上下文，再加入本篇。准备状态（准备中/已就绪/不足/失败）、匹配理由与缺口有简短可操作反馈。无需先摘入画布才能保留为本篇阅读材料。
3. 原笔记按完整文档组织标题、正文与可用图片文字；字段结束不代表整篇结束。评论带父笔记、必要父评论上下文。短片段从完整文档稳定定位，长文按可读空间翻阅，不按一条数据库字段当一页。
4. V3 的场景/观点/做法/原声/边界筛选、片段纸条、分布矩阵与原文高亮共用片段身份和过滤集合。语义分类缺失不能假装已完成；结构用途开头/论点/例子/结尾只属于画布，不替代片段类型。
5. 画布五列保留结构与可扫读片段，完整引文按需展开；我的表达与来源独立；放入正文与指定内页的操作可在卡片附近完成。正文保持连续写作，按需来源栏和沉浸模式；改稿采用左右并排、逐处差异、联动滚动、右侧可编辑与采用/撤销，不用整段红删绿增替代差异计算。
6. 图文创作四步正文/封面/内页/预览与导出具有明确当前位置和下一步，图片完整画幅可见，编辑操作围绕预览。保留同一渲染器和所有安全保存/引用/导出机制。
7. 视觉与文案：沿 V3 纸面、层级、密度、留白、按钮主次和原地聚焦，不恢复已要求删除的口号/教学文案；不以“符合 Token”替代视觉还原。只用本地字体及 LIDS Token；需要的 Page 几何变量先在迁移日志登记。
8. 验收采用同视口 V3/候选成对截图、真实长笔记与评论、空/不足/失败状态和完整成品。每页 root 目检后才进入下一轮集成；Mog 未签收不记完成。

局部几何补充：`--cw-rail-width:13rem`，对应V3可收起的工作区导航；研读与改稿可用全幅空间。成品模板族为creation-v3-type/split/list，渲染器creation-renderer.v3；历史已完成v1导出继续可下载，不以v3续绘假冒旧冻结版本。

## 2026-10-15 · V8 动作按钮补充（Mog 最新指示）

V3 工作流与布局不变；动作控件以 Mog 提供的 `linggan-design-system-v8 (1).html` 为准：直角、墨色边框与错位硬投影，右缘阶梯点阵从静止一列、悬停40%到按下整面，四格离散加载、禁用点阵休眠与清晰聚焦双环。主操作使用 V8 signal-fill，次操作按 ink/outline/soft/quiet/danger 职责表达；标签、翻页、纸条、缩略图等选择控件不套主操作样式。沿唯一 LIDS Token 源增加作用于这套动作控件的专用 Token，避免改旧值使全站变样。正常、悬停、按下、聚焦、加载、禁用和减少动态效果都进入真实浏览器验收；仅静态截图或 Token 检查通过不算还原完成。
