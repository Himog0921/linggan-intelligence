## 页面与规则来源

运营一级下增加今日选题/我的创作，进入 `/ops/creation` 的同一篇工作区。保留现有总览/发布/账号/每日数据/导入导出。未完成自动供给时按真实方案显示数量；可从已有材料创建，禁止演示10条进入正式页面。

沿唯一LIDS的Token→基础控件→工作区组合。页头/导航复用唯一 React AppShell；页面位于 apps/web/src/pages/workbench/，使用 CSS Modules 并消费已定义 token。原生页面接入已暂停，不能新增或演进 shell.rs。V3空间浏览、纸条放大、书页翻阅、分布索引、紧凑工具栏和按需来源是本页已批准的局部表达。纸条允许原地scale(1.075)聚焦，不允许hover-lift；reduced-motion取消变换。书页为阅读容器，不引入通用3D引擎。差异用新增/删除语义颜色与ins/del结构，不只依赖颜色。

## 首屏与密度

操作区优先：不恢复口号、巨幅标题、重复面包屑标题、教学段落。紧凑标题/选题与任务工具栏；成功保存以可访问状态按需查看，失败/冲突始终可见。正文连续编辑；材料、来源、方法和历史抽屉按需展开。保持1440/1280、1280×720短屏与390窄屏；画布局部横向滚动允许，页面不横向溢出。

## 交互

- 材料浏览：来源类型/用途/关键词筛选、分组纸条；索引/纸条/书本高亮由同一fragmentId与筛选集合派生。翻页保留焦点；精确选文可含中文emoji换行，OCR对应原图区域。匿名原声按父笔记分组，不制造作者。
- 画布：待整理/开头/论点/例子/结尾，原声和我的表达并列但不混改；一次用于正文与指定内页，回出处、重复/失效/删除目标可理解。
- 正文：沉浸编辑/改稿对照，中文composition期间不重绘；稳定段落ID，逐段与整篇采用、撤销；旧建议不覆盖新编辑。
- 封面/内页：统一模板家族，标题/副标题/文案/配色/图像与裁切可改；排序不改身份，删除可恢复；正文变化只提示相关页，选择带入不覆盖其他手改。
- 预览/导出：同渲染器实际画幅，资源/溢出检查；正文+1封面+4内页为验收样稿。保存失败、资源缺失、生成失败分别说明；重新下载成功包与生成新版分开。
