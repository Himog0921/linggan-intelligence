# Evidence、Candidate 与 Boundary 表达模式

> 状态: 权威当前
> 最后核对: 2026-08-21
> 适用范围: DESIGN-002 Topic Intelligence Reference Page 及后续明确采纳的情报页面
> 事实来源: `docs/pages/topic-intelligence-surface.md`、产品不变量、DEC-05、Issue #7 与 UI 设计治理协议
> 冲突时以谁为准: 用户最新确认、产品页面和真实数据/权限/行动合同；模式不自行发明事实或资格

这些模式解决的不是“如何把内容装进卡片”，而是如何让用户一眼分清：样本里看见了什么、系统目前只能提出什么、以及仍然不知道什么。

## PAT-001 · 可追溯观察块

**用途**：表达一个已展示样本中的有限观察。

**必须展示**：内容短句或摘要、样本/来源模式、适用时间窗口、使用限制。

**允许表达**：`样本中出现`、`示例表达`、`当前演示未具备可比性`。

**不得表达**：增长、普遍、代表、证实、热门、可信度总分或“系统已经发现”。

**验收**：移除颜色和 ASCII 后，普通读者仍可知道它是样本观察而不是正式事实。

## PAT-002 · Candidate 与 Observation 分栏

**用途**：把值得后续研究的解释与已经展示的内容分开。

| 栏位 | 可以写 | 必须附带 | 不能写 |
|---|---|---|---|
| Observation | 样本里出现的表达、叙事或差异 | 样本模式、范围、限制 | 结论性因果、趋势、总体数量 |
| Candidate | `值得进一步核验的方向` | 支持它的观察和一个反例/未知点 | 已成立的 Claim、已采纳的 Intelligence |
| Boundary | 当前不能判断什么、为何不能判断 | 缺少的合同/资格或观察条件 | 用“暂无”掩盖未知 |

**验收**：候选栏被单独截取时，仍不会被读成系统正式判断。

## PAT-003 · 来源与 Coverage 边界带

**用途**：在任何可能被误读为统计、趋势或代表性的区域前，先交代可用性。

**最低输入**：数据模式（真实/合成）、比较资格、Coverage 状态、用户不应推断什么。

当前参考页固定为：`SYNTHETIC / NOT LIVE` + `SOURCE_INCOMPLETE` + `不能推断趋势、总量、代表性或覆盖完整度`。

只有未来真实合同同时定义时间、输入集合、实际捕获面、失败/未知、分析版本和适用范围时，页面才可以替换该边界带；有数据数量不等于具备趋势资格。

## PAT-004 · 无副作用的下一步意图

**用途**：演示用户如何从理解走向下一步，而不伪造决定或行动已发生。

**本页允许的互动**：选择“继续探索”或“暂时搁置”，在同一局部区域显示 `LOCAL_INTENT_ONLY` 和“未创建真实记录”。

**本页不允许的互动**：写入数据库、生成 Research、授权采集、加入待办、推送通知、显示“已保存/已完成”、toast 成功反馈，或隐藏选择后的限制。

**晋升条件**：未来页面要提供真实动作，必须有产品动作定义、权限规则、请求/回执合同、失败/部分/恢复路径和相应的页面验收。缺少其中任一项时停在 `DECISION_REQUIRED`。
