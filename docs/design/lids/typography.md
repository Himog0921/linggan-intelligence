## 已确认字体角色（ALIGN-TYPE）

| 内容角色 | 选定字族 | 应用边界 |
| --- | --- | --- |
| 中文界面、正文与原声 | OPPO Sans 4.0 | 保留已选中文字形与中英混排基线 |
| 英文界面、正文 | Albert Sans | 常规英文；不改变中文主表达规则 |
| 英文大展示标题 | Alumni Sans | 仅充分大的展示标题，不进入中文标题、小控件或密集表格 |
| 普通数字、计数、时间、普通编号 | Manrope（A） | 数字列等宽数字特性、按数据语义对齐；不把未知写成零 |
| 代码、技术诊断、需逐字符辨识的标识 | 既有 Mono 角色 | 与普通数字分责；审阅中 JetBrains Mono 是诊断候选，不是所有数字字体 |
| LI / FIND 装饰字标 | 保留现有字标身份 | 不因全局数字或英文字体替换而重绘，不成为动作名 |

字体族的选择取代旧文件中“全部机器读数强制 Mono”的要求。普通数字按 Manrope；技术原样字符串按 Mono，不能为换字体改写值、精度或时间格式。

## 字级标准（ALIGN-SCALE-B · 已采纳）

Mog于2026-10-19明确“全部按照 B 来落实，确保当前的一致性，以及只有一个标准”。Q01字号／行高与Q02字重均已关闭，完整采用TYPE-04对照中的B。唯一数值维护源为[typography.json](typography.json)；本表自动生成，组件、页面和审阅登记均由该源派生。

旧11/12/13/15/17/21/27阶梯及仅400/600/700的限制在排版范围内由本标准取代。A只作历史对照，不能作为新页面、组件或Agent的可选标准；新角色或例外需另有明确决定。字体族、字号、行高、字重四项一起按语义角色读取。

## 加载、许可与迁移

审阅工程已默认应用该字体组合；正式前端仍为现有系统/Noto 字体栈，本次未写入字体文件或 CSS。字体资产来源及 SHA 随[对齐清单](review-alignment.json)登记。未来接入须保留原许可和版权，核对具体文件允许的分发/修改条件，按ALIGN-FONT-012执行本地加载/回退，核验字重支持与性能；本文件不把“选定字体”当作资产迁移已完成。

实现时将语义字族映射到唯一 `--lgi-*` 值源，不把审阅工程的 `--ty-*` 或字符范围实现复制成第二套主题。测试实际字体加载、混排、数字宽度、字号和失败回退；静态声明 font-family 不能证明字体已经渲染。

## ALIGN-FONT-012 · Q11已采用（2026-10-20）

U22明确采用“字体加载后自动换入，回退用F2，普通数字右对齐，小数列按小数点对齐”。唯一机器规则仍是typography.json：families为完整顺序，deliveryDecision为交付与数值语义。先显示可读回退，通过font-display:swap自动换入本地已选字体；不要求用户点击应用字体。F2中文回退依次为PingFang SC、Microsoft YaHei、system-ui；英文/数字回退Arial、Helvetica、system-ui；英文展示回退Arial Narrow、Arial、system-ui。首选OPPO/Albert/Alumni/Manrope及B角色数值保持，品牌与代码身份角色保持。关闭的F1、比例数字和手动放行只留16证据，现行字体页为已采用规则及故障诊断。

普通数字/时间/编号保持Manrope等宽数字及右对齐；同一小数列采用整数/小数点/小数段分列定位，保留原始字符串及小数位，不添加精度、不把null或未知记作0。小数位保留区由同列最长实际小数位确定，不应挤入邻列。对齐辅助不授予正式CMP。

字体文件只读不变，保留原许可与可见使用声明；实际字重由文件范围核对，禁止伪粗/伪斜。4首选原文件合计22,904,384 bytes，OPPO22,741,096 bytes；本次不压缩、子集化或改写。实现任务继续按具体平台验证许可条件、字形覆盖和首访/弱网性能，不把本机load结果当生产认证。正式业务资产/运行Token迁移仍须具体实施授权。

加载/回退检查应同时记录FontFace.load结果、字形宽度/混排及当前布局；FontFaceSet.check或font-family声明不能单独证明指定字形已渲染。技术依据保留：[FontFace.load](https://developer.mozilla.org/en-US/docs/Web/API/FontFace/load)、[check边界](https://developer.mozilla.org/en-US/docs/Web/API/FontFaceSet/check)、[数字特性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-variant-numeric)。Q11已关闭；性能、许可及业务接入是实施核验事项，不重开已确认的视觉选择。
