## 1. 为什么要锁死

页头与 Context Bar 是全站唯一**每一屏都出现**的两条带。它们一旦松动，任何人都会往里塞一句话——每一句单独看都合理，累积起来它们就变成公告栏。

这不是假设。v7 的违规样本直接来自本项目的真实页面：约束区塞了 4 项、中英对照重复 3 处、时区同时写了中文全称和代号、静默区被完全吃掉。

因此本文件把两条带的**区位、内容类型与数量上限全部冻结**（ADR-10）。新增功能只能进入已有区位，**不新增区位、不加第二行**。

这条与 [patterns.md](patterns.md) 的"外壳组件的所有权"条款配套：那一条规定外壳样式必须整份住在 `shell.css`，本条规定外壳里**能放什么、放几个**。

## 2. 页头 · 三区位（冻结）

```text
[ A 品牌区 · 固定 326px ][ B 导航区 · 最多 6 项 ][ C 系统区 · 固定 400px · 恰好 2 个元素 ]
```

| 区位 | 只允许 | 禁止 | 上限 |
|---|---|---|---|
| A 品牌区 | 标识 + 产品名 + 一行版本标识 | 用户信息、搜索、任何入口 | 固定宽 |
| B 导航区 | 中文名 + 一行辅助信息；**辅助行只能是计数或状态词其一** | 中英对照并列、同时出现计数与状态、第三行 | 6 项 |
| C 系统区 | 服务状态胶囊 + 命令入口，恰好两个 | 状态胶囊内中英双写、超过 8 字、第三个元素 | 2 个 |

### B 区导航项的合规判据

违规写法（真实样本）：

```text
语料
CORPUS   未知          ← 中英并列 + 计数与状态同时出现
```

合规写法：

```text
语料
328K                   ← 辅助行只留一类信息
```

判据只有一句：**数一数辅助行里有几类信息。多于一类即违规。**

### C 区状态胶囊的合规判据

违规：`本机服务状态` + `本机材料投影 LOCAL MATERIAL PROJECTION`（中英双写、超 8 字、三个元素）。

合规：`本机投影 · 正常`（≤8 字，单一元素）。

一级导航仍必须遵守 [patterns.md](patterns.md) 的"一级导航只指向职责入口，永不指向子面"。本文件不放宽该约束。

## 3. Context Bar · 四区位（冻结）

```text
[ A 路径区 ][ B 约束区 ][ C 静默区 ][ D 锚点区 ]
```

| 区位 | 只允许 | 禁止 | 上限 |
|---|---|---|---|
| A 路径区 | 当前位置的层级路径，末级加粗 | 计数、状态词、英文对照、操作按钮 | 3 级 |
| B 约束区 | 作用于"当前所见内容"的约束，如只读、默认投影 | 系统健康、服务状态、进度、任何数字 | 2 项 · 每项 ≤6 字 |
| C 静默区 | **仅校准场材料**（`M-01`） | 任何文字、数字、图标、按钮——无例外 | ≥120px |
| D 锚点区 | 当前时间 + 时区代号 | 时区中文全称、日期、其他任何内容 | 1 项 |

### C 静默区是全站唯一被明文保护的空白

它不是"暂时没内容的地方"，是**被规范保护、禁止填入任何文字与数字的区域**。任何"这里正好有块空地，把 X 放进去"的提案一律驳回，不需要个案讨论。

静默区是唯一允许出现材料的壳层位置，且只允许 `M-01` 校准场（见 [materials.md](materials.md)）。

### B 约束区与系统状态的分界

约束区回答"我现在看到的这批内容受什么限制"，**不回答"系统好不好"**。

| 内容 | 归属 |
|---|---|
| 只读、默认投影、严格发布时间窗口 | Context Bar B 区 |
| 本机服务状态、连接、心跳 | 页头 C 系统区 |
| 「不混读旧发现卡片」一类**系统策略** | 设置页，两条带都不放 |

### D 锚点区：时区二选一

**时区全称与代号二选一，界面里永远选代号。** `本机时区 / 中国标准时间 / UTC+08` 三写同一件事，只保留 `UTC+08`。

## 4. 违规与合规对照（存档样本）

违规（来自真实页面）：

```text
语料 / 证据库 / 作品材料集合 │ 事实层 只读 材料入口 默认投影 不混读旧发现卡片
NO LEGACY FALLBACK │（静默区被占满）│ 本机时区 中国标准时间 UTC+08
```

违规计数：约束区 4 项、中英对照 3 处、静默区被占满、锚点区含中文全称。

合规：

```text
语料 / 证据库 / 作品材料集合 │ 只读  默认投影 │（静默区留出）│ 09:42 UTC+08
```

被删掉的三项去向已在 §3 的分界表中固定，不是"删掉了事"。

## 5. 验收

1. 页头是否恰好 3 区、Context Bar 是否恰好 4 区？有没有第二行？
2. 导航项辅助行是否只有一类信息？共几项（≤6）？
3. 系统区是否恰好 2 个元素？状态胶囊是否 ≤8 字、无中英双写？
4. 路径区是否 ≤3 级、且不含计数/状态词/按钮？
5. 约束区是否 ≤2 项、每项 ≤6 字、且不含任何数字与系统状态？
6. **静默区宽度是否 ≥120px，且内部零文字零数字零图标零按钮？**
7. 锚点区是否只有时间 + 时区代号一项？

第 6 条建议由自动检查执行：静默区容器内出现任何文本节点即失败。当前尚未实现该检查，属 DESIGN-010 欠账。

本文件只约束壳层的区位与容量；它不改变路由、权限、状态判定或任何页面的数据合同。
