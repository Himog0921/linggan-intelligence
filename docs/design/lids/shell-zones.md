## 当前规则（ALIGN-SHELL）

全局外壳只有一个所有者：AppShell及相应业务Frame提供品牌、一级职责导航、右侧全局入口、位置/范围带及模块侧栏。页面只声明配置，不能重建第二套页头、领域菜单或侧栏。结构对照当前真实React页面，业务含义由现有产品合同决定。

| 区域 | 放什么 | 不放什么 |
| --- | --- | --- |
| 品牌与一级导航 | LI、Linggan Intelligence、现有职责入口 | 当前列表筛选、采集发起、页面大统计 |
| 右侧全局入口 | 已有个人/系统入口；真实状态依合同，审阅合成说明依审阅身份 | 把“合成预览”画成真实Warning/健康状态，或新增权限入口 |
| 面包屑 Z02-P | 真实路径、可返回上级与当前对象/页面 | 虚构父页、计数、进度、业务主动作 |
| 领域选择 Z02-S | **保留在当前面包屑带的位置**，与路径相邻且语义独立 | 移到另起的必选范围栏；伪装成路由层级 |
| 侧栏 Z03 | 当前模块页面入口及唯一可辨的活动项 | 当前列表筛选、普通动作或统计面板 |

领域的默认值、加载、空选择、无权限及切换后状态按真实合同；设计不得默认选第一个掩盖缺失。领域控件与当前侧栏选中项沿现有纹理方向，材质按[materials](materials.md)的ALIGN-MATERIAL-006采用M2。

主区区域分工与计数位置见 [regions](regions.md)。导航已说明页面身份时，不重复一个同名标题或单项Tab；对象标题和有真实内容差异的分区保留。

## ALIGN-NAV-003 · 三级导航统一归面包屑模块

Mog明确要求“后续的三级导航tab，全部固定放到面包屑模块里去，把页面的主要操作区域留出空间”。此位置规则已采纳，替代三级页面分区继续占用主工作区或另占侧栏分区行的安排；不批准新的业务页面或子视图。

- 一级为页头职责入口，二级为左侧模块页面，三级为该页面下真实内容分区，例如评论概览、用户评论、研究批次、用户问题。所有三级页面Tab统一由共享壳／Frame在Z02面包屑模块承载，页面只声明项、当前项与既有导航意图。
- 路径、领域选择与三级Tab是同一模块内的独立插槽；领域保持现位，Tab不伪装成面包屑的路由层级。桌面相邻组合，窄屏可在同一模块内换行／局部横向滚动；不移回主工作区，也不挤压领域或缩小B字号。
- Z04-N保留为既有“页面分区职责”的沟通ID，其物理host改为Z02；Z编号不强制代表DOM嵌套。主工作区不再复制该导航，优先承载查询、主动作和业务内容。
- 筛选集合、图表／表格切换属于Z04-V；对象详情内部的概览、进展、成果等属于Z05-N。它们不是三级页面导航，继续留在对应对象或内容旁。单一同名伪Tab仍省略。
- 两项以上真实分区才显示Tab；活动项与键盘焦点分开表达。使用方向键／Home／End移动焦点，Enter／Space激活；窄屏标签可横向滚动且保持完整可访问名称。路由、返回上下文、dirty／pending后果继续沿真实合同，不能以挪动Tab重设业务状态。

确认的是所属模块和职责，具体容量与断点按ALIGN-SHELL-007的A执行，M2材质数值已按Q05确认；本次仅规范及独立原型应用，未改业务壳层。

## 容量与留白

空区域省略，语义区位不强制增加行或填满。留白不放教学文字或系统宣言。若PAGE明确采用静默材料槽，该槽禁止任何文字、数字、图标、按钮——无例外；不能据此要求所有页面都创建120px占位。

Q06已按ALIGN-SHELL-007采用A，参数唯一[shell-layout.json](shell-layout.json)。旧ADR-10的326px品牌、400px系统区、固定3+4槽、120px静默占位与必有时钟，对本共享壳的强制容量由A替代：品牌与个人入口依内容占位，无内容不创建空槽；时钟只在PAGE合同有实际需要时出现。既有PAGE专用静默材料槽的禁止内容规则仍保留，Q12局部材料例外不变。

## ALIGN-SHELL-007 · A连续导航轨与手动图标折叠

Mog明确采用A，并补充“左侧导航栏可以支持点击折叠，只露出图标”。宽屏一级导航保持完整横轨，侧栏默认展开160px，点击后为64px图标轨；采用18px线性图标与M2选中材质。图标含义、完整可访问名称与当前项保留。折叠开关具备aria-expanded/aria-controls，Enter/Space可操作，焦点留在开关；不触发路由、领域或查询重置，不自动持久化用户偏好。

低于820px沿A将一级导航和模块导航分别放入局部横轨，主区保持整宽；模块轨仍可点击切为图标。领域及三级Tab继续留在Z02，同模块内换行／局部横滚，标签不缩字号。完整路径可展开，键盘定位应自动显露完整Tab。窄屏不新增抽屉或“更多”导航作为另一套默认。

本次64px/18px是对已授权图标折叠的实施参数；如视觉验收需调整仍在同一参数源修改，不复制页面值。已采用决定不代表组件已获Q10正式认证。

## 验收

1. 共享壳层复用且唯一，一级导航仍指向既有职责入口；未新增业务能力。
2. 面包屑是真实路径，领域仍同带原位；加载/空/受限状态不被伪造。
3. 侧栏当前项明确，hover不覆盖选中含义；纹理避让文字。
4. 主区无冗余同名标题或单项Tab；统计与动作各有最小职责。
5. 窄屏/键盘可达现有入口，整页溢出与表格局部横向滚动分别检查。
6. 合成说明与真实系统状态分开；个人菜单新稿的材质按已确认M2，关闭策略仍按Q09及页面现行合同核对。

本文件通过ALIGN-NAV-003替代三级页面Tab原来的主区／侧栏分区行位置；同时替代旧壳层“路径内任何按钮都禁止”对领域控件造成的冲突，以及为此强制增加或填满区域的做法；共享壳容量由ALIGN-SHELL-007替代；不改变路由、权限、当前个人菜单行为或数据合同。
