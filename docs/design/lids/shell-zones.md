## 当前规则（ALIGN-SHELL）

全局外壳只有一个所有者：AppShell及相应业务Frame提供品牌、一级职责导航、右侧全局入口、位置/范围带及模块侧栏。页面只声明配置，不能重建第二套页头、领域菜单或侧栏。结构对照当前真实React页面，业务含义由现有产品合同决定。

| 区域 | 放什么 | 不放什么 |
| --- | --- | --- |
| 品牌与一级导航 | LI、Linggan Intelligence、现有职责入口 | 当前列表筛选、采集发起、页面大统计 |
| 右侧全局入口 | 已有个人/系统入口；真实状态依合同，审阅合成说明依审阅身份 | 把“合成预览”画成真实Warning/健康状态，或新增权限入口 |
| 面包屑 Z02-P | 真实路径、可返回上级与当前对象/页面 | 虚构父页、计数、进度、业务主动作 |
| 领域选择 Z02-S | **保留在当前面包屑带的位置**，与路径相邻且语义独立 | 移到另起的必选范围栏；伪装成路由层级 |
| 侧栏 Z03 | 二级页面父项、三级页面子项；当前父项与当前子项均可辨 | 一级业务入口、当前列表筛选、普通动作或统计面板 |

领域的默认值、加载、空选择、无权限及切换后状态按真实合同；设计不得默认选第一个掩盖缺失。领域控件与当前侧栏选中项沿现有纹理方向，材质按[materials](materials.md)的ALIGN-MATERIAL-006采用M2。

主区区域分工与计数位置见 [regions](regions.md)。导航已说明页面身份时，不重复一个同名标题或单项Tab；对象标题和有真实内容差异的分区保留。

## ALIGN-NAV-004 · 二级与三级页面导航统一归左侧导航树（2026-11-11）

Mog确认左侧导航只放二级页面与三级页面，并选择方案C（Signal Console）。本决定替代ALIGN-NAV-003中“三级页面Tab统一放在Z02面包屑模块”的物理位置规则；一级职责导航、领域选择器、面包屑路径与当前位置的职责不变。

- 一级仍由页头职责导航承载，不重复放入左侧。
- 二级页面是左侧导航树的父项；使用编号、图标和页面名称。没有三级页面的二级项不增加空的展开按钮。
- 三级页面作为所属二级项的缩进子项；当前三级页所在的二级组自动展开，活动父项与活动子项分别表达。手动折叠只改变呈现，不改路由、领域、筛选或查询状态。
- 左侧导航只承载真实页面入口。集合筛选、图表/表格切换、对象详情内部的概览/进展/成果，以及编辑器内的步骤视图，继续留在对应内容或对象内部；不因视觉相似而提升为全局页面。
- Z02-P只保留真实路径、可返回上级与当前页面；Z02-S保留领域选择器原位。两者仍在同一面包屑带，领域不伪装成路由层级。主题图谱的“主题概览/用户生命旅程”继续按既有产品决定作为该页面的视图切换留在Z02，不属于全局二/三级页面导航。
- 桌面端左侧导航树纵向展示。折叠后只显示二级图标，保留完整可访问名称；三级子项在折叠态隐藏，展开后仍可访问。窄屏沿用现有局部横向导航轨，不另造一套导航抽屉。
- 导航链接保留真实href与查询参数；评论研究切换沿用原有StudyNavigation，以保留各视图的筛选、返回位置和历史语义。未保存/在途保护仍由原页面合同负责。

本决定不改变任何页面路由、权限、领域归属、业务命令或数据合同。ALIGN-NAV-003保留为历史决定，不再作为当前导航位置规则。具体容量、折叠与图标参数仍由ALIGN-SHELL-007唯一管理；导航外观由共享Sidebar与shell.css管理。

## ALIGN-SHELL-008 · 共享页头一致性（2026-11-05）

Mog要求全站页头与面包屑跟语料「证据库」「创作者」两页一致。本页记录已实施标准，替代各页面先前自写的页头高度与面包屑拼接：

- **高度**：Z02 默认 44px（`--lgi-space-10 + --lgi-space-1`，上下内边距各 4px）。Z02不再承载全局三级页面导航；右侧仅有真实视图切换或操作时，由其内容自然撑高，不另写页面高度。
- **缩进**：`.v7-context-main` 始终从左侧导航轨宽度处开始（展开 224px / 折叠 64px）；没有模块侧栏的页面（主题图谱）保留同一 224px 缩进，使全站面包屑左缘对齐。820px 及以下按 A 收起为整宽。
- **面包屑**：只由 `ContextBreadcrumb` 渲染。页面只提供按顺序的内容项；分隔符与末项标记由共享层生成。末项统一为 `<b class="v7-annotated-current" aria-current="page">`，带手绘线，不再有页面自写的隐藏当前页或另一种加粗写法。
- **纹理**：任何页面都不得关闭 Pattern Waves 底纹层或隐藏 `.v7-context-row` 的材质节点。
- **所有权**：`.v7-context-row / -main / -crumb / -meta / -section-nav、.v7-tertiary-nav、.v7-context-action、.v7-domain-picker、.v7-annotated-current` 的样式只在 `styles/shell.css` 与 `app/ContextTexture.module.css`（深色材质适配）里；`shellOwnership` 测试阻止页面 CSS 覆盖这些选择器。页面要调整就改共享表，不回到页面 CSS。

本标准的运行时实现为 `apps/web/src/shared/ContextBar.tsx`、`apps/web/src/styles/shell.css`，变更记录见 `docs/design/changes/lids-component-change.json`。

## ALIGN-SHELL-007 · A连续导航轨与手动图标折叠

Mog明确采用A，并补充“左侧导航栏可以支持点击折叠，只露出图标”。宽屏一级导航保持完整横轨，侧栏默认展开224px，点击后为64px图标轨；采用18px线性图标与M2选中材质。图标含义、完整可访问名称与当前项保留。折叠开关具备aria-expanded/aria-controls，Enter/Space可操作，焦点留在开关；不触发路由、领域或查询重置，不自动持久化用户偏好。

低于820px沿A将一级导航和模块导航分别放入局部横轨，主区保持整宽；Z03导航轨包含二级父项与当前组的三级子项，内容局部横向滚动。领域选择器继续留在Z02原位。窄屏不新增抽屉或“更多”导航作为另一套默认。

本次64px/18px是对已授权图标折叠的实施参数；如视觉验收需调整仍在同一参数源修改，不复制页面值。已采用决定不代表组件已获Q10正式认证。

## 验收

1. 共享壳层复用且唯一，一级导航仍指向既有职责入口；未新增业务能力。
2. 面包屑是真实路径，领域仍同带原位；加载/空/受限状态不被伪造。
3. 侧栏当前项明确，hover不覆盖选中含义；纹理避让文字。
4. 主区无冗余同名标题或单项Tab；统计与动作各有最小职责。
5. 窄屏/键盘可达现有入口，整页溢出与表格局部横向滚动分别检查。
6. 合成说明与真实系统状态分开；个人菜单新稿的材质按已确认M2，关闭策略仍按Q09及页面现行合同核对。

本文件通过ALIGN-NAV-004替代ALIGN-NAV-003的三级导航位置规则：二级/三级页面统一进入Z03左侧导航树；Z02继续承载真实路径、领域选择和当前位置。它不改变路由、权限、当前个人菜单行为或数据合同；共享壳容量由ALIGN-SHELL-007管理。
