## 1. 设计职责与唯一主题

Linggan Intelligence 不是普通 SaaS 后台、传统 BI 看板或聊天窗口。它的界面职责是帮助用户分清：世界发生了什么、系统实际观察到了什么、哪些是原始事实、哪些经过归一化或推导、判断依赖什么证据、覆盖还缺什么、系统或 Agent 实际在做什么，以及用户下一步需要判断什么。

一句话视觉定义：**纯白台面上的精密情报基础设施**。

> **DESIGN-003（2026-08-25，Mog 逐项确认）改写了这条定义。** 原表述为「暖灰纸面」，对应 `--lgi-canvas: #ecebe6`。Mog 明确选择纯白、冷静、克制的底子并否定暖灰，因此画布换向为 `#ffffff`，墨色由暖黑 `#121211` 换为冷黑 `#111315`。按 LIDS 自身的冲突规则，用户最新确认优先。
>
> **DESIGN-010（v7.0）保持这条定义并把它变成可计量的三条预算**：白场 70%、结构材料 20%、信号与实时 10%（见第 3 节与 [materials.md](materials.md)）。墨色目标值收紧为 `#0b0f12`，尚未进入运行时。

系统应同时体现真实、精密、可追溯和克制：原声/来源/时间/范围/缺口可见；结构、读数和状态对齐；结论可回到证据；少色、少阴影、少装饰动效。视觉权重为编辑式信息设计约 55%、精密仪器语言约 25%、等距系统语言约 15%、ASCII/终端语言约 5%。

### 新粗野主义作为重音，不作为底色

底子保持安静：纯白、冷黑、高信息密度、大量呼吸空间。新粗野主义只出现在**极少数节点**——品牌标识、当前选中项、主操作、状态徽章——每处都足够硬：厚边、实色硬阴影、实心撞色、hover 整块位移。

这条约束是可计量的：**任一屏内承担粗野重音的元素不超过 8 处**。超过就不再是重音，而是底色，安静与留白同时失效。

「重音而非底色」是 Mog 在 DESIGN-003 中确认的方向，用于调和「新粗野主义」与「冷静克制 + 留白」这两个本来互相拉扯的要求。ASCII 是稳定编码协议，不是纹理；等距场景表达数据路径，不是科技插图。

LOCAL-001A 已获准使用的运行时主题名为：

```html
<html data-theme="linggan-intelligence">
```

该主题名已由 loopback Rust host 的 Evidence Library 页面使用；其完整运行时 Token 值源是 `apps/api/src/local_web/lids_tokens.css`。这项受限实现不表示已有通用主题框架、组件库、真实数据/read model、L2/L3 页面、Agent、部署或完整产品 Web。

## 2. 五层架构和横向约束

```text
Token → Primitive → Component → Pattern → Page
        ↘ Motion / Scene / Data Truth（横向约束） ↗
```

| 层 | 只负责什么 | 不负责什么 |
|---|---|---|
| Token | 色彩、文字、间距、边框、阴影、动效和场景的不可拆分值 | 业务对象、数据含义或操作权限 |
| Primitive | 可复用基础语法：文字、按钮、状态、Surface、Readout、输入、分割和焦点 | 某个 Topic、数据请求或业务结论 |
| Component | 有唯一正式入口、数据契约、状态、可访问性、允许/禁止场景的稳定责任 | 把页面判断或权限偷偷封装起来 |
| Pattern | 页面级组合与信息流顺序 | 具体文案、数据数值或动作授权 |
| Page | 某个页面的单一任务、事实来源、状态、动作、响应式与验收 | 反向发明全局规则或数据合同 |

组件在 Linggan 只有被第二个独立页面证明同一用户可见责任、完成 CMP 规格和验收后才算“正式”。来源包中出现的组件名在没有这些条件前只是**受控候选名称**，不可声称为已实现组件库。

每次变更必须从页面任务/真实数据合同向上追到 Pattern、Component/Primitive 和 Token；不可从截图或想象的视觉效果向下倒推产品。

v7 为这条链补齐了三份专门约束，它们横切五层，与本文件同级生效：

| 文件 | 约束什么 | 对应 ADR |
|---|---|---|
| [materials.md](materials.md) | 背景材料的唯一语法、预算与区位 | `ADR-08` `ADR-09` |
| [shell-zones.md](shell-zones.md) | 页头与 Context Bar 的区位、容量与禁止清单 | `ADR-10` |
| [data-boundaries.md](data-boundaries.md) | 组件必须跑通的四种极端数据情况 | — |

[decisions.md](decisions.md) 是全部结构性决定的台账，记录每条决定的理由、代价与**规则状态 / 运行时状态**两栏。

## 3. 视觉强度：先选 L，再选 Pattern

### L3 · Brand / Observatory

适用于建立整体认知、重大 Topic、情报发布或受批准的品牌级展示。允许完整等距情报装置、坐标刻度、背景大网格、巨型标题、有限环境动效、深色命令坞和 Signal Fingerprint。首屏只有一个视觉核心，必须同时有当前对象、变化、覆盖、原声或证据和系统状态；动画必须有真实状态来源，不能退化为品牌展示。

### L2 · Research / Analysis

适用于 Topic 详情、Evidence Inspector、Signal 分析、Market Insight 和主动研究。阅读、筛选、对比优先；允许局部等距结构、高密度 Evidence/Trace 和一到两个深色关键判断面。局部等距区域不超过主工作区 40%，持续动画只在真实任务运行时出现。

### L1 · Operations / Configuration

适用于 Corpus、评论检索、采集调度、任务列表、设置、规则和映射。以表格、连续列表、分栏和轻分割线为主；不使用品牌级主场景，动效只用于反馈/进度。

背景纹理在各强度下都只能是**测量场**而非装饰。v7 把纹理统一为一套 8px 采样点阵的六种状态，完整规则见 [materials.md](materials.md)；本节只固定它的预算与禁止项。

**材料预算（硬性）**：白场 70%（正文、列表、主要工作面）· 结构材料 20%（边缘、标题轨、身份轨、测量场）· 信号与实时 10%（当前对象、实时仪器、关键定位）。

禁止在任何强度下使用渐变、光晕、噪点位图或任何随内容滚动的动态纹理。禁止用纹理替代状态：状态始终由文字 + 符号 + 颜色三通道表达。

当前 `PAGE-TOPIC-001` 是一个 **L2** 静态合成阅读参考，绝不是 L3 Observatory 或对任何真实 Topic 页的授权。

## 4. 所有页面的基本视觉约束

1. 颜色、字号、间距、圆角、阴影、动效只可引用 [tokens.md](tokens.md)；不写硬编码六位色、任意字号或随机间距。组件只引用 L2 SEMANTIC 与 L3 GEOMETRY，**不直接引用 L1 PRIMITIVE 原色**。
2. 中文阅读使用 Sans；机器事实、状态枚举、结构编号使用 Mono；**人的原声使用 Serif**。长中文正文与研究结论禁止使用 Mono。英文的三类预算见 [语言规则 LANG-05](language-policy.md)。
3. **功能文字下限 11px，没有例外**（`ADR-03`）。9px 及以下的装饰刻度已废止——在非高分屏上不可读。关键正文不小于 14px；长评论/原声为 16px 或以上。
4. 采用 4px 间距基数，同层级相邻元素使用同一间距值。页面大区块优先 32/48px，组件内部优先 8/12/16px。
5. 常规容器圆角只允许 0/4/8px，pill 仅给状态点一类纯圆元素；不以厚胶囊、12px 以上圆角、渐变或多层阴影制造“AI 感”。
6. **字重只有 400 / 600 / 700 三档**（`ADR-02`）。850、950 一类在 PingFang SC 与 Noto Sans SC 中不存在，只会触发浏览器合成加粗，导致中英混排笔画粗细不一致。
7. **边框不使用 1.5px**——在 1x 屏上产生半像素模糊。线宽为 1（分隔）/ 2（对象边界）/ 3（模式切换）/ 5（信号条）四档。SVG 图标描边的 1.5 是会随尺寸缩放的单位，不受此限。
8. 边界优先次序为：留白 → 底色 → 左轨/坐标 → 1px Hairline → 强边框。普通列表、表格和读数默认无阴影。
9. Signal 橙红只表达活跃数据流、选中、情报升级和主动作反馈；不承担 Warning、Danger、Success 或所有增长数字。**它有两个角色且不可互换**（`ADR-04`）：`signal-fill`（`#c63214`，5.4:1）承载文字，`signal-mark`（`#f24a23`，3.6:1）只做色块、轨与销钉，绝不承载任何文字。
10. 一个视觉组只有一个外层 Surface，内部以排版、留白、栅格与分割线组织；禁止 `section → card → small card` 三层框套框。
11. 纯读数没有 hover、假按钮、假进度、假网络状态或“待联调”Primary。未完成能力隐藏，或明确 disabled 并说明开放条件。
12. 不使用黑底荧光绿终端、蓝紫霓虹大屏、玻璃拟态、大渐变、满屏圆角卡片、军事雷达、代码雨、常驻大型 3D 或用视觉复杂度掩盖不确定性。唯一例外是 [materials.md](materials.md) 的 `M-05` 低亮传感面：它是**局部**深色仪器面，绑定真实实时事件，不是深色主题，也不得扩散到整页（`ADR-07` 维持不支持深色模式）。

### 信息密度 T0–T3（`ADR-06`）

密度控制**一屏能看多少内容**——内边距、行高与次要元数据的显隐。**它不是纹理浓度。**

v5 的密度切换只改变纹理浓度，切换后一屏能看的条数不变，因此它是一个假开关。v7 由密度驱动信息量，纹理强度只是附带效果。

| 档 | 内边距 | 行高 | 次要元数据 |
|---|---|---|---|
| T0 疏 | ×1.35 | ×1.25 | 显示 |
| T1 | ×1.15 | ×1.1 | 显示 |
| T2 默认 | ×1 | ×1 | 显示 |
| T3 密 | ×0.8 | ×0.88 | **隐藏** |

验收判据：切换 T0 → T3 后，同一视口内可见的列表条数必须实际增加。没变即实现错误。

密度隐藏的只能是**次要元数据**。事实、状态、原声与主动作在任何密度下都必须可见——密度不是隐藏坏消息的地方。

### 页面模式：一个世界，不同仪器

相同的全局语言下，不同业务域仍然拥有不同画面。这不是四套设计系统，是同一套语言的四种句式：

| 域 | 模式 |
|---|---|
| 证据库 | 连续档案 |
| 采集运行 | 控制 + 实时 |
| 目标档案 | 身份 + 基线 |
| 编年记忆 | 事件脊柱 |

具体骨架见 [patterns.md](patterns.md)。选择模式的依据是这个域的用户任务，不是"换个样子好看"。

## 5. Data Truth：设计不能篡改事实

有真实合同的页面应分别呈现五类问题：

| 轴 | 允许的标准状态 | 不能与什么混同 |
|---|---|---|
| Truth | `OBSERVED`、`NORMALIZED`、`DERIVED`、`REVIEWED`、`PROMOTED` | 数据完整度或运行进度 |
| Coverage | `COMPLETE`、`PARTIAL`、`INTERRUPTED`、`EMPTY` | 数据有效性 |
| Validity | `VALID`、`DEGRADED`、`INVALID` | Coverage 或错误状态 |
| Freshness | `FRESH`、`AGING`、`STALE`、`UNKNOWN` | 已完成/失败 |
| Operation | `QUEUED`、`RUNNING`、`RETRYING`、`COMPLETED`、`FAILED` | 事实来源、Coverage 或 Validity |

`PARTIAL + VALID` 是一等状态：它表示目标尚未完成但已获得数据可在明确范围内使用；必须显示 `TARGET / OBSERVED / RETAINED / GAP` 和可使用范围。不能显示为 `FAILED`、`0` 或“完整代表性”。

`0` 只表示已确认数值为零；无适用值为 `—`，尚未获得或无法验证为 `UNKNOWN`，不适用为 `N/A`。任何 AI/Agent 结论必须带数据窗口、样本、Coverage、处理步骤、冲突、人工复核和适用边界。原声、来源和上下文优先于 AI 摘要。

对没有真实数据合同的页面，不得假装使用上述真实状态轴。它必须使用清晰的 `SYNTHETIC / NOT LIVE`、`SOURCE_INCOMPLETE`、`DECISION_REQUIRED` 或相应空白/未知边界。合成演示不能把静态文案伪装成 `OBSERVED`、`FRESH`、`VALID` 或 `RUNNING`。

## 6. 动效、场景和可访问性

动画只服务四件事：告知状态变化、建立空间/来源关系、解释数据处理过程、降低内容切换突兀。

v7 把时长收敛为**四档**，共用单一缓动 `cubic-bezier(.2,.78,.2,1)`；不得创建 137ms、430ms 一类孤立值：

| 档 | 时长 | 用于 |
|---|---|---|
| instant | 90ms | 按下 |
| fast | 140ms | hover / focus / selected |
| base | 200ms | 弹层、展开 |
| slow | 320ms | 内容进入、面板切换 |

超过 700ms 的交互动画必须有理由。L3 环境动效最多 1–2 个且 8–14 秒，不能无业务状态循环。

**量化位移（`ADR-09`）**：表达"采样"的动效——传感面扫描带、材料溶解——必须使用 `steps()` 按格跳，且遮罩使用硬停止而非平滑渐变。平滑滑动会把离散采样读成装饰动画。这条只适用于材料层，普通 UI 过渡仍用上表的连续缓动。

永久禁止：鼠标视差、无状态浮动、永久 Ring Spin、代码雨、大面积扫描线、弹跳、360° 装饰旋转、L1 环境循环以及用动画掩盖加载。`prefers-reduced-motion` 下场景停在可读静态状态、路径改为静态高亮、弹层直接出现、粒子/扫描/呼吸关闭，而进度仍由文本/数字表达。

L3 等距场景只能在另获技术和资产授权时进入实现；静态 Style Frame、灰模、材质/灯光、状态机、真实数据绑定、Poster、移动降级、Reduced Motion、性能记录和等价 HTML 都是前置门。当前不得把来源包 V3 的 JavaScript Prism、模拟数值或持续动画复用到产品。L2 只可使用受控局部 2.5D/Poster；L1 禁止品牌级常驻场景。

每个可交互元素可键盘到达，命中区至少 24×24px，主要按钮建议 36–40px，具有双层 Focus Ring，且没有 `outline: none` 的无替代。状态必须以颜色 + 图标/定位 + 文字双通道表达；Tooltip 永远不是必读信息或唯一错误处置入口；场景热点需有键盘、触屏和等价 HTML 列表/树。

## 7. 页面和组件的不可跳过门

新页面在写任何运行时代码前必须有 PAGE 规格，至少固定：页面任务、3 秒答案、5 秒动作、非目标、用户/频率、真实数据来源与边界、L1/L2/L3、唯一主 Pattern、结构与组件、必需状态、响应式、动效、可访问性、禁止元素和验收。页面级动作不超过三个，单一视口仅一个视觉核心。

新组件先查重，再写 CMP 规格，后实现、预览、测试、迁移记录；组件必须说明唯一职责、不负责什么、适用强度、数据/空值、五轴状态、视觉 Token、交互/动效、可访问性、响应式、性能、测试、Decision Log 和废止策略。现有组件升级前先查全仓影响；不可留一套“临时第二外观”。

任何影响 Token、Primitive、Component、Pattern、Page、Motion、Scene 或 Data Truth 的改动，必须同一事项更新 LIDS 规格、对应预览/参考页、[migration-log.md](migration-log.md)、UI Change Manifest 和验证记录。例外必须显式列出规则、原因、影响、复核条件与回退；跨多页例外进入长期决定，不能埋在 CSS、条件分支或截图中。

## 8. 验收与成熟度

每项 UI 工作至少分开回答：任务是否成立、状态是否诚实、视觉是否符合 LIDS、动作是否有真实回执。截图、编译、HTTP 200、toast 或模型文字不能独自证明其他层。

最低视觉验收尺寸为桌面 `1280×800`、`1440×900`、`1536×960`、`1728×1117`、`1920×1080`、`2560×1440` 和移动 `390×844`、`430×932`。无页面级横向滚动；移动端不是缩小桌面场景，而是保留 Topic、状态、原声和主动作，降级/隐藏不重要的仪器层。

LIDS 从 `PROPOSED` 升至 `STABLE` 的证据门见 [README.md](README.md)。在此之前，项目文件可以如实声明 LOCAL-001A 已有受限的 loopback L1 页面与运行时 Token 源；但不能因此声称 LIDS 已获得真实数据/read model、通用组件、L2/L3、3D、Agent、部署或用户验收。
