> 最后核对: 2026-08-21

> 冲突时以谁为准: 当前产品、数据、技术、资产、权限与 SCOPE 的独立授权；原型绝不成为现行代码、状态或页面模板

V3 的定位是**L3 视觉母题与结构审计对象**，不是可复制的生产 HTML/CSS/JS、全站模板或运行事实来源。它可以帮助理解“暖灰画布 + 煤黑结构 + 小面积 Signal 橙红”“对象/系统结构/来源边界三段关系”“原声与解释边界”“PARTIAL + VALID”以及深色 Command Dock 的设计意图。

| V3 内容 | Linggan 中的处理 | 仍不能据此声称 |
|---|---|---|
| Precision Canvas、大网格、Calibration Rail | 保留为 L3 专属视觉母题；L2 弱化、L1 关闭 | 当前任一页面已拥有 L3 或真实观测台 |
| Topic / Scene / Runtime 三段结构 | 仅作为未来 `IntelligenceStage` Pattern 候选 | 真实 Topic、Runtime、Provenance 或指标存在 |
| Raw Voice + Interpretation Boundary | 保留为事实优先的表达原则 | 可展示任何真实原文或已完成隐私审查 |
| `PARTIAL + VALID` | 保留为五轴状态的强制分离 | 当前采集链已经支持这些状态 |
| Observe / Trace / Research | 保留为未来模式语义候选 | 存在 URL、权限或真实操作 |
| 深色 Command Dock | 只保留为 L3/L2 已授权命令面候选 | Agent 已连接、可执行、被授权或已完成 |
| 单文件 Prism 生成、模拟数值、时钟 | 不进入生产；只可结构讨论 | 产品目前有真实场景或实时读数 |
| 全局 Mono、7–10px 功能字、鼠标视差、hover-only hotspot、永久 float/ring/scan | 永久禁止 | 任何例外能靠“更有科技感”成立 |

真正的 L3 场景必须在独立事项中通过 Style Frame、等价 HTML、真实状态绑定、键盘/触屏、Poster、移动端、Reduced Motion、性能和资产许可等门；没有这些证据，静态或场景内容只能是明确标识的合成参考。
