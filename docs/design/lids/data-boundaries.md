> 事实来源: Mog 于 2026-09-02 指定的 `linggan-design-system-v7.html`（§11 数据边界）、[system.md](system.md) 第 5 节 Data Truth、已确认数据合同
> 冲突时以谁为准: 真实数据合同与 [system.md](system.md) 的五轴状态定义；本文件只规定这四种极端情况的**呈现方式**，不改写状态资格

## 1. 这份文件解决什么问题

组件在设计稿里总是拿到长度合适、字段齐全、数值中等的数据。真实数据不是这样。四种极端情况在每个页面都会出现，而**如果规范不给确定答案，每个实现者会各自决定一次**——于是同一个"未知"在三个页面长成三个样子。

**没有跑通这四种情况的组件不算完成。** 这是组件规格（CMP）的准入条件，不是可选的健壮性加分项。

本文件与 [system.md](system.md) 第 5 节的分工：
- system.md 定义**状态是什么**（`UNKNOWN` 表示尚未获得或无法验证）；
- 本文件定义**它长什么样**（显示 `—`，素材轨全灰，检视面板说明下一步）。

## 2. 四态

### 边界一 · 超长文本

| 元素 | 处置 |
|---|---|
| 标题 | 两行截断（`line-clamp: 2`） |
| 作者名 | 单行省略号 |
| 标题区 | **不设 `min-height`** |
| 卡片高度 | 由内容决定，靠 grid 对齐 |

给标题区设 `min-height` 是最常见的错误处理：它让短标题卡片下方多出一块空白，而长标题卡片仍然溢出。**对齐由 grid 承担，不由每张卡片自己撑高度承担。**

### 边界二 · 字段缺失

**缺失不显示为空白，也不伪造默认值。**

| 情况 | 处置 | 禁止 |
|---|---|---|
| 作者未知 | 用降级色文字明说「作者未知」 | 留空、显示占位人名、显示平台名冒充作者 |
| 无封面 | 媒体区显示占位图标 + 说明（如「封面尚未采集」） | 灰块、随机色块、插画替代、拉伸其它图 |
| 目标未绑定 | 明说「目标未绑定」 | 显示第一个可用目标 |

空白会被读成"这个字段不存在"，默认值会被读成"这个字段的值是这个"。两者都是对事实的改写。

### 边界三 · 零值与极大值

**零是事实，未知是缺失。两者绝不混用。**

| 原始值 | 展示 | 含义 |
|---|---|---|
| `0` | `0` | 已确认数值为零 |
| `null` | `—` | 无适用值 / 尚未获得 |
| `9,439` | `9,439` | 精确值，等宽数字 |
| `1,234,567` | `123.5万` | ≥10,000 缩写；**悬停显示精确值** |

所有数值使用等宽数字（`tabular-nums`），保证列对齐。缩写只是显示层，精确值必须仍可获取——缩写不得成为精确值的唯一存在形式。

本条与 [system.md](system.md) 的既有规定一致并细化了它：`0` 只表示已确认为零；无适用值为 `—`；尚未获得或无法验证为 `UNKNOWN`；不适用为 `N/A`。

### 边界四 · 状态未知

**未知不是失败。**

| 元素 | 处置 |
|---|---|
| 素材轨 | 全灰 |
| 状态词 | `UNKNOWN` |
| 检视面板 | 说明**下一步动作** |
| 禁止 | 红色错误态、失败图标、`0`、隐藏该对象 |

把 `UNKNOWN` 渲染成红色错误，等于告诉用户"这里出问题了"，而实际情况是"我们还没看过这里"。这两件事的用户下一步动作完全不同。

## 3. 与状态五轴的关系

四态是**呈现契约**，不是第六条状态轴。映射关系：

| 数据边界 | 对应的状态轴取值 |
|---|---|
| 字段缺失 | Coverage `EMPTY` 或 Validity 之外的独立缺失；按数据合同判定 |
| 零值 | 任一轴的**已确认**取值，不是缺失 |
| 状态未知 | Freshness `UNKNOWN` / Truth 未建立 |
| 超长文本 | 与状态无关，纯排版 |

不得因为一个字段缺失就把整个对象降级为 `INVALID` 或 `FAILED`。`PARTIAL + VALID` 仍是一等状态（见 [system.md](system.md)）。

## 4. 验收

组件规格（CMP）与页面规格（PAGE）必须分别记录四态的实际渲染证据：

- [ ] 超长中文标题：两行截断，作者单行省略，卡片高度不因它塌陷或溢出；
- [ ] 字段缺失：作者未知 / 无封面 / 目标未绑定 三种分别有明确中文说明，无空白无默认值；
- [ ] 零值与极大值：`0` 与 `—` 分别正确，≥10,000 缩写且精确值可悬停获取，数字列对齐；
- [ ] 状态未知：全灰 + `UNKNOWN` + 下一步说明，不呈现为错误。

四态的截图证据不能互相替代，也不能用"数据里暂时没有这种情况"跳过——**没有这种数据时用合成 fixture 验证，并在验收记录中标明它是合成的**。
