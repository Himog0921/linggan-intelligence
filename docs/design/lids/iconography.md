## 已采用标准

唯一参数源为 [iconography.json](iconography.json)，实现为 [IntelligenceIcon](../../../apps/web/src/shared/IntelligenceIcon.tsx) 与其[样式](../../../apps/web/src/shared/IntelligenceIcon.css)。本地 SVG 独立实现，不依赖 Lucian 在线资源、远程图标服务或动画运行库。Lucian 的部件时序与 Pele 的克制层级仅作为研究参考。

24 单位网格、1.5 主线宽、最多两层；内容优先保留轮廓和一条识别线。外沿继承当前文字颜色，橙色只承担少量后沿/承托面；状态图标继承状态文字的语义色。13–18px 原位与放大示例使用同一几何，不在小尺寸叠加细节。

| 角色 | 图标 |
| --- | --- |
| 侧栏 | 证据库、评论研究、创作者、折叠、展开 |
| 底稿工具栏 | 数据时间、待补内容、内容就绪、章节导航、刷新、导出 |
| 阅读、导出窗口与布局 | 复制、专注阅读、关闭、标准宽度、加宽、专注宽度 |

## 动作与状态

操作反馈为一次 640ms 的起势、承接/短暂停留和收束；这是本套已批准的组合图标反馈档。章节开合使用 320ms，并绑定真实 `expanded`。其他 UI 过渡继续按既有动效档执行。几何位移、部件关系和关键帧由同一组件样式维护，时长、缓动、线宽与透明度从参数源同步到唯一 `lids_tokens.css`。

刷新仅一次半转，前后轮廓严格对称；复制移动前层，专注阅读两端向外，关闭轻收，侧栏箭头沿操作方向轻移。时间、待补、就绪保持静态。图标动画不代表命令正在执行、内容已刷新、文件已下载或业务成功；这些结果只由原有状态文字和真实回执表达。

反馈仅在可用按钮/链接的 hover 或 focus-visible 出现，禁用控件不播放。图形为 `aria-hidden`、不可聚焦，名称、命中区、禁用、权限和操作处理仍由所属控件负责。减少动态效果时关闭动画/过渡并隐藏装饰描线，章节朝向继续表达真实开合。

## 正式接入与展示

语料导航三入口和共享侧栏开合、研究底稿工具栏/阅读/导出窗口、证据检查器宽度和关闭直接引用共享组件。其他导航图标保留原实现；本条不推导新的业务动作或权限。

真实组件展示进入现有设计系统“字体与材质 → B 图标标准”，展示全部 17 枚、32/18/15px 尺寸和指针/键盘反馈。`ICON-B-001` 作为 `design_asset` 合同登记，不占用 C49，也不把其他组件自动认证为 CMP。规则、源指纹和离线 HTML 由 `lids:record / lids:sync / lids:check / lids:build` 同步。
