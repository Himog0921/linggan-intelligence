## 4. 走查中发现并修正的问题

1. **共享页头放不下第 6 项**：加了「运营」后，在 1181–1361px 和 1501–1545px 宽度下「个人菜单」被截掉一截（main 原本也在 1181–1257px、901–970px 截）。改为页头自己的收紧台阶：
   - 1560px 及以下沿用原 1500px 档；
   - 1380px 及以下去掉品牌副标题和弹性留白，导航项收到 90px；
   - 1240px 及以下隐藏导航里的英文旁注；
   - 960px 及以下导航项 80px。

   服务状态胶囊仍保留到原 1180px 档。901–1920px 的 29 个宽度在运营页和语料页都不再截。手机 390px 上「运营」换到第二行，这是 2026-09-02 定下的壳层规则（「未来职责自动换下一行」）。
2. **运营人页签放不下时被藏起来**：1280px 下发布记录只看得到 3 个人，其余要横滑而且看不出还有（工作台也是这样）。现在发布记录的运营人页签单独占一行，筛选另起一行；账号管理、每日数据放不下时换行。手机上仍可横滑。
3. **媒体列写「无封面」**，会被读成帖子没有图片 → 改为图标加「封面未迁入」，与状态词典一致。
4. **导入面板的输入框看起来能填** → 改为统一的灰色禁用样式。
5. **平台页签与运营人页签挨在一起分不清** → 平台页签加了分隔线。
6. **读取失败时显示英文原因**（浏览器的 Failed to fetch 或接口代码）→ 改为中文原因；读数和表格一起失败时合并成一条提示，一次重试两处都重读。
7. **快速切换运营人时，旧回包可能盖住新筛选** → 只让最新一次请求写入表格。
8. **封面大图弹窗被拉满整屏** → 按图片大小显示。
9. **导出说明在窄屏不换行，压到导入面板** → 改为换行，并注明「每日数据不分业务」。
10. **业务选择器的账号数包含已删账号**（131）→ 只数在台账的（95），与账号管理一致。
11. **导出 CSV 的「数据截至」用国际时间** → 改为北京时间并在列名注明；JSON 仍给国际时间。
12. **手机上读数占三行** → 改为每行 3 个，表格多露出一行。
13. **接口合同把失败回包写成 `error` 字段** → 按代码改为 `code` 字段，并列出四个代码。
