## 3. 视觉工作条件

- 视口：1440×900、1280×720、1024×768、390×844
- 数据密度：第一个领域 27 位作者（超过一页的 25 条，翻页有内容）、第二个领域 2 位；每位作者一篇作品，无封面图片字节、无头像（显示名字首字与符号占位）、无自动分析结果
- 设计依据：[页面规格](../pages/creators-page.md)；外壳样式唯一来源 `shell.css`；Token 唯一来源 `lids_tokens.css`；页面样式为 CSS Module，`tokenDiscipline.test.ts` 自动检查不写死颜色、字号与间距
- 与旧页面的有意差异：见[阶段 D 分册 §3.1](../../plans/active/web-react-001-d-corpus.md) 中标「△」的各项（先确认再加入、未完成与未确认分开、头像封面名称随状态、封面 3:4、普通层不露机器语言、时间统一、≥1 万缩写、采集状态词三页统一）
- 减少动态效果：本页无动画；外壳沿用 `shell.css` 的 reduced-motion 规则
- 截图证据：本机证据目录（未入库，按[生成物登记](../../governance/generated-artifacts-registry.md)处理）；CI 中作为 `web-app-real-chain-proof` 产物保留 7 天；本次保存了列表、抽屉、调整判断、加入确认、材料范围、领域切换、证据库往返、四个视口的截图

## 5. 发现与后续

- 迁移中发现并修正的旧页遗留：① 没有选择器时面包屑出现「语料 /  / 创作者」的空段；② 地址里的 `domain` 不是 UUID 时旧页直接 400，新页按「未选领域」处理；③ 没有任何领域时旧页只写「请选择领域。」没有出口，新页写明原因并给「前往领域管理」；④ 刷新失败但页面仍是上一次的内容时旧页没有说明，新页明说不是最新；⑤ 三个语料页的一级导航「采集」状态词互不一致（创作者页与评论研究页恒为「状态未知」，证据库页取真实值），新页统一取服务器值。
- 验证中发现并已修复的两处：调整判断对话框的支持材料分组默认折叠（旧页默认展开），改回默认展开；用户改动判断或勾选后，「请选择至少一项当前材料」的本地提示仍挂在底部，改为撤掉。两处都带测试断言，并做过变异检查。
- 协调方复核时发现并已修复：「刷新结果」主按钮平时显示成普通描边按钮（`.primary` 的优先级低于 `.page button`，只有悬停才变色），旧页平时是墨色实底；改为 `.page .primary`，修后重跑前端检查与浏览器证明。
- 是否需要 DECISION_REQUIRED：① 采集状态词是否照搬旧页恒为「状态未知」（本次取服务器值）；② #384 后台字段（取样篇数、作品标题；后台修复已拆为 PR #435）合入后补一条真实链路断言；③ 主计划里 #384 的状态词已由协调方同步（#384 已关闭）。均见[分册 §3.2](../../plans/active/web-react-001-d-corpus.md)。
- 不得因此推断：隔离环境通过不等于运行实例已部署；合成数据里没有自动分析结果，不等于真实模型结果的呈现已被证明；#435 的后台字段在主线接口出现之前，页面只能诚实地写「未记录」。
