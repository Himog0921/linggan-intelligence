## 验收方式

- 基线：`localhost:3000`，`origin/main @ 1aab2b2`

两者连接同一本地环境，差异仅来自本次改动。所有数字为浏览器内实测，非估算。

### 关于边框只减少 4 条

必须如实记录：样张阶段的 194 → 100 是在**有五条材料卡片**的前提下测得的，其中约六成减量来自卡片上的状态徽章与封面块去框。当前运行时页面处于空态，没有任何卡片，因此这部分规则尚无对象可作用。

**本次不能声称「线条减半」。** 页面级规则（导航、栏目、上下文行纹理、引用块 side-stripe）确实生效并贡献了这 4 条，但完整收益要等真实 Discovery 卡片进入窗口后才能复测。届时应重新计量并更新本记录。

## 3. 结构与无障碍

| 项 | 结果 |
|---|---|
| `<h1>` | 保留为「证据库」，视觉隐藏（实测宽度 1px），仍被 `aria-labelledby="page-title"` 引用 |
| 文档标题层级 | 由「无 h1」改善为「有 h1」，此前 audit 发现的缺口在本次顺带修复 |
| `prefers-reduced-motion` | 生效，位移与过渡全部关闭 |
| 焦点样式 | 新增 `:focus-visible` 描边；**键盘可达性整体仍未修复**（列表行不可聚焦、表单缺标签、下拉缺 ARIA），另立卡 |
