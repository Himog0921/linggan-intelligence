## 3. 视觉工作条件

- 视口：1440×900、1280×720、1024×768、390×844
- 数据密度：一条连接、一个模型、两到三条调用记录（合成）
- 设计依据：[页面规格](../pages/model-ai-settings-page.md)；外壳样式唯一来源 `shell.css`（与旧页面同一份）；Token 唯一来源 `lids_tokens.css`；页面样式为 CSS Module，`tokenDiscipline.test.ts` 自动检查不写死颜色、字号与间距
- 与旧页面的有意差异：删去与面包屑重复的小标题；「StudyRun」改为「研究批次」；接口协议显示中文名；内容区可滚动；默认配置四个数字框一行排开（窄屏折行）；回执按成功/失败/未确认三种语气区分；时间改为统一写法 `YYYY-MM-DD HH:MM`
- 减少动态效果：本页无动画；外壳沿用 `shell.css` 的 reduced-motion 规则
- 截图证据：本机证据目录（未入库，按[生成物登记](../../governance/generated-artifacts-registry.md)处理）；CI 中作为 `web-app-real-chain-proof` 产物保留 7 天

## 5. 发现与后续

- 迁移中发现并修正的旧页面缺陷：①内容超过一屏时整页无法滚动，下方调用记录看不到；②编辑已有连接且模型 ID 不变时，旧页面沿用旧版本的模型编号，必然得到「设置已变化」；③测试请求的重放回执把结论放在 `result` 里，旧页面一律显示「未通过」；④由其他入口建立的连接（如本机 WeMM）编辑时，协议会被悄悄改成列表第一项；⑤重试一律换新请求编号，网络中断后重试可能重复发起测试。
- 是否需要 DECISION_REQUIRED：共享外壳是否改用 V3 紧凑外壳，留到后续阶段由 Mog 决定（迁移期两种页头必须一致）。
- 不得因此推断：隔离环境通过不等于本机运行实例已部署；合成凭据下的测试失败不代表真实模型连接有问题。
