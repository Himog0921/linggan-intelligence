## 用户结果

同一个插件服务两个清晰使用者：Linggan Intelligence 可以采集并获得按 lane 分开的本机接纳回执，不会弹出或触发人工媒体下载；人工使用者仍可显式打开原有媒体选择窗口并按需下载。搜索与评论滚动以真实新增内容、页面状态和预算停止，不以固定首屏数量或固定等待假装完成。

## 明确范围与非目标

### 范围

1. 将“当前笔记”页面入口拆为 Intelligence 采集与人工媒体下载两个显式动作。
2. 详情、评论、媒体观察分别报告接纳状态；任何 lane 未证明接纳时不得称整个详情包已接纳。
3. 为搜索页和评论容器收紧现有滚动：稳定内容身份去重、可观察加载/到底信号、有限预算、`NO_PROGRESS` 与风险停止事实。
4. 更新插件说明、小红书能力登记和当月进度记录。

### 非目标

- 不读取 Cookie、账号秘密或隐藏平台数据。
- 不规避验证码、风控、频率限制或访问限制；这些信号均停止。
- 不自动下载媒体，不改媒体权限，不新增 OCR/ASR，不扩大真实采集范围。
- 不删除旧人工媒体下载窗口，不修改旧内容工作台运行时、SCOPE-001 或 root checkout 中已有脏文件。

## 已确认事实

- 真实搜索页筛选会实际改变结果；页面连续滚动可继续增高，单次可见卡数不是加载完成依据。
- 真实详情页有独立评论滚动容器、非空评论与按需展开的回复。
- 本机最小样本的详情记录已进入 Linggan；本轮未下载媒体。
- 当前 `collectNote` 先执行详情采集，再弹出人工媒体选择窗口，造成两个用户意图混淆。

## 实施步骤与可证伪验收

1. **入口分流**：为人工媒体下载设置显式动作；Intelligence 详情动作完成后仅显示 lane receipt。\
   验收：Intelligence 路径从不调用媒体选择/下载；人工路径仍调用同一选择窗口。
2. **详情回执**：保留 content、comments、mediaSlots 三 lane 的实际状态，形成中文可读摘要。\
   验收：测试中任一 lane pending/rejected 时整体不称“详情包已接纳”。
3. **自适应滚动**：保留有限页面动作，记录稳定 ID 增量及每轮事实；无新增不是完成，风险立即停止。\
   验收：搜索/评论测试证明新增 ID 才重置无增量计数，`NO_PROGRESS` 不写为页面结束。
4. **说明与记录**：同步 README、能力登记、计划索引和月度记录。\
   验收：治理检查通过，文档清楚区分代码、真实页面和接纳证明。

若需要新增平台权限、下载行为、账号使用、外部服务、真实材料保存范围或数据合同，停止并报 Mog；不得以随机延迟、会话轮换、验证码处理或其他规避机制替代正常页面加载判断。
