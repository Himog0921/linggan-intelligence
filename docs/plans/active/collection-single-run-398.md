## 验收矩阵

- 临时关键词采5篇：名单/周期不变，指定领域下详情、作者、样本可查。
- 多领域同目标：只按本次领域执行，不改长期关系。
- 深采50篇：超过30继续，回复不被2条限制截断；仅发现37则保留37与原因。
- 已选材料：不重新搜索，复用详情与本次新增分开。
- 暂停/刷新/重启/继续：集合不变；停止后迟到回执不重启。
- 30→500→30：累计集合保留，覆盖分次，不覆盖历史。
- 明确无评论与不可访问分开；清洗数不影响采集配额，有效回复上下文保留。
- 任务筛选、领域、分页、统计与返回一致；来源关键词不伪造全文。
- 管理弹窗先列表再编辑、失败不丢草稿、完整工位能力可达。
- 有数据浏览器对照原Demo：比例、工具栏、截断、列宽、滚动、焦点与失败态；空库smoke不能替代。
- 隔离50篇编排不冒充真实平台；真实平台验证另行授权。
