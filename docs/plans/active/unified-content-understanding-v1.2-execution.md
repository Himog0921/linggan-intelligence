### L0 材料就绪实施（Mog 已确认）

本轮按 Mog“确认按照这个标准来”实施：领域沿用证据库入库归属，保留领域使用资格，不再新增语义领域判断。图文需要原生文字的已知状态及完整正文图组，不等待静态图片 OCR；视频需要原视频及适用的 ASR／抽帧结果，无音轨、未检出语音或画面文字不等于处理失败。原帖空正文不算缺失；总图数未知不能冒称完整；实况照片按静态图处理。保留同源有效旧读本，不因新的处理失败抹掉可用材料。

复用 Evidence 唯一底稿的材料记录，在同一后端投影中生成就绪状态；预检、启动、执行前和页面使用同一判据。未准备好时不调用理解模型，既有媒体步骤继续按原机制处理，不新建队列或自动全库生成任务。视频结果明确限定为口播与已提取画面文字，不扩展完整视频视觉能力。保留同材料幂等、来源冻结、结果未知不重发。

UI 影响：证据库既有列表材料区域增加简短状态，原底稿理解区域说明具体缺项和视频覆盖范围；沿用 LIDS 现有文本与提示样式，不改导航、页头、列布局、标准件或设计值。正常完成不新增泛化警告，局部不清仍保留其余理解。打开、刷新、重试读取只 GET，不新增生成按钮。
