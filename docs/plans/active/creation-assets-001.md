## 3. 各片说明

### S1a 资产与检查

- **内容**：账号身份（与机构关系、简介是否写明、背后有无真人及其角色，不写真名）；产品事实卡；衔接句库（入库检查、待审/可用/停用、审核）；稿件的衔接位与“这篇不植入”；三级检查（规格附录 A 的 R-M1–M4、R-W1–W3、R-W6–W11、R-I1–I2、R-L1–L7）；复制到小红书（A.4）；稿件状态“草稿中 / 已复制”。
- **规则只有一份实现**：检查在服务端（Rust）实现，前端防抖调用检查接口，不在前端再写一套；有必改就不能复制（离线时不能复制）。复制回执记录规则集版本与产品事实卡版本。词表类规则只提醒，不挡复制（DEC-0012 第 5 条）。
- **前端放哪**：资产库页放在「运营 › 创作」的页面分区里；检查面板与复制按钮先作为页面内组件挂在现有正文页，S2 新写稿页上线时把**同一个组件**迁入、旧页面同 PR 删除，全程只有一份检查实现。
- **验收**：规格场景 V1、V2；每条规则有正例、反例、边界例（合成数据）；产品事实卡改了，检查跟着变。
- **验证**：规则单元测试；隔离 PostgreSQL 的迁移与合同测试；真实浏览器场景。复制格式的真机验证暂不做（Mog 2026-10-28），按 A.4 格式上线。
- **授权**：跑迁移（共享库写入）要 Mog 在开工评审时授权。
- **PR**：1 个后端（迁移、领域、检查服务、API），1 个前端（资产库页、检查面板、复制）。
- **进展（2026-10-28，Mog 说“开工”）**：后端候选已实现，合同见 [CREATION-ASSETS-001](../../data-contracts/creation-assets-001.md)，通过隔离 PostgreSQL 与 HTTP 证明。前端候选已实现（创作页「资产库」分区含账号身份、产品事实卡、衔接句三类；正文页「检查与复制」面板），通过组件测试和真实浏览器链路证明；与页面规格的差异见 [页面规格 §0](../../design/pages/creation-assets-pages.md)。迁移编号暂用 0181（别的在途分支已占 0169–0180），提 PR 与合并前要再核对一次。
- **不能开工的条件**：Mog 在开工评审里说“开”。产品事实卡（Mog 或运营组长填写并确认）和 2–3 个试点账号的底细**不挡开发**（开发用合成数据），但挡**真实使用**。

### S1b 个人经历资产（保护车道，敏感，仅本机）

- **内容**：人设事实（含新旧冲突处理）；经历库（采集、本人确认、同意记录、讲过几次）；稿件里的经历位与经历来源标记；经历相关检查（R-M7、R-M8、R-W4、R-W5）；撤回时沿引用传播。
- **验收**：规格场景 V8；本人未确认的经历不能进稿件；别的账号的经历不挪用；撤回后稿件、样板和“AI 会看到的内容”里不再出现。
- **敏感材料的约束**：只在 Mog 本机使用，不进 Git、不进日志；任何 Agent 都不读取真实经历（测试一律合成数据）；数据模型记录归属账号与创建人，可见范围在 S0 生效。保留：随账号存续，本人撤回就删，具体期限等合规意见后定。
- **PR**：1 个后端，1 个前端。
- **不能开工的条件**：S1a 完成；Mog 说“开”。

### 7.0 第一阶段（Mog 2026-10-28 的决定）

- 第一阶段**不做**写手可用性测试、两周对照试用、耗时基线和手机真机格式验证。
- 做法：每一片上线后，Mog 用真实账号亲自写稿，走对应场景（规格 V1–V10），把卡住的、多余的、不对的告诉执行方；运营的实际反馈由 Mog 转述。验收以场景在真实链路通过，加上 Mog 的使用判断。

### 7.3 两周对照试用（扩充团队时）

- **人与账号**：3 名熟练度不同的写手；每人固定账号；不要求全队切换。
- **设计**：同人同账号、近似题材、交错顺序，复用与试新分层；一周现法，一周新界面，或按日交替（届时选定），避免“先后顺序”影响。
- **门槛**：写一篇的中位耗时下降 20%；衔接句可用率达到 80%（盲评：隐去来源，由运营负责人和另一位写手各自独立判断，分歧保留）；至少 2/3 的写手愿意继续用（试用结束时各自表态，不以被要求使用代替）。
- **不做的结论**：两周看不出爆款率有没有变化，不作为门槛，也不在结论里写“提高爆款率”。
- **允许不植入**：选择“这篇不植入”的稿子不计入衔接句可用率的分母，但计入耗时。
- **数据**：只汇总计数和中位数，写手代号对应关系放私有目录；发布沿用团队现有审批流程，不为试验增加刷量或重复发布。
- **结果怎么用**：达到门槛——继续做并延长观察；未达到——缩到最有效的一步，或停。
