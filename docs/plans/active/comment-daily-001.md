## 固定业务合同

- 接纳且可读后立即检索，不等待清洗或模型。所有正文仍由 Evidence 持有；清洗是带版本的派生材料，非删除操作。
- 稳定评论身份按作品与平台评论身份；首次进入已接纳的评论语料投影时间（material.created_at）用于日批，重复观察/互动更新不算新增。同文跨作品不合并。历史补跑独立明确选源。
- Cleaner v1 保守规范空白/明确编码，保留否定、emoji 与 ZWJ；直接分析/需上下文/低信息/异常分别统计。原文→清洗→外发字符映射可验证，联系方式仅在外发载荷遮盖。没有可靠历史脚本时不能宣称继承旧规则。
- 自动批次 Asia/Shanghai，每日前日23:00（含）至当日23:00（不含）；首次启用从启用时间起，不隐式补跑历史。服务错过截点时逐批补建，来源版本选择截止时已进入语料投影的版本。23点只固定清单，清洗延迟保留在同批。
- 模型调用按同作品清洗合格来源分包，预算不足拆包；确切来源清单和上下文引用冻结。已有媒体派生文本通过 Work Resource 引用，未取得则说明；不新发采集或媒体任务。
- 模型只返回包内评论引用、原文片段与既有研究维度；引用由程序精确定位，重复片段要求消歧，缺字段返回空；语义质量不等于协议质量。输入中的指令无工具权限。
- 同一调用复用既有 invocation 账本。未知用量保留预留；无供应商幂等保证时不承诺远端恰好一次。失败与无信号分开，结果按评论接纳并可见部分失败。人工修订不被机器覆盖。
- 本包日结果为结构化研究与处理明细，不生成虚构趋势或领域占比；问题组仍为显式标签归组。

## 当前运行细节与边界

- “每日新增”按服务端首次生成评论语料投影计数；评论发布时间、采集观察时间和 Package 接纳时间各自保留。Package 先接纳而评论投影迟到时，进入投影实际到达的下一批，不回写已经冻结的清单。
- 清洗状态是当前可变派生结果；筛选适用于全部匹配来源，分页 cursor 绑定文字/作品/清洗条件。已存查询当前仅保存文字和作品范围，弹窗明示不保存清洗状态。
- 失败仅经“重试失败”显式重排，使用同一批次剩余额度及每条原次数上限。上下文不足需在材料取得后重新选择；不自动扩采。来源数上限之外仍列在原批次，需明确另选才分析。
- 调用期间暂停不会撤销远端计费；本实现停止接纳该次结果，记录失败和真实或未知用量。未知消耗不释放预留，重试不保证远端恰好一次。
- 模型输出要求片段与多维标注，不要求模型生成 hash 或字符位置。程序从外发文本映射回不可变原文，存内部引用、Unicode 范围和版本；事实表达与推断分开。当前没有 Provider JSON Schema 能力协商或结构化输出参数升级，依赖严格后验验证。
- 联系方式遮盖是有限规则，不能宣称完整匿名化；真实材料外发需要明确供应商、样本、额度和用途。Pi 无采集/数据库/发布工具，也没有启用研究 Skill 或自主扩展问题循环。
