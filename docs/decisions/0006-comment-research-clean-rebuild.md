# DEC-0006 · 评论研究开发期破坏性重建

> 状态: 权威当前
> 最后核对: 2026-09-16
> 适用范围: Issue #295 的本机评论研究重建、reset/init、来源选择与语义输入
> 事实来源: Mog 2026-09-16 明确授权、现行 Evidence schema、独立复审
> 冲突时以谁为准: 用户最新决定、AGENTS.md、真实运行/数据库副作用、当前代码与测试

## 决定

本机开发期不保留任何既有评论研究派生数据或其兼容路径。评论研究的旧 Policy、Derivation、Run、调用账本、Atom、Problem、membership、embedding、结果版本、旧 API/read/worker 及 V1/V2/V3 合同将被删除，并由一个单一当前合同重新建立。

保留原始 Evidence 与其资格事实：作品、评论、CapturePackage、来源归属、`domain_ref`、撤回/受限状态及其他业务域数据。reset 只能作用于本机运行库的评论研究派生层；必须逐表列出目标、事务性清空、写入 reset receipt，并拒绝非本机配置数据库。

一个评论只能在其作品 `domain_ref` 与当前 ADHD 研究域相同、作品与评论当前可读且未撤回/受限时成为候选。作品标题、正文、OCR/ASR 只有在同一可读性 gate、来源归属和冻结时间边界下才能成为上下文。它们只能解释主题或指代；Atom 证据只能逐字来自当前目标评论。

## 后果

- 历史 migration 文件继续作为已经应用 schema 的不可变 ledger 保留，但不构成新系统运行路径或兼容保证。
- 新实现不得读取、回放或迁移旧评论研究数据；reset 后需从原始 Evidence 重新选择。
- 真实模型调用、自动重跑、共享数据库操作、部署、`main` 合并和 3000 runtime 切换仍需单独授权。
