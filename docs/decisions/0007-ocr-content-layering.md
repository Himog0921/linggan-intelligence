# DEC-0007 · 图片 OCR 内容分层与标题补位

> 状态: 权威当前
> 最后核对: 2026-09-20
> 适用范围: Linggan 本地图片 OCR、OCR 派生文本、封面主文案、证据库展示标题和受控视觉语义分类
> 事实来源: Mog 2026-09-20 对 50 张本地封面 Tesseract/Paddle 对照的验收、当前媒体生命周期合同与代码
> 冲突时以谁为准: 用户最新确认、AGENTS.md、真实代码/运行结果及当前数据合同

## 决定

1. 图片与视频帧 OCR 不再使用 Tesseract；本地 PaddleOCR 是唯一识字引擎。
2. OCR 先产生不可改写的原始文本、逐行坐标和置信度；语义层不得生成不在原始 OCR 中的正文。
3. 语义层生成两个独立的派生视图：`cover_headline`（作者在封面上突出表达的主文案）和 `image_substantive_text`（图片中可用于语料的实质文本）。二者不覆盖 OCR 原文，也不互相替代。
4. 标题展示固定为 `原始平台标题 → 首图 cover_headline → 前三张图片的 cover_headline → 标题未知`。OCR 补位必须公开其来源，不能伪装成平台原始标题。
5. 平台水印、应用界面、衣物/环境偶发文字和非作者表达的背景文字可被排除，但排除决定必须记录原因、命中的 OCR 行和规则/模型版本。
6. 本地规则负责显著性、边缘位置、重复水印和平台界面等确定性判断；复杂图片可进入受控视觉模型。视觉模型只选择/分类已识别行，无法使用受控视觉配置时保持 `NEEDS_REVIEW`，不发送图片、不猜标题。
7. Mog 授权历史 Tesseract OCR 派生物退出可读/检索路径并清理其派生文件；原始媒体、Evidence、处理事件与非 OCR 派生不在处置范围。处置以可审计失效事件实现，不能静默删除来源事实。

## 后果

- `ocr_raw`、`ocr_layout`、分层结果和展示标题来源成为不同事实；搜索和语料读取不得把它们合并为单一“图片文字”。
- 新模型或规则版本会创建新的处理作业和结果，不能改写旧版本。
- 视觉 AI 是外部处理边界：只有明确配置的视觉模型、最小必要图像和有调用账本的请求才可执行；部署或保存配置不自动授权真实调用。
