# DEC-0011 · 第一代 AI 的任务与材料边界

> 状态: 权威当前
> 最后核对: 2026-10-19

> 事实来源: Mog 2026-10-19 当前会话确认及正式派单，Issue #454
> 冲突时以谁为准: Mog 最新明确决定、真实来源和执行合同

## 决定

第一代只在 ADHD 实现每篇解读/方向清单及主题视图、创作者汇总与公开简介判断、多轮写作。AI 模型、自动化/额度、skill、运行状况集中在设置页，业务页保留业务结果和一句话状态/暂停/去设置。该决定替代旧文档“不建设万能 AI 中心”的相应产品限制，不改变 Topic、Claim、Decision/Action 等领域分责。

研究底稿是 AI 读取笔记的唯一入口。内容身份、来源血缘、当前使用资格分开；版本/输入变化按合同处理，点赞与重复观察不应触发重读。一个主方向、最多一个也相关，允许暂无；人工裁定保留。方向清单由 Mog 确认发布，库内变化不冒充市场趋势。

第一代 skill 只导入、版本管理、试跑比较和启用；本地改文件后重新导入，不做在线内容编辑。每篇解读当前不设每日上限，先取得测试实耗再配置；不是新调用/全库回填或自动运行批准。外发按工作、供应商与材料范围明确，可撤回。

PR-1A→1B→1C 顺序、同一主执行任务、独立 PR 和收尾审查。第二/三步按各自替代范围删旧；材料、证据、调用账保留，评论研究冻结。#420 保留底稿验收；#452/#453 负责评论页遗留；#435 搁置；媒体积压、持续观察、测试 schema 清理独立安排。

## 本次实施许可

Mog 明确授权 PR-1A 代码、隔离测试、Draft PR。没有共享库迁移/回填、媒体或采集恢复、真实模型、合并部署或后续底座实施许可。普通技术选择自主推进，每 PR 收尾一次审查，范围内修正不反复整轮。

详见 [统一计划](../plans/active/ai-gen1-001.md) 与 [材料输入合同](../data-contracts/note-material-input.md)。本决定没有声称第一代 AI 已上线或 Mog 已完成质量验收。
