### 产品职责到运行时的解释边界

本文中的判断守卫、缺口巡视、新说法侦测、选题猎手、战绩回收，是首页需要持续回答的**五类问题和产品职责**；总编是聚合、去重、资格检查与首页发布选择责任。它们不等于六个 Agent、进程或服务，也不要求所有事实由 Agent 生成。首页事项必须来自可追溯、经过资格检查的领域事件、Observation / Claim 变化、请求或运行状态；五类职责负责组织与解释这些材料。运行时最终由规则、统计、单 Agent、多 Agent 或人工怎样分担，留给 `first-phase-runtime` 决定。

等距地形、6–8 区、三栏、3 日规则和推送等现有 HOME 体验决定，仍须在 `p0-surface-prototype` 中用真实脱敏样本验证取舍；它们不是技术实现授权，也不能由本次语义澄清替原型票给出答案。

## 一句话结论

> **首页是「昨夜世界与系统各发生了什么」的日报，主语是领域不是机器。三栏骨架：左栏是目录与语料，中间是恒定领域地形加昨夜行动轨迹，右栏是待决定与编队状态。它每天必须给出新的当日状态回执；有新事项时每一项都必须能说清出处，没有合格新增或观察不完整时也必须如实说明。**

│              │                                  │                      │

### 左栏

左栏是**这一页的目录**，不是另一份内容。每条昨夜叙事对应下滚区一张具体卡片，点击滚动定位。读完左栏即读完今天全部目录，消除左栏与下滚区的重复。

叙事使用人话，技术细节按需展开。Agent 必须主动报告自身不确定性，例如「不确定这是真的变化，还是因为本周新增了两个观察对象」。

左栏底部每天保留「今日语料」槽位，与今天的事项无关。它标为语料而非情报，附「能说明什么／不能说明什么」，可一键进入完整上下文、所在内容与同类表达。候选规则为：当前每日版本新进语料中场景具体、有动作细节、非泛化抱怨、此前未展示过；没有合格新增时显示「今日无合格新增」，观察本身不完整时显示「今日语料观察不完整」并说明缺口。不得复用旧材料冒充今日新增。

左栏条数决定下滚区长度：目录三条，下面就三张卡。「少量」这条纪律在版面上自动成立。

### 中间

底层是恒定领域地形。恒定性落在大区层，空间记忆建立在这一层；Topic 小地块可增删合并而不破坏整体构图。分区归属由词表治理管辖，移动地块只产生导航变更提案，不改定义、知识关系或历史分类。

上层是昨夜编队的行动轨迹：出发、落地、作业、带回材料或断在半途。**每个动作必须编码一个真实事件，永动即噪音。** 没有事件时地形静止，静止表示昨夜世界没动，这是有效情报而非缺陷。

地块详情走就地浮层，三五行说清当前状况，需要更多则进入 Topic 工作区。

荒地必须可见：一个大区长期没有新材料时明显变暗、变矮、开裂。这是缺口巡视要报的重要情报，不能因为「没有数据」而让它从地形上消失。

### 右栏

上半是待你决定：补采申请、知识变更提案等有后果的决定包。没有时必须明说「今天没有需要你决定的事」，这是有效信息不是空状态。

下半是编队状态。跑完、跑了但失败、根本没跑，三者视觉上必须完全可分。**静默降级按事故处理**：任何成员未跑完，状态必须刺眼，不得是一个小灰点。

## 下滚区

三段固定顺序，卡型各自设计：

| 段 | 供给成员 | 卡片必答 |
|---|---|---|
| 值得深挖的事件 | 新说法侦测、判断守卫 | 发生了什么／为什么今天出现／证据与来源／还有什么解释没排除 |
| 选题卡 | 选题猎手（含回流） | 为什么现在／原话及出处／叙事角度／明确不能证明什么 |
| 值得观察的笔记 | 战绩回收 | 观察多久／当前水位／何时该下结论／当初的预期是什么 |

段序固定优于动态排序：位置稳定形成空间记忆，今天什么最重要由左栏目录顺序表达。

### 选题卡回流

- 今日新卡永远在最前。
- 未处置卡保留 3 天，超期沉入选题库，首页不再占位。沉底不是丢弃，是换地方。
- 沉底卡仅在**重新变得值得**时回流，且必须写明「为什么现在又出现」（新增原声支持、相关判断被推翻、时机窗口到达）。**没有理由的回流是为填满页面制造内容，属于明令禁止。**
- 回流必须在左栏目录出现一条，不得只发生在下滚区。
- 每张卡的处置被记录：划走、看过未动、搁置、采用、废弃。

### 下钻

点击卡片就地展开抽屉，装载完整判断包：证据、反例、还有什么没排除、适用与不适用范围、可执行动作。

动作必须能在抽屉内完成：采用、搁置、废弃、批准补采、标记继续观察。每个动作返回明确回执（例如「已搁置，3 天后沉入选题库」），不以 toast 结束。

真需要深入研究时，抽屉内再提供进入 Topic 工作区的入口。Topic 工作区保持其六层重结构，一天大概只进一次。

## 五类常驻产品职责

首页内容的供给来源，是可追溯且经过资格检查的领域事件、Observation / Claim 变化、请求和运行状态。下列五类职责负责把这些来源组织成用户可理解的事项，不是事实的唯一生产者，也不预设五个 Agent 运行实例。没有合格事项时首页给出当日状态回执；观察不完整时必须单独说明缺口。

| 成员 | 常驻回答的问题 | 主要产出落点 |
|---|---|---|
| 判断守卫 | 既有判断被新材料推翻了吗？ | 左栏叙事、值得深挖 |
| 缺口巡视 | 哪块证据在变薄？哪个观察断了？ | 右栏待决定（补采申请） |
| 新说法侦测 | 有新的表达方式在冒头吗？ | 左栏叙事、值得深挖 |
| 选题猎手 | 有能直接开工的选题吗？ | 下滚区选题卡 |
| 战绩回收 | 当初的判断对不对？ | 值得观察、判断校准 |

按问题划分而不按 Topic 或工序，原因有三：产出天然就是「值得关注事项」而非中间过程；编队规模不随 Topic 增长而膨胀；每个成员都有明确的失败条件和为空条件。

**编队不得自行发起采集。** 采集走既有责任链：Acquisition Request → 人的授权 → Admission → Work Order。编队可以提交补采申请，申请进右栏等待决定；申请不是授权，授权不是执行成功。

### 总编

总编是编队的组织者，不是第六个按问题划分的成员。它负责去重合并、横向排序、决定谁上首页。

- **默认输出为空。** 只有通过硬条件的候选才被放行。
- 硬条件至少包含：跨多个独立来源而非单一爆款或单一作者；已排除「因为本轮扩大了采集范围」这一解释；能说清若为真会影响哪个具体决定。
- 条数机制：绝对门槛为主，上限封顶。过门槛的按排序取前 N，可以少于 N，永不超过 N，**不设保底条数**。
- **交白卷是合法输出。** 若总编的目标是填满页面，它必然注水。

### 总编的可审计性

平时提供一个可展开入口查看被毙候选。空页当天**强制**在首页交代：昨夜交回多少条候选、为什么都没过、最接近的那条差在哪、后续如何处理。

空页是整个产品的信任临界点。不解释的空页会被理解为故障，随后是打开频率下降，随后是彻底弃用。

## 每日节奏

```text
每日版本截止水位  汇总当日可用事项与运行状态
      ↓
早晨固定时间   一条极简钩子：今日语料一句 + 数量，每天必到含安静日
      ↓
打开首页       地形一眼看出哪几块在动
      ↓ 5–10 分钟
左栏读目录 → 点开抽屉 → 决定 → 下一条
      ↓
采用某张卡     冻结弹药包 + 填写预期 → 标准出口交出去
```

每日版本截止水位是首页发布节奏候选，不是统一 Coverage，也不是唯一技术调度方式。每个事项仍保留自己的 observation scope、输入集合和 Coverage；首页只能汇总其资格与缺口，不能用一个夜间批次替代这些边界。具体采用批次、增量还是组合运行，留给 `first-phase-runtime` 决定。

一天内多次打开看到相同内容，这是特性：它训练每天只开一次，匹配 5–10 分钟的时间预算，也避免诱导刷新。

推送钩子故意不完整。它的唯一职责是把人带到首页，内容留在首页。**摘要做得越完整，首页越没有存在价值。**

## 校准回路

### 短回路：处置 → 门槛

每张卡的处置累积成模式后，系统提出调整建议（例如降低某成员的优先级），进右栏等待批准。**不自动生效。** 静默调整会让系统慢慢偏离而无人察觉；且「划走」有多种原因，直接当作负反馈是危险的。

批准与否都留痕，使「校准」本身成为一段可追溯的历史。

### 长回路：预期 → 战绩 → 判断

采用一张卡时同时留下两份预期：

- 系统自动一份，基于该卡的证据强度与同类历史；
- 人工一份，可以极简到一个数字。

**摩擦必须低到不会被绕过。** 一旦开始跳过标记「采用」直接去写，整条校准链就断了。

发布后只回填实际能够取得且有来源的结果，再进行有限三方对比。私信、咨询、销售和产品行为尚未接入时保持 `Unknown`，不能补零、推断或用公开互动代替；公开互动也不能自动证明原判断成立。

| 结果 | 含义 |
|---|---|
| 系统对、人错 | 该类判断上应更信系统，人存在系统性偏差 |
| 人对、系统错 | 系统存在盲区，应定位并补足对应证据 |
| 都错 | 该类判断本身不可靠，不应继续投入 |
| 都对 | 该方法在该类选题上成立，可加大投入 |

**预期写下后不可改。** 可追加新版本并注明原因，不得覆盖原版本；事后调整预期等于自我放水，整套校准作废。

## 继承的纪律

### 不撒谎的情绪货币

首页的情绪冲击必须来自以下四类，按优先级：

1. **真实原话** — 零推断、可回溯、别处无法复制；
2. **表达迁移** — 结构变化而非数量变化，可只陈述共现结构不给比例；
3. **缺口与失败** — 诚实报告未达成与停止原因，反直觉地建立信任；
4. **时间的重量** — 连续观察天数、判断存活时长、跨来源出现次数；唯一随时间自动增值的来源。

### 明确禁止出现在首页的视觉元素

以下均违反 `DEC-05` 或 Gate 3-4 已确认边界，且无法通过版面美学豁免：

- 增长／下降百分比、趋势箭头、velocity 类指标；
- confidence 分数、observation quality 分数、evidence score 等把支持与反例压成单一可覆盖数值的表达；
- 跨时间可比折线图与其上的断点标注（跨账号、跨时间可比性当前为 `SOURCE_INCOMPLETE`）；
- 竞争度、共鸣度、可操作性等无据的定性标签，应替换为有据表述（例如「56 条原声支持，其中 11 条明确提到有效」）。

### 状态诚实

空页、观察不完整、分析处理中、权限受限、系统异常必须使用五种明确不同的表达，不得统一为灰色的「暂无数据」。批次失败的夜晚与平静的夜晚在视觉上必须完全不同。

### 使用范围

首页展示的确定事实必须带来源；真实材料默认脱敏；未知不显示为 0；AI 文本必须能展开所用材料、反例与缺失。以上继承 [`page-map.md`](page-map.md) 的页面共同规则与 [`../product/domain-invariants.md`](../product/domain-invariants.md)。

## 产品边界

### 不与内容工作台重复

现役内容工作台的日常入口（`data-management/overview`）由目标达成、KPI、平台占比、漏斗诊断、运营堆叠柱、热力矩阵、长期趋势、运营排名与关注列表构成，其主语是**我方团队执行**。

Linggan 首页的主语是**世界**。目标、KPI、漏斗、运营排名、加微数据不进入本首页。

### 不长出内容生产能力

采用选题卡后冻结带版本的弹药包（为什么现在、原话及出处、叙事角度、不能证明什么、双份预期），通过标准出口交给下游。下游可以是内容工作台、写作技能或手写，Linggan 不感知具体下游。

冻结是校准的前提：事后必须能调出「当时拿着什么去写的」那个快照。第一阶段出口可以简陋到只是导出文件或复制，传输方式随时可升级，冻结的历史补不回来。

### 使用者

第一阶段小团队多人只读；处置、采用、批准仅限单一决策人。校准数据主体必须唯一，否则三方对比得到的偏差既不属于任何个人也无法行动。本条不引入多租户模型或权限系统，只需一个只读角色。

## 第一阶段推迟

| 项 | 推迟原因与解锁条件 |
|---|---|
| 复杂预算分配与自动降级顺序 | 用户裁定先记录真实花销；跑满两周有真实数字后重新评估。简单硬安全上限、触顶停止和 partial + gap + reason 不推迟 |
| 白天即时推送 | 需要总编门槛成熟到能判断「什么算重大」；编队跑满三个月、对误报率有实感后再议 |
| 移动端操作能力 | 沿用 `DEC-G7-08`；手机只读，不做移动工作台 |
| 大区具体划分 | 属内容决定而非结构决定，走词表治理，等真实语料上来再定 |
| 底图美术与动效细节 | 后续专项 |
| 门槛函数的自动权重调整 | 需要足够处置记录与三方对比数据；在此之前只做提案不自动生效 |

## 已知风险

- **无预算控制的不可预测停止**：五个成员每晚横跨所有大区运行，费用耗尽时可能随机停在半途，而首页无法说清漏了哪部分，Coverage 的可解释性会受损。缓解措施是从第一晚起记录每个成员的实际花销。
- **等距动画退化为装饰**：若行动轨迹未与真实事件严格绑定，或引入与事件无关的永动效果，首屏主体会在数周内被视觉过滤。判据为「今天的首页与三周后的首页，除数字外有什么不同」。
- **摘要架空首页**：推送钩子一旦扩充为完整摘要，首页的全部投入失效。

## 待验证

以下结论均来自设计推演，尚无真实样本支撑，必须在低保真原型与真实脱敏数据上复核：

1. 6–8 个大区是否足以覆盖 ADHD Domain 且保持可读。
2. 左栏目录 3–7 条是否匹配 5–10 分钟预算。
3. 未处置卡 3 天保质期是否过短或过长。
4. 恒定地形在 Topic 数量翻倍后是否仍然稳定。
5. 每早钩子的打开率，以及钩子是否反而降低了首页访问。
6. 三方对比需要积累多少条才开始产生可行动结论。
