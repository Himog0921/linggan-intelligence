# 评论研究

> 状态: 权威当前
> 最后核对: 2026-09-07
> 适用范围: COMMENT-DAILY-001 交付分支，承接 COMMENT-RESEARCH-001
> 事实来源: Mog 当前会话决策、Issue #167、0039/0043 migration 与当前 Rust/API
> 冲突时以谁为准: 用户最新确认、AGENTS.md、真实代码/数据库与验证；本页不证明部署

评论是语料库的基础材料。接纳、去重与当前可读资格成立后，用户直接研究，不需要手动搬运、完成全部采集或等待 AI。当前四个内部视图及查询页已接入代码。MODEL-PI-001 进一步接入 [模型与 AI 设置](model-ai-settings.md) 及真实 Pi SDK 执行链；外部供应商和真实样本效果尚未验收。

| 入口 | 用户动作 | 实际保存/读取 | 限制 |
|---|---|---|---|
| `/corpus/comments?view=voices` 原声浏览 | 文字、作品与清洗状态筛选，分页、勾选分析，展开来源与上下文 | Evidence Current 和语料投影快照；作品标题与作者来自 Work Resource，评论点赞与时间来自本条已接纳记录 | 库内观察样本；父评论缺失不补全；本机受限研究，不是外部模型权限 |
| `?view=groups` 问题分组 | 看相同问题标签的原声样本，继续研读 | 当前源上的最新人工问题标注，或明确同模型/规则版本的候选 | 当前是精确标签归组；未实现语义聚类、代表/边缘样本裁定，也不是正式 Topic |
| `?view=assets` 语料资产 | 将精确表达连同理由收存；修改理由、加入/移出/移动集合、撤销误收存 | 源版本 UUID、Unicode 起止范围、源 SHA-256、理由与集合；不复制原文 | 原声变化后历史选择保持；当前源资格失效时停止返回引用及理由 |
| `?view=daily` 每日研究 | 设置每日 23:00 处理、看批次与逐条结果、暂停/恢复、重试失败 | 冻结来源与配置、清洗版本、分包调用账本及逐条接纳结果 | 每日窗口、预算、首次启用与补偿见下文；结果仍为研究候选 |
| `/corpus/queries` 已存查询 | 保存条件并在以后重跑；改名、修改文字及已有作品范围、删除 | 服务端名称、文字条件、可选作品范围 | 不冻结结果，不触发采集或订阅；当前只承接评论查询 |

资产保存是研究者的选择，不能据此宣布真实、普遍或适合生产。普通研究和计数不会被“是否收存”过滤。当前集合可创建、列出、筛选；既有资产可加入、移出或移动到一个集合。资产理由、集合归属及撤销通过追加版本保存，页面可查看整理记录；已撤销资产退出列表和集合统计。已存查询可改名、修改文字条件、保留或清除已有作品范围及删除。原始创建请求不变，旧请求重放返回当前状态，不覆盖修订或复活撤销/删除项；并发修改必须匹配当前修订号。集合改名、跨集合复用和导出仍未实现。

## 来源、上下文和资格

Evidence 的 `comment_research_read` 是跨作品和单源研究入口。最新原声按作品与平台评论身份去重，但 API 只提供内部不透明来源引用，不返回评论用户 ID、名字或平台评论 ID。页面一次最多显示 20 条、每条先显示 350 字符；详情一次至多显示 4,000 字符，长源标明截断。作品上下文仍来自共享 Work Resource，不能用监控目标另造作者事实。

跨页 cursor 保留接受时间及原查询；新来源不混进原页快照，重新查询才更新样本。`total` 是全匹配可读样本数，部分采集并不使已有评论失效。筛选文字是字面子串，`%` 和 `_` 没有 SQL 通配含义。

新增稳定评论身份的研究限制记录，覆盖该评论所有历史和后来再次观察的版本；原有 `/api/local/work-resources/{ref}/comments` 也使用同一可读 view。资产/标注/分析每次读取都核对资格；已有分析引用的父评论受限时，相关结果不再返回。研究限制只收缩用途，不宣称平台删除，也不删除不可变 Evidence。

本机通道增加 Host/Origin/Fetch-Site 校验和 `Cache-Control: no-store`。这是 loopback 内部研究边界，不是多用户角色、账号授权系统或第三方处理许可。查询、集合、资产、人工修订写入使用 JSON、严格类型、幂等 ID 与修订冲突检查。源正文不写入日志、URL 或新资产表。

## 清洗、按作品分析与每日批次

本次升级以 [COMMENT-DAILY-001](../plans/active/comment-daily-001.md) 取代旧页面的单条试运行/即时自动入口。原声接纳且可读即可浏览；执行 worker 在不调用模型的清洗阶段保守规范空白和明确字符编码，保留否定与 emoji，并记录原文字符映射。直接分析、需上下文、低信息、异常分开统计；低信息/异常仍可阅读和人工收存。

用户可以勾选最多 100 条确切来源，通过弹窗查看模型、供应商和本批额度后试跑或补跑。分包只组合属于同一作品的评论、父评论与作品已取得的正文和媒体文字，最多 30 条并受单次输入/输出限额进一步缩小。评论用户身份不外发；联系方式经过有限规则遮盖。缺少父评论/媒体不补造，也不新建采集或处理任务。

模型返回包内评论编号、引用片段、多维标注及限制。程序检查完整输出、字段、来源、唯一引用以及 Unicode 映射，模型不填写 hash/字符位置。一条输出不合格不会丢掉同包其他合格评论；无信号与失败分开。解释只能是候选，不因引用校验通过而升级为事实。

每日研究默认关闭。用户显式启用后，按北京时间前日 23:00（含）至当日 23:00（不含）冻结首次进入评论语料投影的稳定评论身份；第一批从启用时刻开始。互动更新和同身份再次观察不算新增。错过截点逐批补建，待清洗材料留在原批次；历史补跑必须明确选源。批次冻结模型配置、来源和额度，恢复/重试不清零计费；未知用量保留预留，不默默重新计费。暂停供应商后仍可暂停每日研究。

日批保留 pending/running/succeeded/no_signal/failed/low_information/anomaly/context_missing/restricted/source_limit。页面给出最近 60 批、清洗数、处理数、当前可读作品数、Token 使用；批次明细每页 50 条并可回原声。额度不足显示原因，超额来源保留清单。上下文后来取得后可重新选源；失败重试仅重排仍可读且未达次数上限的条目。这里没有日报散文、语义聚类或正式趋势。

每次调用共用既有模型账本，120 秒租约、最长 60 秒本地等待和配置次数上限。外发前、结果接纳前及读取结果时核对来源/上下文资格；同包某评论/父评论受限或已消费媒体失效，相关结果停止展示。迟到输出不能提交，远端已发请求不保证撤销。输入按 UTF-8 字节和封装余量保守拦截，实际 Token 由供应商报告。

Pi 的提示词与解析合同随代码版本管理；本包没有引入让 Agent 自行调度的 Skill、工具或“自动找新问题”能力。固定模型测试使用同一 v2 合同的合成包，结构失败返回具体原因。真实模型的语义效果需要有范围的真实样本验收。

问题组当前最多检查 10,000 条当前可读原声，返回前 100 个精确标签组，每组最多展示 20 个来源入口；超出时明示范围。人工修订优先，旧模型结果保留。不能用标签归组宣称完成了语义聚类、代表性抽样或需求规模估计。

人工七维修订分别是场景、问题、尝试过的方法、评论者自述失败原因、情绪、期望、表达方式；每项区分来源直接表达与研究推断。人工历史追加保存，不被机器运行覆盖。当前界面展示最新人工修订及保留版本数，完整旧修订内容可从受控 API 读取。

实施与验收见 [本包合同](../plans/active/comment-research-001.md) 和 [分层验收](../design/acceptance/comment-research-001-acceptance.md)。
