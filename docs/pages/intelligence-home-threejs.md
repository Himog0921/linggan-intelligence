## 1. 首页的任务

首页帮助 Mog 在短时间内知道：今天领域的哪里值得注意，为什么；哪些观察没有完成；有什么需要决定。它通过稳定的空间位置积累熟悉感，通过少量有依据的变化提供日常价值。详细比较在市场洞察，具体工作管理在智能工作台。

首页保留三栏与恒定地形，不承接选题管理或内容发布结果。旧 HOME 的选题猎手、战绩回收在当前范围改为供给比较和情报追踪职责；不预设五个真实 Agent。

## 2. 页面布局

```text
全局页头：品牌 | 首页、智能工作台、市场洞察、语料库、采集 | 状态、命令
上下文：ADHD / 今日快照                观察与分析状态 / 截止时间
────────────────────────────────────────────────────────────────
今日叙事             领域地形（主要视觉）                 待我决定
少量发现             稳定大区 + Topic 地块                同一待决对象
每条对应事件         橙色标记指向有价值的新增               决定后回执
点击联动地块         点击地块 → 地图内就地详情
                     轨迹回放 / 全貌 / HTML 视图          持续工作
今日语料             图例始终可见                        已完成/中断/未跑
一段合格材料         下方为选中发现的解释与下一步            只显示职责状态
────────────────────────────────────────────────────────────────
今日情报：与左栏目录一一对应的发现、成果更新、观察缺口
历史版本入口：上一期/指定日期（保持当期截止水位和口径）
```

1440 CSS px 桌面是本轮基准；更宽时扩大中央空间。两侧保持阅读宽度，地形自适应。有限宽度优先将右栏移到正文下方，保留完整操作；不将整屏等比缩小。移动操作仍不在当前产品承诺中。

左栏不是第二套信息流，每个标题都定位到同一发现和地块。右栏仅显示少量当前需要决定事项及工作状态，完整列表进入工作台。大量运行指标不搬进首页。

## 3. 地形表达什么

| 视觉元素 | 唯一含义 | 避免的误读 |
|---|---|---|
| 固定大区位置 | Map View 的导航分区 | 不因每日样本数变化而搬动位置 |
| 区内小地块 | 可进入的 Topic 或明确候选 | 不是每篇作品、每个评论一个节点 |
| 物理高度 | 层级/空间分隔的固定视觉结构 | 不暗示需求、机会、质量或市场体量 |
| 橙色标记 + 编号 | 当前快照中值得查看的事项 | 不表示这个主题正在增长 |
| 轮廓/浅色 + “观察不足”文字 | 尚缺观察或资格，不隐藏区域 | 不暗示该方向没有需求 |
| 选中边缘与 HTML 详情 | 当前用户焦点 | 不改变正式定义与统计 |
| 有限轨迹 | 已记录的取得/分析/交付事件之间的导航关联 | 不展示模型思维或永动粒子 |

初始 6–8 区沿用 HOME 的数量假设，原型给六个合成导航区。实际大区名称和成员通过真实材料与运营比较决定。首页空间布局与市场洞察的主题关系共享稳定引用，布局移动不改定义。

旧设计“荒地变矮/开裂”在此收敛为可见缺口与文字：视觉可以表达未知，但不把材料数量映射为主题价值。该几何映射是本轮待评审建议。

## 4. 交互

1. 首次进入直接看全貌，镜头固定等距方向，不自动飞行。
2. 悬停给简短提示；点击区域选中并打开地形区域内详情。键盘通过同名 HTML 区域按钮完成等价操作。
3. 左栏点击发现 → 定位区域 → 显示该发现的核心解释、依据/范围与“进入主题”“继续分析”。首页不强制先进入复杂工作页。
4. 点击“回放今日轨迹”只播放当前截止水位内的记录，播放完即停；没有事件时显示没有可回放记录。
5. “全貌”重置选择/相机；不因拖动导致迷失。第一版不提供自由翻转、无限缩放或第一人称漫游。
6. “HTML 视图”切换到同一快照的区域列表；选中状态和链接保持。WebGL 不可用时自动启用。
7. 决定操作在右栏或就地抽屉中完成，展示真实后续回执；正式采集、模型或权限决定由其 owner 处理。

原型中这些操作只改变演示内存，不发送真实请求。首页快照场景可切正常、无合格新增、观察中断、尚无基线，供评审状态表达。

## 5. 状态与时间

| 情况 | 地形与今日内容 | 下一步 |
|---|---|---|
| 有合格新事项 | 保持地形，标记新增位置，左栏目录联动 | 阅读、下钻、继续分析 |
| 已检查但无合格新增 | 地形稳定，无假脉冲；显示检查回执 | 浏览领域或已有成果 |
| 观察不完整 | 保留上次有效地形，明确旧快照；异常标在受影响范围 | 看采集阻塞及影响 |
| 分析中断 | 材料更新和分析水位分别显示 | 看已完成结果，恢复工作 |
| 尚无领域结构 | 中央给可读的起步说明和已有语料/主题分析入口 | 不展示合成“活地图”冒充数据 |
| 渲染不可用 | 完整 HTML 区域列表和同一发现/决定 | 全部核心操作仍可完成 |

快照有自己的截止时间；每条发现仍有独立材料范围和观察水位。回看历史不显示今天的最新数字。跨期资格不足时保留“新增观察”措辞，不画确定性趋势箭头。

## 6. Three.js 技术方案

Three.js 负责中央场景；周边正文、按钮、列表和抽屉用现有 Web 页面能力。原生 JS 可以与 Rust 输出的 HTML 共存，不要求全站换 React 或引入 React Three Fiber。

- 正交相机保持物体大小与镜头距离无关，适合等距领域导航。[官方 OrthographicCamera](https://threejs.org/docs/pages/OrthographicCamera.html)
- Raycaster 将指针点击映射到带稳定主题引用的对象；文字和按钮保留在 HTML 层。[官方 Raycaster](https://threejs.org/docs/pages/Raycaster.html)
- 几何使用轻量 Shape/Extrude/Plane，无大纹理、模型资产或后处理 bloom；优先用可读几何与状态标签建立辨识度。
- 默认按需渲染，只有选择、尺寸、数据或有限回放时更新，后台页停止回放。原型不建立永久动画循环。[官方按需渲染](https://threejs.org/manual/en/rendering-on-demand.html)
- 尺寸按容器更新；像素比设上限而非盲目追随高 DPI。切页释放 geometry/material/renderer，并处理 context loss。[响应式](https://threejs.org/manual/en/responsive.html)、[资源释放](https://threejs.org/manual/en/cleanup.html)
- Reduced Motion 下取消镜头与轨迹动画，仍能选择事件与区域；触屏/键盘不依赖 hover。

生产性能目标（待真实环境测量）：首个可读 HTML 不等待 3D；场景懒加载；桌面交互 p95 ≤100ms；回放目标 30fps；原型起步 geometry <10,000 triangles、draw calls <150、DPR ≤1.5；静止时无持续绘制。预算是设计目标，不伪称已满足所有设备。

首个合成原型固定 Three.js 0.185.1，依赖以 npm tarball integrity 校验，并把库与页面打入一个可离线打开的 HTML。这里是本轮选定版本，不声称它是生产版本。

## 7. 未来数据接入

需要的页面读合同：快照/截止水位；Map View 和稳定主题节点；获准的发现引用与关联区域；当前待决对象；职责/工作执行摘要；允许展示的今日语料引用。此处仅列责任，不新增 schema 或万能 event 表。

候选的页面聚合服务从领域/采集/分析 owners 读取这些内容；浏览器只负责映射。每条轨迹必须可展开成“实际做了什么、依据哪个回执”，不把 model token stream 当作领域变化。

先从一组真实主题、少量合格发现和当前运行回执接入，再决定是否扩大场景。地形没有独立的机会打分或材料仓库。

## 8. 原型覆盖与实际验证

首轮走查计划：1440×1000 与 1720×1100；五入口和全部二级面；主题比较到工作/补采/回收/成果；首页正常/安静/中断/无基线；3D 选择、有限回放、HTML 降级、Reduced Motion；超长标题、未知作者、0/null/极大读数。

首轮实际检查（2026-09-06，Codex 内置浏览器；当时为 15 个二级页）：

- 1440×1000 与 1720×1100 桌面检查；1440 下 15 个二级入口逐页核对标题和职责，页面宽度均为 1440，无整体横向溢出。首页、主题表格/分布和详情已视觉走查。
- 首页使用实际 WebGL Three.js。射线点击地块选中“学习与执行”；左栏/HTML 区域可定位到同一主题。正常静态场景为 852 triangles / 36 draw calls；回放中为 932 / 38，结束后两次观察 frames 均为 237，未继续绘制。该读数是本机原型观测，不是性能分位或生产容量保证。
- 安静场景移除新增标记（480 triangles / 30 draw calls）；中断场景明确保留旧快照；无基线显示起步说明。手工 HTML 替代视图有六个区域按钮并可进入观察不足区域。
- 三方向比较 → 固定 90 天输入 → 库内分析 → 补采申请 → 同意 → 实际演示取得 2/3 → 返回更新 → v2 成果已走通。后续把主题页切到 30 天，成果仍保留 90 天的 320/40/160 作品输入。
- 主题排序、无命中筛选、清除筛选、表格/分布切换、四个详情 Tab、问题 × 回答矩阵下钻已操作。修正了分布视图的空态误提示和 30 天 25% 数据点的纵轴空间。
- 随手记编辑、搜索、页面刷新后保存内容及深链页面恢复已验证；测试文字已恢复为初始合成笔记。材料列表覆盖超长标题、作者未知、0、null 和极大数字的显示。
- 自有三个 JS 语法检查通过；重建 SHA-256 一致；变更文档 298 个本地链接无缺失；`git diff --check`、项目治理与设计手册检查通过。浏览器当次收集到的 error/warn 日志为空。

内置浏览器 URL 安全策略拒绝工具直接打开本地文件，因此独立 HTML 的离线打开未验证；上面的浏览器检查使用既有本地 HTTP 预览。未尝试绕过这一限制。

未证明/未完整实现：真实模型、采集、聚类、问题匹配与数据来源；历史快照切换、全量主题树的三维布局；浏览器刷新后的分析任务持久化、对象级筛选/滚动全量恢复、导出内容逐项验收、全部权限状态；WebGL context loss 的故障注入、Reduced Motion 的系统级浏览器测试、读屏软件及性能 p95。Reduced Motion/context loss 已写处理分支，但未把源码阅读算作浏览器证明。原型每区接一个合成主题，小块仅示意层级几何。

原型的任务/筛选主要在当前会话保存，随手记存浏览器 localStorage；分析为预置文本，可编辑要求不调用模型。合成演示与浏览器检查均不代表生产部署或 Mog 业务验收。

### 语料库四入口修订的补充验证
