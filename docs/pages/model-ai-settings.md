# 模型与 AI 设置

> 状态: 权威当前
> 最后核对: 2026-09-10
> 适用范围: `/settings/models` 的连接、模型、V1 默认研究模型、embedding 与调用账本
> 事实来源: COMMENT-RESEARCH-RESET-001、当前 local API 与运行合同
> 冲突时以谁为准: 用户最新授权、真实运行回执和当前代码

此页是模型调用的唯一配置面，不是评论研究的第二套工作流。

| 表面 | 用户动作 | 系统事实与边界 |
|---|---|---|
| 连接 | 保存 endpoint、凭据和启停状态 | 凭据只在 Keychain；保存不发起评论研究。 |
| 模型 | 测试最小 synthetic JSON、设置 V1 默认研究模型 | 测试回执决定当前是否可调用；未测、失败和停用分别说明。 |
| 向量 | 保存并测试独立 embedding 模型 | 只为候选召回产生版本化向量，不自行合并问题。 |
| 调用账本 | 查看最近调用的时间、阶段、用量与失败 | 可审计但不展示原始评论或凭据。 |

评论研究只读取已保存的默认模型和 embedding 配置。研究设置保存一次 policy 后，用户点击“开始研究”才冻结 V1 Run；连续排程没有入口。生成模型只负责提取 Atom 与判断 same/new Problem；向量只召回候选；最终统计、membership、变化与发布由程序验证。评论研究页的单轮 Token 额度覆盖语义提取、向量候选与问题归并的每一次外部调用；每笔调用仍写入通用调用账本并携带该 Run。

用户可理解的状态必须区分：未配置、连接已保存但未测试、可调用、停用、embedding 未就绪、调用失败和本轮已完成。不得保留旧 trial/backfill/daily plan 的按钮、状态或 API，也不得让用户在原声列表看到“语义向量准备”。

保存连接、测试 synthetic input 和保存 policy 都不自动发送真实评论。真实评论、费用和结果只在用户主动开始一轮已配置的研究后发生；该轮的预算、模型/连接版本、调用阶段与用量由 invocation ledger 保留。
