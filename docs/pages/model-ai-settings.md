# 模型与 AI

> 状态: 权威当前
> 最后核对: 2026-09-06
> 适用范围: MODEL-PI-001 / Issue #169 交付分支，依赖 #168
> 事实来源: Mog 已确认的四区设置结果、0040、当前 API / Pi / worker
> 冲突时以谁为准: 用户最新确认、真实代码与隔离运行；本页不证明部署或外部模型质量

入口为个人菜单 → 设置 → 模型与 AI（`/settings/models`）。这是本机数据库工作空间的配置页；它不增加智能内核监控一级页面。

| 区域 | 用户操作与落地结果 | 不可混淆的状态 |
|---|---|---|
| 供应商连接 | 添加名称、协议、基础地址和 API 凭据；测试目录；发现模型；更换配置；停用/启用 | 保存不调用。目录响应只证明目录可读；目录不支持时可以手动填模型 ID。当前支持 OpenAI Completions、OpenAI Responses 与 Anthropic Messages |
| 可用模型 | 选择目录候选，或填供应商准确 ID；显式运行合成评论能力测试 | 目录存在、模型可调用、评论结构/来源校验通过分开显示。探测上限 10 秒、1024 输出 token、无内部重试；不发送库中真实评论 |
| 用途默认 | 选通过评论校验的模型，保存输入/输出 token、等待秒数、最多尝试次数、自动数量与累计额度 | 保存不会创建分析。旧任务/结果冻结配置引用，新默认只影响新任务 |
| 额度与运行 | 查看独立执行循环心跳/错误、计划数量/预算、调用结果与用量；暂停或显式恢复计划 | 运行心跳不证明供应商成功。恢复不重置额度或尝试次数。未知 token 保留未知，账单金额不由 Pi 目录零单价推导 |

OpenAI 兼容接口通常使用含 `/v1` 的基础地址；Anthropic 使用服务根地址，SDK 添加 `/v1/messages`，目录读取添加 `/v1/models`。浏览器没有供应商直接请求；所有调用通过当前连接的后端凭据。页面不回显、持久化或打印密钥。Keychain 无法访问时明确失败，无文件明文回退。更换产生不可变连接版本；已有任务保留旧地址和旧凭据。若要停止旧调用，停用整条连接；更换配置不会解除停用。

配置保存后有三种明确动作：

- 单条试运行：从当前可读原声中选定一条，确认模型、来源与累计额度；来源详情可直接带内部 sourceRef 进入选择窗口。
- 自动新增：显式启用一份数量与 token 授权，只纳入启用后新接纳且当前可读的来源版本。换默认模型不重置该计划累计额度；新增任务使用当时配置，已排队任务保持原配置。
- 历史补跑：筛选原声并选择确切来源（页面每次最多 20 条，API 最多 100 条），单独确认总数与累计上限；不自动追加未选材料。

保存和旧请求重放不能启动第二份分析、覆盖新默认或恢复已暂停计划。已有相同来源/规则/配置的工作被复用，新增计划可能排入 0 条；回执提供实际所属计划链接，进入后可查看并恢复该计划，不误称再次处理。即使原计划已不在最近 50 条中，指定链接仍能定位。

暂停计划的行内「恢复此计划」打开确认窗口，恢复需携带当前修订号；页面过期或旧恢复请求重放会提示冲突，刷新后再操作。恢复保留原来源、配置、已用额度、次数和时间起点，只接续尚可执行的工作，已完成来源不再调用。当前自动计划恢复后沿用原启用时间范围，暂停期间新接纳的来源仍可纳入剩余额度；被新自动计划替代的旧计划只接续已有工作，不重新成为自动新增计划。连接仍停用时，恢复计划也不能派发。

每次尝试先预留输入与输出上限；普通可重试错误至少间隔 30 秒，最多使用配置的 1–3 次尝试。只要调用可能已发生而完整用量未知，就保留预留与已经明确的更大用量。中断后的维护在无新工作或余额不足时仍收口，达到冻结次数上限的工作标记失败，已成功工作的回执按原结果收口，不再次调用。输入预算用 UTF-8 字节及固定封装余量作保守拦截，实际 token 由供应商另报；输出上限传给 SDK。超时终止本地等待与子进程，不保证远端取消或免计费。计划余额不足、连接停用、worker 无近期心跳分别可见。

结果经当前来源资格、来源 hash、Unicode 精确片段与多维结构验证后回到评论研究。人工标注优先，旧分析历史保留。问题组仍按相同标签归组，不能声称已完成语义聚类、需求规模推断或代表样本质量判断。

常驻入口是在既有 `linggan-worker` 中独立异步运行的评论循环，10 秒调度一次；模型调用不在巡检 tick 内。单独 `linggan-comment-worker --execute [--once]` 供隔离验证/明确运行；原 `--queue-only` 不调用任何模型。保存开关不是运行证明，页面心跳和调用回执才说明这一层实际发生了什么。

真实供应商尚未配置。本包的本地协议 fixture 明确标记 SYNTHETIC / NOT EVIDENCE，验证真实 Pi SDK 和运行边界；真实外部材料、成本和语义效果仍须 Mog 在可用配置页确定后验收。运行准备见 [运行说明](../runbooks/model-pi-runtime.md)，实施证据见 [分层验收](../design/acceptance/model-pi-001-acceptance.md)。
