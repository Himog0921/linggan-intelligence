- 交付包与边界：Mog 在对话中直接派定，授权「从 `origin/main` 开新工作树、一次做完、给一个 PR」。worktree `claude/evidence-library-v9-ui` 自 `a85bedc` 建立。范围限于 `/corpus/evidence` 的读与呈现；不采集、不回填、不做 mutation、不迁移共享库、不部署、不合并。
- 新读能力：新增 `crates/evidence/src/material_evidence_fragment.rs`，为每个作品读取一条有界原声摘录，随摘录返回来源类型、选取依据、是否截断、来源引用与命中槽位，作为 `items[].evidenceFragment` 出现在列表响应里。这实现的是 `media-lifecycle-contract.md` 早已写下但一直没做的那条线——原始受限材料留在受控 Inspector，普通列表带有界片段。摘录上限 88 字符，所有偏移量是字符偏移不是字节偏移，`null` 表示这个作品确实还没有可引用文本，页面据此渲染诚实空态而不是拿标题顶替。
- 取材顺序有一处按真实数据反转：有检索词时机器识别文字排在评论之前（读者要的就是那个字符串，且槽位可用于定位）；无检索词时改为 正文 → 评论 → 正文图片文字，并**排除封面 OCR**。本库真实封面 OCR 产出形如 `oy 六 字 =] Li`、`6双干失信各关 | oy 一 Re ea aos`——封面是设计图，识别结果必然是噪声，把它放在读者预期看到一句话的位置，页面会看起来是坏的，而且那是系统自己无法背书的说法。实测 14 篇里 3 篇有可引原声，11 篇走空态。
- 页面按 V9 重建：查询区收敛为一条 FIND 主检索 + FILTER 气泡 + 排序 + 主动作；快捷视图与排版切换压成一条标签带；研读行改为 微缩封面 / 身份 / 一句衬线原声 / 互动四数 / 材料摘要轨，九宫格通道矩阵按 V9 明令从列表行移入 Inspector；Inspector 四 Tab 更名为 概览 / 证据 / 材料 / 来源轨迹，新增 408 / 640 / min(920px,72vw) 三档宽度与关闭，偏好写 `localStorage` 并进 URL，1180px 以下改右侧抽屉。
