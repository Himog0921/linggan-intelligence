## 每条记录必填

- 日期和事项编号；
- 为什么改；
- 影响文件或模块；
- 新旧文档或事实冲突如何处理；
- 实际运行了什么验证、结果怎样；
- 哪些边界仍未证明；
- commit（提交后补充；未提交时明确写未提交）。

重要决定、迁移、发布和包级里程碑记入月报；普通实现、格式、测试细节记在 PR 回执，无 PR 的直接维护可用会话回执或 commit。不要求每次代码提交触碰共享月报。具体更新条件以[协作协议](../governance/agent-collaboration.md)为准。
