## 每条记录必填

- 日期和事项编号；
- 为什么改；
- 影响文件或模块；
- 新旧文档或事实冲突如何处理；
- 实际运行了什么验证、结果怎样；
- 哪些边界仍未证明；
- commit（提交后补充；未提交时明确写未提交）。

小型拼写修正可以合并记录；行为、合同、数据含义、配置、权威文档或操作流程变化不得省略。
