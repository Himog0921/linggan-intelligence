## 3. 卡片不是新的研究对象

一张卡仍对应已有 problemRef。显示已保存定义，而不是从原声现场生成“新发现”；一条关联原声明确是预览，不保证代表整段问题。标题最多两行、定义最多两行、原声三行；正文完整版在抽屉可读。黑底短定位号不是价值排名；真实数量与未知值分开。

“最近变化”来自建档/版本记录/首次原声关联三种事实。“定义版本更新”不代表语义提升；材料补入不自动生成洞察。不做按访问频率随机换引文，不引入人工确认门槛，不因样本少隐藏有效问题或线索。

## 4. 只读卡片接口

`GET /api/local/comment-study/problem-cards`，继承既有 local Host/Origin 与响应 no-store 守卫，不触发模型、Run、写库或迁移。

| 参数 | 约束 |
|---|---|
| domain | 必填 UUID，并检查领域存在 |
| q | 标题/定义字面搜索，最多300字符；不声称支持原声语义搜索 |
| view | all / changes；changes 为近28天已记录变化 |
| order | recent / created / support |
| limit | 默认12，1–50；列表 limit+1 判定后续 |
| cursor | 绑定领域、搜索、视图、排序、服务端基线及排序范围版本；不能作为权限凭证 |

同一 SQL 先做领域、可读性、去重、筛选、全局计数，再排序/分页；预览只对该页读取，不按卡发 N+1 请求。原声身份为作品+评论标识，账号身份为平台+账号，不宣称自然人。首次关联时间从历史 membership/source 身份计算，不把同一评论重研当新增。来源或排序发生变化，旧游标返回409，要求从首页刷新，不静默跳过/重复问题。

`baselineMicros` 是新增材料翻页边界，不是冻结权限或完整历史数据库快照。每次查询依旧检查当前 source/parent restrictions 和 effective signal。读取事务只读，单语句超时8秒；错误不伪装成零结果。查询性能与 Rust/PG 集成必须在真实隔离环境继续确认。

## 5. 抽屉、限制和返回

桌面抽屉顶边实测当前工具栏下缘并保留共享页头位置；小屏使用全宽。原生 dialog 提供焦点圈定，关闭回到打开卡片；打开/关闭不要求清空列表。URL 和 history 只记领域、筛选、游标、问题定位、密度，不保存原声正文。保留原宿主规范化 URL 前的初始书签，以及 popstate 捕获阶段的筛选，避免旧宿主把问题查询删除。

列表/详情/语境请求带取消和序列保护，旧请求不覆盖新选择。详情定义和原声读取可独立失败。同一评论的多个 signal 仍合为一条原声。作品语境目前只返回标题与父评论，页面不把标题扩写成作品观点。

来源不可读时隐藏相应定义或研究表达；已打开卡片重新核对不可读后同步刷新背景卡片。线索先核对当前原声，变更时不继续展示旧归一表达。复制重新读取定义资格，只包含可读定义、计数/范围、真实页面定位及版本；不批量导出原声。不成功的剪贴板操作提供可选中文本，而不是声称已复制。未接入内容对照不生成“我方没讲过/市场无人回答”。

## 6. 状态字典

| 情况 | 行为 |
|---|---|
| 查询失败/错领域回执 | 失败提示与重试，不呈现0 |
| 筛选无结果 | 可清除搜索，与没有研究材料区分 |
| 近28天无变化 | 明确无记录变化，历史问题/线索可读 |
| 未归并/待语境/预算中止 | 独立线索视图，原处理状态与批次入口 |
| 建议或经验表达 | 继续可读，不通过卡片外观升级为用户问题 |
| 定义依据受限 | 隐藏定义及不可读版本，其他允许的证据可保留 |
| 数量未知/真实0 | 分别显示“—”与0，不互相替代 |
| 非最新请求返回 | 忽略/取消，不改变当前选择 |
